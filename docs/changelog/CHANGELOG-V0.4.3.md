# v0.4.3（开发中）

> 2026-11-06 起累积。五个版本文件已升至 `0.4.3`，处于开发阶段，尚未打包、未打 tag。

## 新增

- **直接粘贴图片**：截图、网页图片、从资源管理器复制的图片文件现在可以直接 `Ctrl+V` 粘贴。本地文档（含未命名文档）统一保存到用户目录 `~/Documents/yizimarkdown/assets/` 并写入绝对路径：不会在项目目录里创建 `images/` 或其他文件夹，也不随应用缓存清理丢失。同一张图按内容哈希自动去重，单图上限 8MB。
- **未命名文档也能先粘贴**：图片直接落用户 `assets/`，与是否已保存无关，不需要先保存文档；首次保存到本地 / 云端时路径会自动处理。
- **云端图片随文档同步**：云端文档的图片统一存放在 WebDAV「根目录」下的 `assets/`（默认 `/yizimarkdown/assets/`，整个云端空间共用一个目录），正文按文档层级写 `assets/` 或 `../assets/` 相对路径；图片随保存上传、重新打开时自动下载。本地文档保存到云端时会自动转存过去，换设备也能带走。
- **富文本内嵌图落盘**：从 Word / 网页粘贴的图片不再写成巨大的 `data:image` base64（Word 的 `file://` 临时图会复制进图片资产目录），文档体积与同步流量明显下降。
- **云端文件树顶部导航**：改为常驻图标，依次为上级目录、根目录（WebDAV 根）、主目录（设置中的根目录）、新建文件夹、新建文件、一键展开、刷新。
- **移动文件 / 目录**：文件与文件夹的右键菜单、行尾「…」菜单新增移动入口，打开与「保存到云端」同款目录选择弹窗；不能移动到自身或其子目录。
- **展开 / 收折全部**：递归展开当前树根下的所有子/孙目录，失败目录就地显示错误，不影响其他分支；展开后按钮切换为「收折全部」并改为向上箭头，再点一次全部收起。

## 改进

- **首次启动语言自适应**：没有安装器语言时按系统语言自动选择界面，系统语言不受支持则回退英文；设置里的语言项附带英文 `Language` 标识，中文界面下也能快速定位，不会把不懂中文的用户困在中文界面里。
- **俄语界面**：新增 `src/i18n/ru.ts`，全部界面文案提供俄语翻译；设置 → 通用 → 界面设置 → 界面语言新增「Русский」，安装器语言选择、EPUB 导出语言下拉同步支持俄语。
- **多语言致谢页**：演示模式结尾页不再只认中文「谢谢 / 感谢」和英文「Thanks」，补齐简繁中文、英、日、韩、德、法、西、意、葡、荷、波、瑞、土、乌克兰、俄语的常见致谢 / 结束词，并忽略大小写、结尾标点与多余空格；`Q&A` / `Q & A` / `Q＆A` 同样命中。仍要求 H1 整串匹配，不会误伤普通标题。
- **本地图片统一存放**：本地文档（含未命名文档）的粘贴图一律写到 `~/Documents/yizimarkdown/assets/`，Markdown 使用绝对路径；不再提供「文档旁 images/ / 应用资源目录」二选一设置。代码仓库 / 项目目录不会再出现 `images/`，图片也不随缓存清理丢失。云端文档的图片统一转存到 WebDAV「根目录」下的 `assets/`（默认 `/yizimarkdown/assets/`），所有文档共享一个目录，正文按层级写相对引用。
- **另存为会带上图片**：把文档另存到新目录时，正文里相对引用的图片会一并复制到新目录的对应位置，不再出现「文件搬了、图没跟过来」。
- **点击文件夹不再跳转**：改为 Obsidian 式展开/收折，当前条目高亮显示。
- **新建位置跟随选中目录**：新建文件/文件夹在选中的文件夹内创建（选中文件时使用其父目录）；创建或移动后自动展开到目标目录。
- **宽度手柄提示**：在「按住拖动调整宽度」下方新增一行「双击还原默认宽度」。

## 修复

- **源码模式鼠标光标偶发变白**：光标设为「原生（默认）」时，Windows 11 + WebView2 的系统 I 型指针会间歇丢失透明通道、整块变白，白底上几乎看不见。原生档现在改用应用自绘的细 I 型光标，外观与原生一致：亮色主题黑色、暗色主题浅灰，不再受系统指针位图与显卡合成影响；编辑器、实时模式块、输入框与 AI 输入区同步生效。
- **原生控件跟随应用明暗**：亮色主题下不再出现深色的系统滚动条、表单控件或系统原生光标（`:root` / `.dark` 补 `color-scheme`）。
- **选中后点击选区内部无法退出**：全选或部分选中时，点击已选中的文字不再被选区覆盖层拦截，选区会收拢并把光标放到点击位置。实时模式的 `.cm-selectionLayer` 仍保持在正文之上，但改为 `pointer-events: none`，只负责绘制。
- **实时模式目录块不跟随 `--toc-*` 令牌**：预览用令牌、实时模式的 `[toc]` widget 却写死背景与边线。现在实时模式同样消费 `--toc-bg` / `--toc-border` / `--toc-radius` / `--toc-padding`，自定义 CSS 设 `--toc-bg: transparent; --toc-border: none;` 后两种模式一致。

## 导出完成后打开文件

- PPTX / EPUB 等导出弹窗成功后，「导出」按钮变为「打开」，并提供「打开所在目录」。
- DOCX / PDF / HTML / Markdown / TXT 导出成功后弹出统一的完成弹窗，可直接打开文件或定位到所在目录。
- 工具栏「导出」图标改为经典导出/上传语义的「托盘 + 向上箭头」。

## 代码块行号

- **显示行号开关**：代码块右上角新增行号图标，与换行开关一样持久化；预览、实时模式和 HTML / PDF 导出同步。
- **逻辑行编号**：跨行的语法高亮会在换行处正确闭合/重开，开启自动换行时行号只出现在逻辑行首。
- **行号分隔线**：行号右侧增加一条细竖线，与代码内容隔开；竖线随行高伸展，自动换行时保持连续。

## 表格与模板设置

- **新建表格不再预填内容**：只插入空白表格骨架（3 列 + 1 空行），不再出现「列1 / 列2 / 列3」。
- **预览表格对齐实时模式**：表格字体、行高、内边距回到正文基准；空单元格补不可见行盒；全空表格强制满宽，不再被主题的 `max-content` / `auto` 宽度缩窄成细条。
- **模板删除**：设置 → 模板新增删除按钮，带确认弹窗；删除当前默认模板时会同步清空默认模板设置。

## 目录块样式与开关

- **全局默认无边框无背景**：`[toc]` 目录块改为 `--toc-bg: transparent` / `--toc-border: none`，由预设主题各自声明边框与背景。
- **右上角显示开关**：预览与实时模式的目录块右上角新增 hover 显示的边框/背景开关，样式与代码块按钮一致；状态持久化，切换后两种模式同步，关闭时强制透明无边框。切换界面语言时 tooltip 会同步刷新。
- **目录条目**：不显示无序列表装饰（圆点会压过标题文字），层级只靠缩进牵引，视觉上更像大纲而非第二份列表；右上角 hover 开关保持不变。
- **目录导出**：
  - HTML / PDF 与预览一致，**同样不输出列表装饰**；边框/背景跟随目录右上角开关，静态导出隐藏不可用的开关按钮。
  - DOCX 使用 Word TOC 域与 TOC1–6 样式，不导出无序列表编号；开启目录边框/背景时用单格表格包裹（主题边框色 + 表面底色），关闭「导出主题色」或关闭目录开关时一律无边框、无背景。
