# v0.4.3

> 2026-11-09 发布。本次更新累积自 2026-11-06。

本次更新有两个重头：**禅模式**把界面收走，只留下文字；**Linux 客户端首次发布**，让 YiziMarkdown 正式覆盖 Windows、macOS、Linux 三大桌面平台。

## 新增

- **禅模式（本次核心）** — 按 `F9` 或点工具栏按钮，工具栏、标签栏、侧栏、AI 面板、状态栏会按层次朝屏幕边缘收折淡出，只留正文与留白；整个过程中**版面不变**，正文一个像素都不会移动。
  - 鼠标贴住屏幕任一边（上 / 左 / 右 / 下），对应区域原地淡回；离开约 1.2 秒后自动收回。
  - 禅模式按钮常驻原位，周围一圈极浅的呼吸涟漪，既是「你在禅模式里」的状态锚，也是退出通道。
  - `F9` / `Esc` 均可退出；仅在源码 / 实时模式可用，切到并排、预览，或进入阅读 / 演示会自动退出。
  - 行号与侧栏竖线隐藏、极淡暗角、指针静止 2 秒自动隐藏，纵向滚动条换成极简细条。
- **Linux 客户端（首次发布，本次第二重头）** — YiziMarkdown 第一次正式支持 Linux，提供 Debian 系 `deb` 与通用免安装 `AppImage` 两种安装包（Ubuntu 22.04+ / Debian 12+，当前仅 amd64）。
  - 安装后自动注册菜单项、图标与 `.md` / `.epub` 文件关联，双击即可打开文档。
  - AppImage 自带 GTK / WebKit 与媒体组件，无需额外安装依赖，双击即用。
  - 发布页同时提供 `YiziMarkdown_<ver>_amd64.deb` 与 `YiziMarkdown_<ver>_amd64.AppImage` 两个安装包。
  - 配置、技能、模板、主题与图片统一存放到系统文档目录，升级 / 重装不再丢失。
- **阅读模式翻页动画** — 新增水平滑动（默认）、淡入淡出、轻微缩放三种动画，书卷式 3D 翻页保留，共 4 种可在阅读 HUD 中切换并记住选择；连按不跳页，目录 / 页码 / 脚注跳转不播放动画。
- **直接粘贴图片** — 截图、网页图片、从资源管理器复制的图片文件可直接 `Ctrl+V` 粘贴。本地文档（含未命名文档）统一保存到用户目录 `~/Documents/yizimarkdown/assets/`，正文写绝对路径；不会在项目目录里创建图片文件夹，也不随缓存清理丢失；同一张图按内容哈希自动去重，单图上限 8MB。
- **云端图片随文档同步** — 云端文档的图片统一放在 WebDAV 根目录下的 `assets/`（默认 `/yizimarkdown/assets/`），正文按文档层级写 `assets/` 或 `../assets/` 相对引用；保存时随文档上传，重新打开自动下载，换设备也能带走。
- **富文本内嵌图落盘** — 从 Word / 网页粘贴的图片不再写成巨大的 `data:image` base64（Word 的临时 `file://` 图片会复制进图片目录），文档体积与同步流量明显下降。
- **云端文件树导航** — 顶部改为常驻图标：上级目录、根目录、主目录、新建文件夹、新建文件、一键展开、刷新。
- **移动文件 / 目录** — 右键菜单与行尾「…」菜单新增移动入口，不能移动到自身或其子目录。
- **展开 / 收折全部** — 一键递归展开当前树根下的所有子目录，失败目录就地提示；再次点击全部收起。
- **导出完成后可直接打开** — PPTX / EPUB 等导出成功后按钮变为「打开」，并提供「打开所在目录」；其他格式导出完成也有统一弹窗，可直接打开文件或定位。
- **代码块行号开关** — 代码块右上角新增行号按钮，与换行开关一样持久化；开启自动换行时只在逻辑行首编号，行号右侧有细分隔线；预览、实时模式与 HTML / PDF 导出同步。
- **目录块边框 / 背景开关** — 预览与实时模式的 `[toc]` 目录块右上角新增悬停开关，状态持久化，两种模式同步；HTML / PDF / DOCX 导出遵循该开关。
- **俄语界面** — 新增 `Русский`，界面语言增至 16 种；安装器语言选择与 EPUB 导出语言下拉同步支持。
- **多语言致谢页** — 演示结尾页可识别 16 种语言的常见致谢 / 结束词（含 `Q&A` / `Q & A`），忽略大小写、结尾标点与多余空格。
- **图片资源目录说明与保护** — 本地与云端的 `assets/` 目录会自动写入中英双语 `README.md`，说明用途、哈希命名与「请勿手动清理」；云端 `assets/` 在文件树中标记为系统目录，禁止移动 / 重命名 / 删除，展开时显示图片数量。

## 优化

- **Linux 用户目录与内置资源** — 配置、技能、模板、主题与粘贴图片改存到系统文档目录（通常 `~/文档` 或 `~/Documents`；没有文档目录时用 `~/.local/share/yizimarkdown/`），升级 / 重装不再丢失；内置主题、模板、技能也能正确加载。
- **Linux 窗口与任务栏图标** — 窗口带应用图标，任务栏 / Dock 正确显示；开发态另提供一条图标安装命令，方便在桌面环境中看到应用图标。
- **AppImage 音视频支持** — 安装包内置 GStreamer 组件，Markdown 里的音视频可正常播放。
- **更新提醒覆盖 Linux** — macOS、Linux 与 Windows 便携版统一走「发现新版本 → 打开对应系统下载页」的提醒。
- **Linux 文件关联** — 文件关联类型已补全，双击 Markdown 文件即可直接用 YiziMarkdown 打开。
- **首次启动语言自适应** — 没有安装器语言时按系统语言自动选择界面，不支持则回退英文；语言项附带英文 `Language` 标识，中文界面下也能快速定位。
- **图片统一存放** — 本地文档图片一律进用户 `assets/` 并写绝对路径，不再提供「文档旁 / 应用目录」二选一；云端文档统一转存到 WebDAV 根下的 `assets/`，所有文档共享。
- **另存为会带上图片** — 文档另存到新目录时，相对引用的图片一并复制到对应位置，不再「文件搬了、图没跟过来」。
- **云端文件树交互** — 点击文件夹不再切换树根，改为就地展开 / 收折并高亮当前条目；新建文件 / 文件夹跟随选中目录，创建或移动后自动展开到目标位置。
- **阅读模式菜单可读性** — 目录抽屉、跳页弹窗与动画菜单改为实底，避免主题半透明背景透出正文。
- **表格与预览一致** — 新建表格只插入空白骨架（3 列 + 1 空行），不再预填「列1 / 列2 / 列3」；预览表格的字体、行高、内边距回到正文基准，空单元格补不可见行盒，全空表格强制满宽。
- **目录条目更干净** — 目录块不再显示无序列表圆点，层级只靠缩进牵引，视觉上更接近大纲。
- **模板删除** — 设置 → 模板新增删除按钮，带确认弹窗；删除当前默认模板时同步清空默认设置。
- **宽度手柄提示** — 「按住拖动调整宽度」下方新增一行「双击还原默认宽度」。

## 修复

- **中文输入法空格导致标题 / 列表不渲染** — 输入法在候选状态按空格时，偶尔会把 `#`、`-`、`>` 后面写成不换行空格（NBSP），使标题、列表在实时 / 预览 / 并排下退化成普通文字。现在会按 Markdown 语法自动纠正这类误输入；正文中间的空格、代码块内容与有意输入的全角空格不受影响。
- **Linux 配置无法持久化** — 旧版把用户配置写进只读的安装目录（`deb` 的 `/usr/bin`、AppImage 的临时解包目录），退出即丢失；现在统一落到用户目录。
- **Linux 内置主题 / 模板 / 技能缺失** — 安装版资源目录识别错误，内置主题与模板读不到；已改为从安装包资源目录读取。
- **源码模式鼠标光标偶发变白** — Windows 11 + WebView2 下系统 I 型指针会间歇丢失透明通道、整块变白；原生档改用应用自绘的细 I 型光标，亮色主题黑色、暗色主题浅灰，编辑器、实时模式、输入框与 AI 输入区同步生效。
- **原生控件未跟随应用明暗** — 亮色主题下不再出现深色的系统滚动条、表单控件或系统光标。
- **选中文字后点击选区内部无法退出** — 全选或部分选中时，点击已选文字不再被选区拦截，选区会收拢并把光标放到点击位置。
- **实时模式目录块样式不一致** — 实时模式的 `[toc]` 目录块现在与预览一样跟随目录边框 / 背景 / 圆角 / 内边距设置，自定义 CSS 在两种模式下表现一致。
- **阅读模式偶数页文档末页页码错位** — 双页模式的跨页对齐规则有误，导致末页出现「半页假跨页」、页码跑到中轴；已修正对齐规则，页码回到正确位置。
