# v0.4.3（开发中）

> 2026-11-06 起累积。五个版本文件已升至 `0.4.3`，处于开发阶段，尚未打包、未打 tag。

## 新增

- **云端文件树顶部导航**：改为常驻图标，依次为上级目录、根目录（WebDAV 根）、主目录（设置中的根目录）、新建文件夹、新建文件、一键展开、刷新。
- **移动文件 / 目录**：文件与文件夹的右键菜单、行尾「…」菜单新增移动入口，打开与「保存到云端」同款目录选择弹窗；不能移动到自身或其子目录。
- **展开 / 收折全部**：递归展开当前树根下的所有子/孙目录，失败目录就地显示错误，不影响其他分支；展开后按钮切换为「收折全部」并改为向上箭头，再点一次全部收起。

## 改进

- **点击文件夹不再跳转**：改为 Obsidian 式展开/收折，当前条目高亮显示。
- **新建位置跟随选中目录**：新建文件/文件夹在选中的文件夹内创建（选中文件时使用其父目录）；创建或移动后自动展开到目标目录。
- **宽度手柄提示**：在「按住拖动调整宽度」下方新增一行「双击还原默认宽度」。

## 修复

- **选中后点击选区内部无法退出**：全选或部分选中时，点击已选中的文字不再被选区覆盖层拦截，选区会收拢并把光标放到点击位置。实时模式的 `.cm-selectionLayer` 仍保持在正文之上，但改为 `pointer-events: none`，只负责绘制。
- **实时模式目录块不跟随 `--toc-*` 令牌**：预览用令牌、实时模式的 `[toc]` widget 却写死背景与边线。现在实时模式同样消费 `--toc-bg` / `--toc-border` / `--toc-radius` / `--toc-padding`，自定义 CSS 设 `--toc-bg: transparent; --toc-border: none;` 后两种模式一致。

## 目录块样式与开关

- **全局默认无边框无背景**：`[toc]` 目录块改为 `--toc-bg: transparent` / `--toc-border: none`，由预设主题各自声明边框与背景。
- **右上角显示开关**：预览与实时模式的目录块右上角新增 hover 显示的边框/背景开关，样式与代码块按钮一致；状态持久化，切换后两种模式同步，关闭时强制透明无边框。切换界面语言时 tooltip 会同步刷新。
- **目录条目装饰**：恢复无序列表的层级标记（实心圆 / 空心圆 / 方块），标记色跟随主题强调色，目录不再与普通正文混淆。
- **目录导出**：
  - HTML / PDF 与预览一致，保留无序列表装饰；边框/背景跟随目录右上角开关，静态导出隐藏不可用的开关按钮。
  - DOCX 使用 Word TOC 域与 TOC1–6 样式，不导出无序列表编号；开启目录边框/背景时用单格表格包裹（主题边框色 + 表面底色），关闭「导出主题色」或关闭目录开关时一律无边框、无背景。
