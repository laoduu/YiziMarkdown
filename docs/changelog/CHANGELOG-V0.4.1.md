# v0.4.1（2026-11-02）

> 版本日志随开发累积。本文件收录 2026-10-31 至 2026-11-02 的本轮改动。

## 新增

- **数学公式与 Mermaid 默认支持**：两者从可选插件提升为核心渲染器，不再需要到「设置 → 插件」开启；纯文本文档仍按需加载重模块。
- **插件系统 v2（内置插件）**：插件具备 manifest、版本/API 兼容检查、激活时机、权限与能力声明、导出能力和停用清理；当前版本只加载编译进应用的内置插件。
- **首个内置插件：EPUB 导出**：插件默认启用，可在插件页关闭；启用后工具栏导出菜单出现 EPUB，导出前打开控制面板，可选章节拆分、封面、可见目录、阅读主题与文档信息，导出 EPUB 3 电子书（保留公式/图表/图片）。
- **EPUB 多章与封面/目录**：支持按 H1/H2/自动拆分章节；生成标准文字封面页和阅读顺序中的可见目录页；EPUB 导航文档始终保留；跨章节锚点链接自动改写。
- **直接阅读 EPUB**：打开 `.epub` 直接进入阅读模式（EPUB 会先最大化窗口）；解析 EPUB 3 nav / EPUB 2 NCX 生成目录，读取内嵌封面图、图片、公式、Mermaid SVG、脚注和跨章节链接；统一使用应用阅读主题（忽略出版社 CSS），阅读位置按文件记忆。DRM 加密与固定版式 EPUB 暂不支持。
- **Word 原生目录域**：DOCX 导出不再把 `[toc]` 展开成静态列表，改为 `TOC \o "1-6" \h \z \u` 域和 `TOC1–TOC6` 样式；在 Word 中更新域即可得到带页码、可点击的真实目录，目录标题和提示跟随界面语言。

## 优化

- **Mermaid 跟随应用主题**：图表配色从当前主题的 bg/text/accent/surface/border/font 映射，亮色、暗色和自定义主题都同步；不再提供 Mermaid 官方 default/dark/forest/neutral 预设。
- **预览目录改造**：`[toc]` 改为真正嵌套的 `<ul>`，标题 id 在 core 阶段统一生成；保留细边框独立区块，去掉引用块式粗竖线，并修复主题链接样式导致的 hover 双下划线、空目录漏出 `[toc]`。实时模式 TOC 同步改为嵌套列表与同一套边框样式。
- **EPUB 打开窗口策略**：EPUB 在挂载阅读层前先最大化窗口，避免从文件对话框打开时全屏失败留下普通窗口、第一帧内容尺寸不对；退出阅读后还原打开前的窗口尺寸。
- **打开文件默认支持 EPUB**：文件对话框默认筛选加入 `.epub`，不再需要手动切换格式过滤器才能看到电子书。
- **鼠标光标默认原生**：普通箭头、编辑器 I-beam、编辑位置闪动光标默认都使用原生样式；只有选择「加粗（高可见度）」才启用主题色自绘箭头/I-beam 与块状插入光标。块状光标宽度由 `0.6ch` 收窄到 `0.45ch`，settings v16 会一次性把旧存档的光标默认迁移为原生。

## 修复

- **Mermaid 主题切换自动重渲染**：预览、并排预览、实时模式、演示模式在主题 CSS 注入完成或主题切换后都会重新取色，不会保留默认配色或旧的 SVG 颜色。
- **阅读模式 Mermaid 翻页变黑修复**：翻页复制页面时不再删除 SVG 内部 id，修复 Mermaid 的 ID 作用域样式失效后图形退回黑色的问题；阅读模式的 Mermaid 同时改用 SVG `<text>` 标签，EPUB 中已渲染的图表会在打开时按当前主题重新渲染。
- **整页图片 EPUB 分页修复**：图片块换页时不再提前移除节点，修复真实书籍分页抛出 `removeChild` 异常后显示「没有可阅读的内容」的问题。
- **阅读模式窗口状态修复**：进入阅读时若 HTML5 全屏未生效，会继续尝试原生全屏；两者都失败则还原进入前的最大化状态。非全屏阅读层增加顶部拖动条与最小化/最大化/全屏/退出阅读按钮（关闭只退出阅读，不关闭应用）；最大化/还原即时刷新状态，窗口尺寸变化做防抖后只重排一次，并显示排版进度。
- **最大化 → 全屏中间态修复**：最大化窗口优先使用原生全屏，不再先取消最大化再触发小尺寸重排；最大化/全屏切换期间冻结分页，状态落定后只按最终尺寸重排一次。
- **DOCX 结构合法性修复**：修正 `rPr`/`pPr` 子元素顺序、嵌套引用单元格结尾、重复脚注引用、表格/引用块间距等问题，降低 Word 365 打开报「发现无法读取的内容」的概率。
- **行号与正文对齐**：行号 gutter 元素补上与 `.cm-line` 相同的 2px 上内边距和行高，修复行号整体比正文高 2px 的问题。
- **演示模式长页进入时默认回到顶部**：长页离开后不再保留上次滚到的中段/底部；页内滚轮行为不变，仍然是先滚内容、触底后再翻页。
- **金句页只作用于 `>` 引用本身**：引用块之后的普通文案恢复正文规格，不再被 1.7em 放大，也不再被一对大引号包住；金句引用默认居中。
- **金句引号定位与 PPTX 导出一致**：演示与导出都按页面内真实的引号伪元素定位，不再假设「首块上引号、末块下引号」。
- **PPTX 自动压缩不再串页**：每一页从用户设置的基础字号开始测量，自动压缩只影响当前超页页，后续普通页不会被静默缩小。
- **PPTX 标题字号统一且不参与缩放**：正文页的 `##` 标题使用同一字号；封面、章节、致谢保留各自版式；标题不随字号旋钮或自动压缩变化。
- **PPTX 正文页标题位置固定**：内容、列表、表格、路线图、代码、图表、图片、公式、目录页的标题统一从内容区左上角起排；无标题的居中版式保持原样。
- **PPTX 超页检测更精确**：按最终场景节点的四边包围盒统计顶部、底部和左右溢出，修复居中版式顶部溢出被低估的问题。
- **标题 H1–H3 右移 6px**：去掉预览标题的 `padding/margin-left` hack，修复主题 margin 覆盖后 H1–H3 比 H4–H6 右移 6px 的问题。

## 其他

- **版本与发布状态**：`package.json` / `package-lock.json` / `Cargo.toml` / `Cargo.lock` / `tauri.conf.json` 已同步到 `0.4.1`，2026-11-02 发布。
- **EPUB 能力边界**：暂不支持 DRM / 加密 EPUB、固定版式 EPUB（漫画、画册），并统一忽略出版社 CSS。
- **Word 目录域**：首次打开 DOCX 时需要右键目录 → 更新域（或按 F9）生成页码；之后标题改动也用同一方式更新。
- **本轮未继续**：PPTX 溢出审计与 Word 独立版式规范不在本轮改动范围内，后续单独排期。
