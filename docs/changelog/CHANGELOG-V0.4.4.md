# v0.4.4

> 2026-11-14 更新（开发中）。本次更新累积自 2026-11-09。

## 新增

- **左侧边栏可调整宽度** — 文件 / 大纲 / 云端侧栏的右边缘新增拖拽手柄，按住即可调整宽度，松手后自动记住。
  - 默认宽度与旧版一致，仍为 260px；最小也是 260px，不会把顶部「文件 / 大纲 / 云端」标签挤变形。
  - 最大宽度取「600px」与「窗口宽度 40%」中的较小值，与右侧 AI 助手面板保持一致，窗口变窄时会自动跟着收窄。
- **演示模式统一为 1280×720 逻辑画布** — 不同分辨率、窗口宽高比与系统缩放下，幻灯片内部相对版式保持一致；非 16:9 窗口只留同色边，不再出现黑边。标题装饰线会跟随左 / 中 / 右对齐。
- **PPTX 导出字号与版式检测** — 导出弹窗可单独调整本次导出字号（70%–160%，默认继承演示设置）；新增「检测版式」按钮，只测量不写文件，先看舒适 / 可压缩 / 超出兼容上限页码，再决定是否导出。
- **PPTX 兼容性保障** — 页底预留一行余量，自动压缩最低到正文 14pt；降到下限仍放不下的页会明确列入「超出兼容上限」，不再无声压缩或溢出。
- **长代码行按栏宽折行** — PowerPoint 没有元素内滚动条，导出时长代码行改为按字符宽度自动折行（CJK / 宽字符单独计宽），避免右侧横向溢出。

## 修复

- **欢迎文档升级后仍显示旧内容** — 升级安装后，欢迎页会自动读取安装包内的新版本，不再沿用旧标签页里保存的旧正文。
- **手动检查更新误报「发现新版本」** — 清单版本与当前版本相同时改为显示「已是最新版本」；已跳过的版本也不会再反复提示。
- **Windows 程序运行位置显示异常** — 「设置 → 配置目录」里的程序运行位置不再带 `\\?\` 前缀，正常显示为 `D:\Program Files\YiziMarkdown` 这样的路径。
- **拖动 AI 助手宽度时滚动条错位** — 源码 / 实时模式下，拖动 AI 面板边框时编辑器右侧滚动条会跟随面板边缘移动，不再停在旧位置变成一根孤立的细条。
- **Linux 安装版显示开发版名称** — 用 deb 安装正式版后，任务栏 / 进程列表不再把应用识别为「YiziMarkdown (Dev)」，开发态与正式版各自使用独立的窗口类名。
- **Linux 文件关联点击无效** — 设置里的「设为默认 Markdown 编辑器 / EPUB 阅读器」现在真正生效：勾选即把本应用设为系统默认，取消即清除默认记录，状态与系统一致。
- **双击文档仍打开开发版** — 开发态图标条目不再注册文件类型；安装正式版后勾选「设为默认」，双击 `.md` / `.epub` 会启动安装版而不是 dev 版本。
- **阅读模式提示块退化成普通引用** — NOTE / TIP / IMPORTANT / WARNING / CAUTION 五类提示块在阅读模式下补齐类型图标与配色，标题保持直立，不再丢失样式。
- **导出弹窗不记住上次选择** — DOCX 的「主题色 / 字号行距跟随预览 / 字体跟随预览」与 EPUB 的「生成封面页 / 可见目录页 / 章节拆分 / 阅读主题 / 移除重复标题 / 语言」等勾选与下拉会记住，下次导出无需重新设置；书名、作者等文本仍按当前文档自动填充。PPTX 的备注 / 页脚 / 超页策略此前已持久化。
- **任务列表回车不续写** — 在 `- [ ]` 任务项后按回车会继续生成 `- [ ] `，不再退化成普通无序列表；缩进、有序编号与嵌套层级保持不变。
- **演示模式偶发黑边** — 舞台与画面改为同色，画布缩放跟随窗口尺寸实时更新，进入 / 退出全屏不再出现短暂黑边。
- **PPTX 导出页底溢出** — 按正文 / 代码 / 表格行高预留一行余量，PowerPoint 二次折行后不再轻易顶出页面；长代码行改为折行，不再靠缩到极小字号硬塞。
- **公式偶发显示为 `$...$` 源码** — KaTeX 加载完成前创建的 markdown-it 实例会在就绪后自动重建，公式不再被固化成源码。
- **幻灯片间距不一致** — 段落 / 代码块 / 表格 / 分隔线统一为 0.7u 单边距，单栏与分栏、flex 与普通块流下的间距保持一致。
