# v0.4.4

> 2026-11-12 更新（开发中）。本次更新累积自 2026-11-09。

## 新增

- **左侧边栏可调整宽度** — 文件 / 大纲 / 云端侧栏的右边缘新增拖拽手柄，按住即可调整宽度，松手后自动记住。
  - 默认宽度与旧版一致，仍为 260px；最小也是 260px，不会把顶部「文件 / 大纲 / 云端」标签挤变形。
  - 最大宽度取「600px」与「窗口宽度 40%」中的较小值，与右侧 AI 助手面板保持一致，窗口变窄时会自动跟着收窄。

## 修复

- **欢迎文档升级后仍显示旧内容** — 升级安装后，欢迎页会自动读取安装包内的新版本，不再沿用旧标签页里保存的旧正文。
- **手动检查更新误报「发现新版本」** — 清单版本与当前版本相同时改为显示「已是最新版本」；已跳过的版本也不会再反复提示。
- **Windows 程序运行位置显示异常** — 「设置 → 配置目录」里的程序运行位置不再带 `\\?\` 前缀，正常显示为 `D:\Program Files\YiziMarkdown` 这样的路径。
- **拖动 AI 助手宽度时滚动条错位** — 源码 / 实时模式下，拖动 AI 面板边框时编辑器右侧滚动条会跟随面板边缘移动，不再停在旧位置变成一根孤立的细条。
- **Linux 安装版显示开发版名称** — 用 deb 安装正式版后，任务栏 / 进程列表不再把应用识别为「YiziMarkdown (Dev)」，开发态与正式版各自使用独立的窗口类名。
