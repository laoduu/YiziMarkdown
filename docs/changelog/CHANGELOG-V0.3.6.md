# v0.3.6

## 新增功能

- **实时模式补齐一大批常用语法**：行内 HTML（上下标、下划线、高亮、键盘键、小字、引用等）、`<br>` 换行、行内图片、HTML 实体与转义、引用式图片与链接、注释、脚注（多行、多段）、有序与嵌套任务列表、围栏代码块直接编辑（带语言标签与复制按钮）、公式，以及表格单元格里的加粗 / 代码 / 公式等格式，都不用切回预览就能看到成品效果
- **实时模式表格可以像 Obsidian 一样操作**：鼠标拖选多个单元格；行首 / 列首出现手柄，点击选中整行 / 整列；表格边缘的 `+` 一键加行加列；右键菜单支持剪切 / 复制 / 粘贴、左中右对齐、插入行列、移动行列、按列排序、清空单元格、删除行 / 列 / 单元格
- **表格与 Excel / 网页表格互通**：选中后 `Ctrl+C` 按表格格式复制，可以直接粘进 Excel；从 Excel 或网页表格复制后 `Ctrl+V` 直接填回对应单元格
- **`[toc]` / `[[toc]]` 目录全场景可用**：预览、PDF、HTML 导出里是可点击跳转的目录；导出 Word 时变成按标题层级缩进的项目符号列表；演示模式下变成整册页面清单，点条目直接翻到对应页
- **设置新增「文档」分类**：帮助中心、演示语法、主题设计规范、技能规范四个官方文档一键打开
- **本地字体改为按需加载**：设置里点一次「加载本地字体」即可，结果会缓存在本机，下次打开设置不用再等；字体列表支持「显示更多」，不再一次性列出上千项
- **任务勾选更可靠**：按源码行精确回写，任务项里带公式、行内代码、HTML、嵌套列表，或者多条任务文案完全相同时，都能改对那一行；预览与实时模式都能直接点
- **有序列表多行连续编号**：选中多行点「有序列表」，得到 1、2、3 连续编号，跳过空行、保留缩进；重复点击会整体重排，不会叠出多层编号

## 优化

- **大纲点击即时高亮**：点哪一节就亮哪一节，不用点两次；之后正常滚动时高亮仍会跟随阅读位置
- **预览「行高」设置真正生效**：段落与任务列表项都按设置的预览行高显示
- **演示模式的任务列表与预览一致**：不再多出一个项目符号，嵌套任务列表也不会挤在勾选框旁边
- **行内图片与文字排在同一行**：`文字 ![](图) 文字` 不再被强制断成三行；只有图片独占一段时才按块级排版，所有主题下表现一致
- **表格里的长代码、长链接不再撑宽表格**：单元格内的长内容自动折行
- **表格改写后不跳回顶部**：删除行、粘贴、排序等操作完成后，阅读位置保持不动，长文档里不用重新找位置
- **导出 Word 的 Mermaid 图保留文字**：图形线条与节点文字都完整，不再出现「有框无字」

## Bug 修复

- **演示模式任务列表多出一个圆点**，嵌套任务列表挤在同一行
- **打开「编辑器设置」会卡住**：系统字体枚举与上千个字体按钮的渲染都改掉了，进入设置不再停顿
- **大纲里混进假标题**：代码块里的 `# 注释`、文档开头的元信息、HTML 注释、缩进代码行不再出现在大纲里，重复标题的跳转也不会再错位
- **拖动选择表格单元格时行底色「慢一拍」**：鼠标所在行的悬浮色不再盖住选中色，拖到哪一行哪一行立即变色
- **图片加载失败时撑高行距、顶开表格列宽**：现在改为显示图片说明文字（没有说明时显示「图片加载失败」），版面保持稳定
- **导出 Word 后 Mermaid 图只有框、没有文字**
- **勾选任务后源码没变或改错行**
- **工具栏「有序列表」让所有行都显示 `1.`**：源码模式里现在能看到真正的连续编号

## 其他
