# v0.3.4

## 新增功能

### 脚注（学术引用）

- 正文写 `[^1]`、文末写 `[^1]: 文献条目`，预览 / 演示 / 导出 HTML 都会渲染成**上标编号 + 文末参考文献**，两边点击可互相跳转
- 工具栏与斜杠菜单都有「脚注」入口：插入后光标**直接落在文末定义行尾**，可以马上写文献条目
- 预览里**鼠标悬停上标即可看到对应文献**，不必跳转
- 实时模式同样渲染上标与定义行，三种模式的字号与行距统一

### 演示模式：分栏区间

- 想在一页里写「引言 + 并排两块 + 落款」时，用**单独成行的 `***`** 圈出栏区——**N 栏写 N+1 条**
  ```
  引言
  ***
  左栏
  ***
  右栏
  ***
  落款
  ```
- 首尾两条 `***` 圈住栏区，栏区之外就是页级文案；`***` 同时充当外框与内线（像表格的 `|`）
- 工具栏与斜杠菜单的「分栏区间」按钮会**一次插入三条**并把光标放在左栏，填完左栏、下面那个空档自然就是右栏
- 只写 1~2 条时仍是旧语义（`***` = 分隔线），**存量文档不受影响**

### 演示模式：栏内对齐与分栏样式

- HUD「演示排版」新增两个旋钮：**栏内对齐**（左 / 中 / 右）与**分栏样式**（卡片 / 分隔线 / 无）
- **分栏样式默认「卡片」**：每栏一张等高的主题卡片，明暗与主题自动跟随
- 对齐只管栏内，**页标题不参与**——它仍是页面层级，继续跟所属版式走

### 演示模式：提词备注

- 原「演讲者备注」改名「**提词备注**」：它是**与幻灯片同屏**的，观众看得到，名字不该暗示有副屏
- 面板默认**收在屏幕左缘之外**：鼠标移到左缘即展开，按 `S` 锁定常显，再按 `S` 或 `Esc` 收回
- 按 `S` 而当前页没有备注时，左下角提示「本页无备注」——以前按 `S` 毫无反应，很像功能并不存在

### 编辑体验

- **右键菜单**：全应用自定义右键菜单。侧栏文件 / 云端可新建文件、新建文件夹、重命名、在资源管理器中显示、删除（**移入回收站**）；文件 tab 可关闭 / 关闭其他 / 关闭右侧 / 关闭全部；顶栏可最小化 / 最大化 / 全屏 / 关闭
- **上标按钮**：工具栏新增，选中文字可直接变成上标
- **行内 HTML**：实时模式现在会渲染 `<sup>` `<mark>` `<kbd>` `<u>` 等行内标签

## 优化

- **演示：图片**默认居中；高度上限改为**内容区高度的 78%**，图片不再把同页文字顶出画面
- **格式工具栏收折**重做：修掉「手动收折后，放大窗口会被自动展开顶回」；阈值改为 1320px（放得下才展开）；收折有了完整动画；窗口很窄时品牌名自动缩为 `YiziMD`
- **代码块**悬浮控件改为 Typora 风格：悬停右上角出现「换行 / 复制」
- **公式菜单**改为悬停打开，与代码块 / 表格一致
- **云端**：「保存到云端」对话框记住上次保存目录；云端目录树的行结构与本地一致（点三角就地展开、点名称进目录）
- **全屏**：修掉「最大化状态下进全屏是假全屏」；退出全屏会恢复进入前的最大化状态；右上角新增全屏按钮；新增 `F11` 快捷键
- **多开大文档时输入不再变卡**：以前每敲一个字符都要把所有打开的文档整体重存一遍，打开的文档越多越大越滞涩；现在只重存真正变化的那一篇
- 缓存被清理过时重启，个别标签页会先显示「**正在恢复内容…**」再从磁盘读回——这是缓存不足后的正常表现，不是内容丢失

## Bug 修复

- 演示：**在正文里「提到」指令会被真的执行**——正文、代码围栏、行内代码、表格单元格四种上下文全中，而且是静默的（内容变少、版式变错，没有报错）。现在指令必须独占一行
- 演示：图文页右侧多段文字**叠印**在一起
- 演示：图片把同页文字顶出画面
- 实时模式：插入图片后不渲染；现在插入即成块并立即渲染，本地图片路径也会被正确解析
- 实时模式：点击定位错位一行（脚注区引入后再次出现，已定位到根因）
- 实时模式：行内 `[^1]` 引用与定义行不渲染
- 代码块 / 公式 / 表格菜单「点不开」（hover 与点击都没有反应）
- 格式工具栏收折时没有动画；收折时按钮压缩不均匀
- 双击顶栏空白切换最大化从未生效
- 脚注悬浮预览窗口弹出后不关闭
- **本地缓存写满后保存会静默停止**：还能继续打字，重启后未保存的内容没了，界面上毫无提示。现在会优先让出「磁盘上已有文件」的缓存来腾空间，并在状态栏常驻警示 + 弹一次提示；连未保存的内容都放不下时会明确提示你**立即保存**
