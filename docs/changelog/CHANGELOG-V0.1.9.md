# v0.1.9

## 新增功能

### 演示模式（幻灯片）

将任意 Markdown 文档按 `---` 分页渲染成**应用内全屏幻灯片**，模拟 PPT 播放。参考 solomd 演讲模式的分页思路，围绕 Yizimarkdown 自身产品风格自研轻量引擎（零新增依赖）。

- **进入演示**：工具栏「放映」、标签栏「演示」、快捷键 `Ctrl+Alt+P` 三种方式
- **分页语法**：`---`（单独成行）分页，代码围栏内不切分，front matter 自动忽略
- **纯 Markdown 驱动**：不需要任何额外格式，引擎根据内容结构自动选择版式，用户零学习成本
- **6 种自动版式**：封面（`#` 标题开头）、内容（`##`/段落/列表/表格）、图片、引用、代码、图表（mermaid）
- **居中排版**：块居中、文字居中，列表和引用保持左对齐；标题一律居中，h1/h2/h3 仅字号递减
- **封面强调**：一级标题开头的页面自动放大标题 + 主题色渐变下划线
- **标题位置稳定**：内容页采用固定顶边距对齐，翻页时标题不再上下跳动
- **大气引用页**：大引号（6em，50% 透明度）+ 居中大字 + 左对齐
- **跨平台全屏**：HTML5 Fullscreen 优先 + Tauri window API 降级；最大化窗口可靠进入
- **主题继承**：进入继承当前主题/明暗，演示内可切换；15 个主题标题颜色精确继承
- **播放交互**：`→/←` 翻页、`F` 全屏、`S` 备注、`?` 帮助、`Esc` 退出、页码 HUD
- **示例与文档**：演示模板 `templates/Slide-Template.md`（纯 Markdown）、`help.md` 幻灯片语法章节

### 模板功能完善

- **「从模板新建」入口**：工具栏「新建」右侧新增「从模板新建」下拉菜单（类导出格式菜单），选择模板即按该模板的 Markdown 结构创建新文档
- **修复默认模板 bug**：此前在设置中设定默认模板后，新建文档只会把模板**文件名**当作内容加载。现改为正确读取模板内容作为新文档结构
- **模板管理**：设置 → 模板 可新建、编辑、删除模板；设置 → 通用 可设默认模板

## Bug 修复

- **`tauri dev` 启动崩溃（EBUSY）** — Vite 监听 cargo 写入中的 `src-tauri/target` 目录触发文件锁冲突，`server.watch.ignored` 排除 src-tauri
- **幻灯片列表不渲染** — Tailwind preflight 重置 `list-style`，显式还原 `ul/ol` 列表符号
- **`Esc` 退出不彻底** — 操作系统截获 Esc 退出全屏时收不到按键，新增全屏状态丢失检测，退出后恢复打开前视图
- **切换主题文字色不跟随** — 主题元素级规则作用域为 `.editor-content`，注入时改写为幻灯片作用域
- **荔枝红 / 紫罗兰 H1/H2 字号不对** — 未加作用域的 `.theme-x h1` 泄漏进幻灯片，改为仅注入 `:root.theme-*` 变量
- **无序/有序列表内容宽度不一致** — 统一用 CSS 计数器 + `::before` 自定义标记
- **最大化窗口进入全屏底部黑条** — 先 `unmaximize` 再 HTML5 Fullscreen
- **F 键全屏切换失灵** — Tauri `set_fullscreen(false)` 在 borderless 窗口静默失败，改用 HTML5 Fullscreen API
