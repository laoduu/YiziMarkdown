# v0.4.2（2026-11-04，未打包）

> 2026-11-03 起累积，2026-11-04 补齐提示块自定义标题、工具栏菜单与 Word 图标，并完成 AI 助手「获取模型」与供应商鉴权修复。本版合并社区 PR #7（Word 版式与上下标/高亮），并完成其后续修复。
> 五个版本文件已升到 `0.4.2`，尚未打包、未打 tag。

## 新增

- **行内语法**：`^上标^`、`~下标~`、`==高亮==`。预览、实时模式与导出的 DOCX 使用同一套语义；工具栏新增上标 / 下标 / 高亮三个按钮。
- **GitHub 风格提示块**：引用块首行写 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]`，预览、演示模式与 DOCX 均生效。`[!类型]` 后同一行的文字作为自定义标题，例如 `> [!TIP] 小技巧`。
- **提示块工具栏菜单**：引用按钮右侧新增提示块按钮，hover 列出 Note / Tip / Important / Warning / Caution，点击插入对应模板并自动填入跟随界面语言的默认标题；15 种语言补齐相关文案。
- **提示块 DOCX 图标**：导出时同步渲染类型图标与彩色标题，内嵌 octicon SVG 矢量 + PNG 回退，旧版 Word / WPS 也能显示。
- **DOCX 导出弹窗**：导出前可选择「导出主题色」「字号行距跟随预览」与「字体跟随预览」；关闭主题色时标题、表头、代码高亮走黑白灰，关闭字号跟随时使用规范版式（A4 / 11pt / 1.5 倍行距），关闭字体跟随时使用 Word 经典默认字体（正文 Calibri / 等线，标题 Calibri Light / 等线 Light）。
- **Word 目录域**：目录条目使用 `_Toc000000001` 形式书签，并提供 TOC1–TOC6 样式。
- **界面设置与界面字号**：「设置 → 通用 → 界面语言」改为「界面设置」，新增界面字号 80%–120%（步进 5%，默认 100%）。用户 100% 以当前推荐观感为基准（实际倍率 1.1），只缩放界面文字与图标；面板尺寸、工具栏布局和文档编辑 / 预览内容不受影响。常规 UI 字号收口为 11 / 12 / 13 / 14px 四档，品牌字 15px、快捷键大标题 18px 为特例。
- **设置面板布局**：左右两列改为 1:1；左侧分类栏从 180px 加宽到 260px，避免长语言菜单项换行。
- **分类更名**：设置分类「AI」更名为「AI 助手」，15 种语言同步。
- **EPUB 默认阅读器**：「设置 → 通用 → 文件关联」新增「设为默认 EPUB 电子书阅读器」，与 Markdown 编辑器关联互相独立；Windows 写注册表，macOS 使用 `org.idpf.epub-container` UTI。
- **DOCX 标题 / 正文字体分离**：标题可单独使用 Light 字族（Calibri Light / 等线 Light），正文使用 Calibri / 等线；`fontTable.xml` 为标题字体补充苹方 / 微软雅黑 / Helvetica Neue 替代链，兼容 Windows 与 macOS。
- **AI 获取模型**：设置 → AI 助手「模型 ID」右侧新增「获取模型」，自动拉取当前供应商的模型列表并下拉选择，选中后自动填入并保存。OpenAI 兼容端点读取 `{base}/models`（Base URL 不以 `/v1` 结尾时回退 `{base}/v1/models`），Anthropic 读取 `{base}/v1/models`，Ollama 读取 `{base}/api/tags`；15 种语言同步新增文案。
- **代码块换行持久化**：代码块右上角「切换换行」改为全局偏好，写入设置存档；切换文档、刷新或重启后保持上次选择。预览 / 实时 / 阅读模式共用根类控制，默认横向滚动。
- **演示模板合并**：删除旧 `Slide-Template.md`，新版 `Slide-Template-new.md` 改名为 `Slide-Template.md`，只保留一份。内置模板同步改为「同名覆盖」：版本或模板内容（树指纹）变化时覆盖用户目录同名文件，用户自建的其他模板不受影响；旧 `Slide-Template-new.md` 自动清理。模板同时修正了 Mermaid/KaTeX 插件说明、`align` 取值、页级 `fragments: on` 与 front matter 默认值；封面后新增「请先复制，再修改」提示页，模板共 37 页。
- **EPUB 公式与图表**：阅读清洗保留 KaTeX 内联排版样式，修复公式黑块/错位；Mermaid 按当前阅读主题重渲染，避免浅色阅读页出现深色图表；保留 `.mermaid` 外层 `data-source`，确保带预渲染 SVG 的图表也能重渲染；公式容器取消首行缩进并支持横向滚动。
- **主题六级标题**：统一 H1–H6 字号（2.0 / 1.5 / 1.3 / 1.2 / 1.1 / 1.0em），H6 与正文同字号但通过字重、颜色、字距保持标题感。全部 16 个预设主题补齐 H4–H6 元素规则与 `--editor-h4/h5/h6` 颜色令牌，按「H1 品牌色 → 正文色」重建六级色阶。
- **[toc] 目录令牌化**：正文目录块的背景、边线、圆角与间距改为 `--toc-bg` / `--toc-border` / `--toc-radius` / `--toc-padding` / `--toc-margin`；16 个预设主题均声明 `--toc-bg` 与 `--toc-border`。自定义 CSS 设为 `--toc-bg: transparent; --toc-border: none;` 即可取消背景与边线。

## 优化

- 正文目录改为嵌套 `<ul>`，跳级标题自动挂到最近的上级；目录块保留 Typora 式细边框。
- 标题 id 改为单一来源（解析阶段写入 `heading_open` 属性），预览目录与正文锚点不再各算一遍。
- 标题高亮改用 `box-shadow` 外扩，修正主题 `margin` 简写导致的 H1–H3 / H4–H6 缩进错位。
- 行内标记规则在预览与 Rust 侧统一：`^` ≤32 字符、`~` ≤8 字符，并禁止标点、括号与 Markdown 标记字符。
- 格式工具栏中带下拉菜单的图标（代码、表格、公式、提示块）统一使用主题色，hover 状态不再出现颜色不一致。
- 工具栏所有下拉菜单（导出、模板、代码、公式、提示块）改为内容自适应宽度并限制在 20rem；长语言标签自动换行，类型图标固定尺寸、不再被长文本挤没。
- UI 字体栈改为 `system-ui / Segoe UI / Microsoft YaHei UI / PingFang SC` 优先，并移除全局 `antialiased`，Windows 下文字更清晰。
- 阅读 / 演示模式的抽屉目录改用界面字号体系与 `--font-ui`，不再写死 11/13/14px。
- **六级标题视觉**：`magazine` 保留衬线标题与斜体/大写；`nature` 保留衬线标题并统一 H3–H6 字重；`typewriter` / `cyberpunk` H1–H6 统一大写与字距；`matrix` / `sunset` 暗色 H4–H6 增加分层发光；`minimal` H3–H6 统一 600 字重；`facebook` / `typewriter` 使用紧凑字号与间距。
- **标题色令牌**：预览、阅读模式与演示模式统一消费 `--h1-color … --h6-color`，`--editor-h2/h3` 不再是只被幻灯片消费的假旋钮。

## 修复

- `64K~512K、0~20、1~5` 这类数字区间不再跨区间配对，中间文字不会被整段吞成下标。
- `^` 不再把 `[^1]` 脚注引用卷进上标，脚注引用与编号保持完整。
- `==**加粗** 与 *斜体*==` 在预览中同样保留高亮内的粗体与斜体，与 Word 导出一致。
- 导出含目录的 DOCX 时，成功提示补充「右键目录 → 更新域（F9）」，停留 6 秒。
- 提示块类型与标题之间没有空格时（如 `> [!IMPORTANT]重要提醒`），DOCX 预处理不再漏识别并导出为普通引用源码；现在与预览 / 实时模式一致。
- 提示块自定义标题的 base64 占位注释只在 DOCX 预处理阶段生成，不污染预览、实时模式与源文档。
- **AI 供应商默认地址**：Rust `default_base_url` 补齐 LongCat 与 MiMo，避免 Base URL 留空时静默回退到 OpenAI 端点并返回 401；其余供应商逐一核对无缺失。
- **MiMo 鉴权**：模型列表、聊天与密钥验证统一发送 `api-key` 请求头，同时保留 `Authorization: Bearer`。
- **LongCat 模型列表**：兼容 `/openai/models` 与 `/openai/v1/models` 两种路径。
- **未填写密钥提示**：输入框为空且系统钥匙串无该供应商密钥时，「获取模型」直接提示补填 API Key，不再误报「未获取到模型」。
- **H4–H6 标题过小/无层级**：此前 H4 继承正文 `1em`，H5/H6 退回浏览器默认 `.83/.67em`，且主题只定义 H1–H3；现已补齐六级字号、字重、间距与颜色，H6 不再小于正文。
- **DOCX / PPTX 中 Mermaid 连线丢失**：Mermaid 连线描边依赖 SVG `<style>` 类选择器，WPS、LibreOffice、旧版 Word 等不执行该 CSS 时只剩节点和箭头。导出前将计算样式固化为内联 `style`，并把实线的 `stroke-dasharray: 0` 改为显式 `none`（部分渲染器会把零长度虚线当成整线不可见）；连线在忽略 `<style>` 的阅读器中也完整显示。

- 术语沿用「提示块」，正式描述为 GitHub 风格提示块（alert）；通用组件领域也叫 callout / admonition。
- 新语法与提示块补入 `help.md`、官网帮助中心的语法速查与版本日志。
- AI 助手「获取模型」说明补入 `help.md` 与官网帮助中心；部分供应商不提供模型列表接口时仍需手动填写模型 ID。
- 主题规范补入六级标题令牌、颜色阶梯、主题模板与检查清单；`check-themes.mjs` 扩展为八项检查（新增标题六阶完整性与对比度）。
- 主题规范的主题元数据章节改为 `builtin.json` / `themes.user.json`，并补充 `custom/` 与 `overrides/` 的用户层说明。
