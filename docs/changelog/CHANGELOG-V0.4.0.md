# v0.4.0

## 新功能

- **演示模式一键导出 PPTX（原生可编辑）**：工具栏导出菜单与演示 HUD 两处入口，共用同一个导出弹窗
  - 继承演示的**主题 / 明暗 / 版式 / 演示字号 / 填充比例 / 分栏样式**，暗色主题所见即所得，不强制白底
  - 输出**原生对象**：文本（含加粗、颜色、行距）、表格、图片、形状、手绘列表圆点与序号、图表位图；不是整页截图
  - **公式走原生 OMML**，在 PowerPoint 里可直接编辑；老旧播放器（WPS / 旧版 Office）自动回退为 TeX 纯文本
  - **Mermaid 图表**与 DOCX 导出同源：重新渲染为纯文本标签 SVG，再栅格化嵌入，避免 `foreignObject` 丢字
  - **演讲者备注**（`<!-- notes: … -->`）与**页脚**（章节名 + 页码）默认导出
  - **超页处理**：默认「警告并列出页码」，也可选「自动压缩字号」（逐档缩放 100%→60%，浏览器真实重排，不是拉伸图片）
  - **告警按当前界面语言显示**：超页、公式回退、图片/图表失败等告警在弹窗里本地化，点页码可直接跳到演示对应页
  - 导出基准固定 **16:9 / 1280×720**，与当前窗口大小无关；先选保存路径再生成本地文件，带进度显示并可随时中止

## Bug 修复

- **实时模式列表只切换被点的那一行**：任务列表、无序列表、有序任务列表点某一行时，只有该行显示 `- [ ]` 等源码，同一列表的其它行仍保持圆点和勾选框；此前是点一行导致整个列表变源码
- **多级嵌套列表里中文输入法恢复正常**：有序 / 无序 / 任务列表层层嵌套时，微软拼音等输入法的候选词可以正常上屏，不再出现拼音字母变成普通英文（如 `nihao`）的情况
- **实时模式的表格右键菜单会跟随界面语言**：剪切 / 复制 / 粘贴、左中右对齐、插入 / 移动行列、按列排序、清空单元格、删除行列与单元格等 25 项文案，不再固定显示中文
- **表格边缘的交互提示也已翻译**：行首 / 列首手柄的「选择整行 / 选择整列」，以及表格边缘「+」的「添加行 / 添加列」
- **实时模式代码块与目录提示**：「切换换行 / 复制代码 / 复制失败」按钮、`[toc]` 空状态「当前文档没有标题」会使用当前界面语言
- **预览模式两处文案**：代码块悬浮按钮标题、图片加载失败时的占位文字
- 上述 30 条文案已补齐 15 种语言（简体中文、繁体中文、英、日、韩、德、法、西、葡、意、波、荷、瑞、土、乌）
- **PPTX 里的公式不再空白**：原生公式的兼容信封改到形状层（与 PowerPoint 自身写法一致）；OMML 转换失败或为空时回退为 `$TeX$` 纯文本，不会再生成一块空公式

## 说明

- 导出只覆盖演示模式已有的 Markdown 语法，**不新增任何标记**
- 动画、页面切换、片段分步、HUD 与进度条不进入 PPTX（只导出最终全显状态）
- 每页按「独立可编辑文本框」排布，编辑时整块文字仍可整体改字体/字号；不拆成逐字符对象
