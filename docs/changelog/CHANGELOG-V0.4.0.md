# v0.4.0

## 新功能

- **演示模式一键导出 PPTX（原生可编辑）**：工具栏导出菜单与演示 HUD 两处入口，共用同一个导出弹窗
  - 继承演示的**主题 / 明暗 / 版式 / 演示字号 / 填充比例 / 分栏样式**，暗色主题所见即所得，不强制白底
  - 输出**原生对象**：文本（含加粗、颜色、行距）、表格、图片、形状、手绘列表圆点与序号、图表位图；不是整页截图
  - **公式走原生 OMML**，在 PowerPoint 里可直接编辑；老旧播放器（WPS / 旧版 Office）自动回退为 TeX 纯文本
  - **Mermaid 图表**与 DOCX 导出同源：重新渲染为纯文本标签 SVG，再栅格化嵌入，避免 `foreignObject` 丢字
  - **演讲者备注**（`<!-- notes: … -->`）与**页脚**（章节名 + 页码）默认导出
  - **超页处理**：默认「警告并列出页码」，也可选「自动压缩字号」（逐档缩放 100%→60%，浏览器真实重排，不是拉伸图片）
  - **告警按当前界面语言显示**：超页、公式回退、图片/图表失败等告警在弹窗里本地化，点页码可直接跳到演示对应页
  - 导出基准固定 **16:9 / 1280×720**，与当前窗口大小无关；先选保存路径再生成本地文件，带进度显示并可随时中止
- **安装向导可自选语言，装完就用它**：全新安装时先选界面语言（16 种），向导本身与装好后第一次启动的 YiziMarkdown 都会用这个语言；升级 / 自动更新不会改动你已选的语言
- **安装向导品牌化**：安装包图标、欢迎页侧栏图与各页页眉图换成应用自己的图标与配色
- **macOS 与便携版也会提示新版本**：这两类版本不会自动安装，但启动时会检查版本清单，发现新版就在右下角弹出一张不打断工作的提示卡。点「去下载」直接打开该版本的发布页，手动下载替换即可；「稍后」只在本次运行里不再提示，「跳过此版本」以后都不再提示它。Windows 安装版仍然是一键更新

## 主题与设置

- **主题改动能跨版本保留**：内置主题改为只读、随包升级，你自己的东西放进用户目录 `~/Documents/yizimarkdown/themes/`——改过的主题名与覆盖的内置主题在 `overrides/`，自建主题在 `custom/`，安装器不再碰它。内置主题本身更新时，卡片会显示「新版」让你二选一（保留我的 / 用内置新版），**绝不静默覆盖**
- **从旧版本升级会自动迁移**：首次启动把旧安装目录里改过的主题、`user.css`、`keybindings.json` 搬到用户目录，只迁移一次，之后的升级不再重复导入
- **主题卡改成「迷你编辑器窗格」**：每张卡都用该主题的真实配色渲染侧栏、标题、正文与状态栏，一眼看出主题长什么样；卡上的日 / 月按钮只预览**这张卡**的明暗，不会切换全局主题，点卡片其他区域才激活。外观面板同步放大，1280 宽屏正好三列
- **编辑器设置底部预览所见即所得**：左栏按源码侧的字体 / 字号 / 行距 / 行号 / 换行渲染真实 Markdown 源码，右栏按预览侧设定渲染正文示例
- **实时模式四种动画的预览与真实效果逐帧一致**：预览和实际编辑共用同一套动画参数，不再「点着都差不多」

## Bug 修复

- **导出 PPTX 的默认文件名会用文档标题**：与 Word / HTML / PDF 导出同一套规则——已保存文件沿用原文件名，未保存则取 front matter 的 `title` 或正文第一个标题行，不再固定叫「未命名新文件」
- **全屏与窗口状态整治**：全屏进入 / 退出统一走单一状态源，修复一组窗口状态错乱问题
  - 全屏状态下**拖动标题栏不再把窗口拖走**：此前全屏窗口会被整体拖出屏幕外，退出全屏才恢复；现在全屏中拖动被禁用
  - 全屏状态下**双击标题栏空白处不再触发最大化**，右键菜单也不再提供「最大化」项（此前会把窗口变成带底部黑带的错乱几何）
  - **最大化后再进全屏、退出时能正确回到最大化**：此前退出后窗口退化成普通大小
  - 全屏时**隐藏「最大化」按钮位**：它与全屏按钮的退出图标完全相同，并排两个一样图标没有意义；退出全屏统一由全屏按钮承担
  - 全屏按钮的图标 / 提示与实际状态保持一致
- **窗口按钮不再残留键盘焦点框**：点击窗口按钮后按 Esc（如退出全屏），按钮上不再出现绿色焦点框；键盘导航的焦点样式不受影响
- **滚动条悬停时光标恢复正常形状**：源码 / 实时模式下 hover 纵向滚动条时光标不再保持文本输入的 I-beam
- **窄窗口下滚动条不再被宽度手柄挡住**：正文列贴到面板边缘时，「拖动调整宽度」的命中区会让开滚动条，滚动条可以正常点击拖动
- **实时模式列表只切换被点的那一行**：任务列表、无序列表、有序任务列表点某一行时，只有该行显示 `- [ ]` 等源码，同一列表的其它行仍保持圆点和勾选框；此前是点一行导致整个列表变源码
- **多级嵌套列表里中文输入法恢复正常**：有序 / 无序 / 任务列表层层嵌套时，微软拼音等输入法的候选词可以正常上屏，不再出现拼音字母变成普通英文（如 `nihao`）的情况
- **实时模式的表格右键菜单会跟随界面语言**：剪切 / 复制 / 粘贴、左中右对齐、插入 / 移动行列、按列排序、清空单元格、删除行列与单元格等 25 项文案，不再固定显示中文
- **表格边缘的交互提示也已翻译**：行首 / 列首手柄的「选择整行 / 选择整列」，以及表格边缘「+」的「添加行 / 添加列」
- **实时模式代码块与目录提示**：「切换换行 / 复制代码 / 复制失败」按钮、`[toc]` 空状态「当前文档没有标题」会使用当前界面语言
- **预览模式两处文案**：代码块悬浮按钮标题、图片加载失败时的占位文字
- 上述 30 条文案已补齐 15 种语言（简体中文、繁体中文、英、日、韩、德、法、西、葡、意、波、荷、瑞、土、乌）
- **PPTX 里的公式不再空白**：原生公式的兼容信封改到形状层（与 PowerPoint 自身写法一致）；OMML 转换失败或为空时回退为 `$TeX$` 纯文本，不会再生成一块空公式

## 说明

- 导出只覆盖演示模式已有的 Markdown 语法，**不新增任何标记**
- 动画、页面切换、片段分步、HUD 与进度条不进入 PPTX（只导出最终全显状态）
- 每页按「独立可编辑文本框」排布，编辑时整块文字仍可整体改字体/字号；不拆成逐字符对象
