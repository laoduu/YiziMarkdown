# v0.4.5

> 2026-11-15 更新。本次更新主要修复 Linux 文件关联。

## 修复

- **Linux 双击 Markdown / 右键「用 YiziMarkdown 打开」只启动应用、不打开文件** — 安装包的桌面条目只写了启动命令，没有把选中的文件传给应用，文件管理器因此把路径丢掉了。现在 deb 与 AppImage 的桌面条目都会附带文件参数，双击和右键打开都会直接载入对应文档。
- **文件路径兼容 `file://` 形式** — 部分桌面环境或启动器会传 `file:///home/...` 形式的地址；现在会自动还原为本地路径，中文、空格与百分号编码的路径都能正确打开。
- **第二个实例打开文件** — 应用已在运行时再次双击文档，会复用现有窗口并打开文件，不再只把窗口切到前台。

> 升级后如果文件关联仍未生效，请在「设置 → 通用 → 文件关联」里关闭再重新打开一次。
