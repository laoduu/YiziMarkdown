# v0.4.5

> 2026-11-21 更新。本次更新累积自 2026-11-15 的 Linux 文件关联修复。

本版本以**文档内 AI**为核心 —— 划词改写、光标处创作与会话历史，产出直接写回文档；同时新增**划词格式条**与**实时模式表格键盘导航**，补全**格式开关**与**技能直通正文**，并把设置里的下拉菜单统一到主题。另修复一批编辑正确性与 PPTX 导出排版问题；首轮 Linux 包里的文件关联修复也随三平台版本一同发布。

## 新增

- **文档内 AI（本次核心）** — 划词后在正文里直接让 AI 改写，产出直接写回文档，不再需要「右侧对话 → 复制 → 粘贴」。工具条与格式条的切换移到浮栏最右端，最左侧的星芒就是入口。
    - **划词改写** — 选中文字点星芒，在选区旁输入指令：结果可替换选区、插入到下方、复制或放弃；「对比原文」在正文里就地显示红删绿增的 diff；可附「当前小节 / 整篇文档」作语境；「补充需求」可多轮打磨，写入后浮层自动关闭，可用 Ctrl+Z 或顶部工具栏撤销。润色、扩写、缩写、翻译、纠错、转列表等快捷意图按选区内容自动给出。
    - **光标处创作** — `双击 Ctrl` 或点顶部工具栏星芒，可在光标处让 AI 直接写一段：结果可插入光标或复制。与划词改写共用同一浮层，提示词自动切换为写作模式；快捷键可在「设置 → 快捷键」里改为 Ctrl+Enter 或关闭。
    - **AI 会话历史** — 每次生成（改写 / 创作 / 技能直通）按文档留档：浮层底部右侧的历史图标向下展开，左侧列表、右侧详情，可查看完整结果并「插入 / 复制 / 删除」。未命名文档先按标签页记，保存后自动跟随文件；云端文档按云端路径记。历史存在本地、与内容无关 —— 文档在别处被改过也不会丢，插入时按原文在正文里搜索定位，找不到就落到光标处并提示。单文档保留 50 条、90 天自动过期。
- **划词格式条** — 划词浮栏最右端的 ⇄ 按钮可在「工具条」与「格式条」之间切换，选择会记住。格式条提供加粗、斜体、删除线、高亮、行内代码（含代码块）、上标 / 下标、标题（H1–H3）、无序 / 有序 / 任务列表、引用与公式（行内 / 块）；带二级选项的图标 hover 展开。设置 → 划词助手 中可排序、显示或隐藏单个格式，链接默认隐藏。
    - **按选区显示已应用状态** — 选中文字时格式条会标出当前已生效的格式：加粗过的文字 B 为高亮态、列表行为列表图标高亮、标题行为 H 高亮，等等（含行内代码、上下标、引用、公式、链接）；点一次应用、再点一次取消，状态随正文即时更新。判定完全读取正文，撤销或手动改标记后同样准确。
- **实时模式表格键盘导航** — `Tab` / `Shift+Tab` 左右跳格（行末换到下一行，最后一格自动新增一行），`Enter` 跳到同列下一行（最后一行自动新增一行），`↑` / `↓` 切换上下单元格，`←` / `→` 在单元格文本首尾时切换左右单元格。
- **格式开关：再点一次即取消** — 正文与表格中的加粗、斜体、删除线、行内代码、高亮、上下标：已应用时再点一次即取消，不再叠加出 `****`；对加粗文字点斜体会得到 `***文字***`，不会误拆原有格式。
    - **标题 / 列表 / 引用切换** — 标题同级再点取消、换级直接替换；无序列表、有序列表、任务列表与引用支持再次点击取消；列表类型之间可直接互转。
- **技能直通正文** — 技能可设置 `delivery: "inline"`：划词浮栏里点击该技能会直接打开文档内 AI 并执行技能提示词，结果可替换选区 / 插入到下方；默认的 `chat` 仍送进右侧 AI 助手对话。

## 优化

- **文档内 AI 浮层交互** — 围绕「打开就能写、写完不挡正文」打磨浮层。
    - **打开即聚焦** — 顶部星芒或快捷键打开浮层时，输入框直接可打字，不用再点一下。
    - **底部单行布局** — 「附加上下文、润色、扩写、缩写、纠错」与右侧「历史、字数、发送」合并为一行，不再占两排；窄窗口下左侧横向滚动。
    - **浮层可拖动** — 顶部新增拖动柄，可把面板拖到不挡住正文的位置；拖动后不再跟随选区锚点，窗口缩放时自动夹回视口。
    - **输入区可调高** — 浮层底缘新增拖动手柄，上下拖动加高输入框（最多 480px），输入长指令时看得全。
    - **思考过程默认展开** — 生成时「思考」内容直接可见并跟随滚动保持最新一行在视野内，正文开始输出时才收起（仍可点开）；用户上翻阅读时不打扰。
    - **历史在浮层内展开** — 历史不再叠在浮层上的弹窗，而是在浮层底部向下展开：左列表右详情，关闭即收折；面板加高，长内容在自己的滚动条里消化，切换记录时浮层位置保持不动。
    - **历史详情可读性** — 超长指令（如完整技能提示词）默认只占 4 行，点击展开；回复内容不再有自己的内部滚动条（详情栏唯一滚动），插入 / 复制 / 删除按钮吸底常驻。
- **划词助手浮栏** — 出现、收起与切换都更稳定、更安静。
    - **改为选区落定后出现** — 拖拽 / 用方向键选词的过程中不再跟随（此前反向拖选会逐行跳动、顺向拖选偶发抖动），松手（键盘则停手约 150ms）后一次定位，并水平居中在选区上方；靠近视口边缘时自动夹回。
    - **自动收起** — 滚动正文、缩放窗口、点击浮栏与正文以外的地方（侧栏、顶部工具栏等）、打开设置 / 快捷键 / 演示 / 阅读 / 导出等弹窗时，浮栏自动收起，不再压在弹窗上。
    - **入口改为星芒图标** — 浮栏最左侧由应用图标换成单色星芒 SVG：划词出现时主星弹入、小星随后点亮，之后每 6 秒轻眨一次，悬停轻微放大旋转；系统开启「减少动态效果」时保持静止。该位置是文档内 AI 的统一入口；图标固定 16×16、不带外框。
    - **切换按钮与星芒同款配色** — 右侧「工具条 ↔ 格式条」切换按钮改用强调色，并在左侧加分隔线，与 AI 入口区分。
    - **工具条 / 格式条切换更稳** — 两者高度一致，切换时不会纵向跳动；宽度变化带收放动画。
    - **首次使用提示** — 第一次划词时浮栏上方会提示「点 ✦ 让 AI 改写选区 · 点 ⇄ 切换格式条」，只提示一次。
- **实时模式表格** — 点击与选区更顺手。
    - **单击换格** — 在一个单元格编辑后单击另一个单元格，一次点击即切换，不再需要点两次。
    - **整行 / 整列格式化** — 选中整行或整列后可直接使用工具栏的加粗、斜体等统一设置；格式化后选中态保留，方便连续操作。
    - **单元格选区跟随主题** — 单元格内划词的高亮色与正文一致，深浅主题自动适配。
- **格式应用更稳** — 标题、列表、引用按整行处理，光标在行中间也不会插进文字里；保留原有缩进，空行不加标记。
- **技能去向可配置** — 内置技能开箱即用，自定义技能也能明确选择产出落到哪里。
    - **润色 / 格式化开箱直通正文** — 内置「润色改写」「Markdown 格式化」默认改成直通正文：在划词浮栏里点一下就直接打开文档内 AI 并执行技能提示词，结果可替换选区，不用先进右侧对话再复制粘贴。「演示稿提炼」「文档摘要」「全文翻译」仍送进右侧对话 —— 它们产出的是原文之外的新内容。升级时未改过这些技能的用户会自动同步；想改回去在「设置 → Skill 管理」里切换。
    - **结果去向改为分段二选一** — 设置 → Skill 管理的新建 / 编辑表单里，「结果去向」不再收在下拉菜单里，改成左右两段的分段控件：每段一行去向名、一行说明（送进右侧对话 / 在正文里替换选区），选中段以主题色高亮，两个选项一眼看全、单击切换。
- **设置与快捷键** — 控件观感统一，入口更好找。
    - **下拉菜单跟随主题** — 语言、默认模板、光标样式、文档内 AI 快捷键、插件配置，以及 AI 设置里的服务商 / 协议 / 模型 / 引用上限 / 上下文轮数共 10 个下拉，连同插件导出弹窗的字段选择，全部换成自绘列表：展开面板使用主题的背景、边框与阴影，选中项强调色 + 对勾，悬停有高亮，深色主题下不再弹出系统配色的浅色列表；支持 ↑↓ / Home / End / Enter / Esc 操作，靠近窗口底部时自动向上展开，16 种语言的长列表在面板内部滚动。
    - **F1 快捷键速查补全** — 速查面板新增「文档内 AI 快捷键」一行，实时显示当前设置（双击 Ctrl / Ctrl+Enter，关闭后不显示）；用户自定义绑定了无默认键的条目（如导出 TXT）现在也会出现在速查里。
    - **文档内 AI 快捷键设置** — 「设置 → 快捷键」里可切换双击 Ctrl / Ctrl+Enter / 关闭；下拉按两栏各 50% 布局，不再挤压左侧名称。
- **云端版本对比显示保存时间** — 打开已缓存的云端文档、遇到「云端文档已更新」提示时，「内容对比」除大小、行数与 SHA-256 外，新增本地 / 云端的保存时间：本地取缓存副本的最后写入时间，云端取服务器的 `Last-Modified`，一眼看出哪一份更新；服务器未提供时间时显示 `—`。
- **行号更小巧清晰** — 行号字号缩小到与侧栏大纲一致（随界面缩放同步），字体由等宽改为与界面相同的非衬线；当前行的行号数字用主题色标出（不加粗、无背景），正文行同步显示淡底衬。

## 修复

- **划词助手** — 浮栏位置与跨平台粘贴。
    - **浮栏停在旧位置** — 划完一段再划更靠下的一段时，浮栏有时仍留在上一段的位置，Linux 上尤其容易复现。根因是拖拽中的「不重定位」哨兵值（`-1`）会覆盖真实坐标，而前端又跳过负坐标；现改为始终上报真实坐标、选区落定后一次定位，三平台同一套逻辑。
    - **Windows 划词工具条无法粘贴** — 用 `Ctrl+C` 复制后点「粘贴」会提示无法读取剪贴板。现在改为读取系统原生剪贴板，复制与粘贴不再依赖应用内缓存；表格右键粘贴同样受益。
- **表格与输入法** — 编辑时不再把标记写到错误的位置。
    - **单元格内格式落到表格外** — 在单元格里选中文字点加粗，语法会插到表格外面；现在只写入该单元格，再点一次即可取消。
    - **输入法组字误触发表格换行** — 中文输入法组字时按 `Enter` / 方向键，不再触发增行或跳格。
    - **任务列表输入法 NBSP** — 输入法在任务复选框后写入不换行空格时，Windows 预览会把整行当作普通列表；旧文档打开后也会自动修正。
- **PPTX 导出排版** — 长代码折行后的高度会回流到版式。
    - **代码块压住后续内容 / 卡片底部留白被吃** — 分栏里的长代码在 PowerPoint 中没有横向滚动条，导出时会折成多行；此前多出来的高度只加在代码底色上，导致卡片底部留白消失、后面的列表被代码压住。现在折行增高会回流：同排卡片等高增高、栏内后续内容同步下移，栏外落款与后续正文也一起让位；长代码行另留 4% 安全余量，避免打开文件的机器缺字体时横向出血。
    - **分栏卡片与落款贴在一起** — 分栏区与紧随其后的栏外文案（落款）之间补上与其他正文块一致的间距，演示预览与导出同时生效。
- **Linux 文件关联** — 双击 `.md` 或用 YiziMarkdown 打开时直接载入文档（首轮 Linux 包已修复，本次三平台同步）。
    - **只启动应用、不打开文件** — 安装包的桌面条目只写了启动命令，没有把选中的文件传给应用，文件管理器因此把路径丢掉了。现在 deb 与 AppImage 的桌面条目都会附带文件参数，双击和右键打开都会直接载入对应文档。
    - **文件路径兼容 `file://` 形式** — 部分桌面环境或启动器会传 `file:///home/...` 形式的地址；现在会自动还原为本地路径，中文、空格与百分号编码的路径都能正确打开。
    - **第二个实例打开文件** — 应用已在运行时再次双击文档，会复用现有窗口并打开文件，不再只把窗口切到前台。

> 升级后如果文件关联仍未生效，请在「设置 → 通用 → 文件关联」里关闭再重新打开一次。
