# v0.3.5

## 新增功能

- **公式导出为 Word 原生公式**：行内 `$…$` 与块级 `$$…$$` 导出后是 Word / WPS 里**能点进去编辑**的公式（分式、根式、上下标、求和积分、矩阵、cases 等），不再是一张图或一段源码；实在转不出的写法退回源码，不会变成空白
- **SVG 图片导出为矢量**：放大不糊；旧版 Word / LibreOffice 自动使用内嵌位图，不会整张空白
- **正文列宽度可拖拽**：鼠标移到正文左右边缘会出现一条短竖线，按住左右拖即可调宽，**源码 / 实时 / 预览共用一个宽度**，双击恢复默认 900px；部分主题原先预览宽度固定 800 / 700px，现在也跟随这个设置

## 优化

- **导出 Word 跟随预览排版**：字号、行高、段落与列表间距、标题比例都按设置里的「预览字号 / 预览行高」换算（此前固定 11pt、1.5 倍行距）；暗色主题导出为白底可读的配色，主题强调色保留原色相
- **导出 Word 的代码块有语法高亮了**，颜色与预览逐 token 一致，换主题或改自定义 CSS 也跟着变
- **导出 PDF 与预览一致**：字体、字号、行高跟随预览设置；纸面统一白纸 —— 不铺主题背景，也不印「卡片式」主题的页面边框与投影，暗色主题按亮色配色导出；A4 / 18mm、无页眉页脚；代码块长行折行、长表格每页重复表头、标题不落页尾、公式字体随文档内嵌
- **列宽手柄更安静**：拖动时只显示正在拖的那一侧；悬浮时在竖线外侧提示「按住拖动调整宽度」，窗口太窄时提示自动翻到内侧，不会被裁掉
- 导出后的 Word 显示「15pt、单倍行距」是**正确换算**（20px = 15pt，Word 的「单倍」约等于 1.2 倍行高），改设置后导出会同步变化

## Bug 修复

- **导出 Word 会丢内容**：公式、脚注、开头 `---` 之间的元信息、分隔线 `---`、工具条插入的上下标与 `<mark>` 高亮、行内 `<br>`；WebP 图片是空框，`.jfif` / 没有扩展名 / 扩展名写错的图片被跳过
- **导出 Word 的换行全部失效**：软换行、行尾两空格、行尾反斜杠都不换行，代码块的多行被挤成一行
- **导出 Word 的列表编号错乱**：第二个有序列表接着上一个继续数、指定的起始序号被忽略、嵌套列表变成 `1.1.` 多级编号、任务列表出现「项目符号 + 勾选框」双标记
- **导出 Word 的无序列表项目符号是方框**，而且层级越深越大
- **导出 Word 的引用块**被打断成好几段、左边框与底色不连续，嵌套引用看不出层级
- **导出 Word 的脚注**：正文里的引用消失、定义文字跑进正文；脚注内字号参差不齐
- **导出 Word 的表格**没有列宽网格，多列表格宽窄不齐
- **预览里的任务项**内容重复出现两遍，窄窗口下还被挤成硬换行
- **导出不再悄悄改标点**：直引号、`a--b`、`...` 保持原文；裸网址自动成链接，`[[双链]]` 按原文显示
