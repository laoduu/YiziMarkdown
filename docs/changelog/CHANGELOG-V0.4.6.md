# v0.4.6

> 开发中（2026-11-19）。发布时请确认版本号与日期。

本版本聚焦实时模式表格的编辑体验、格式开关与划词格式条，并修复划词助手在 Windows 上无法粘贴的问题；云端文档的版本提示新增本地 / 云端保存时间对比。

## 新增

- **文档内 AI 改写** — 划词后点浮栏最左侧的星芒，可在选区旁直接输入指令让 AI 改写正文：结果支持替换选区、插入到下方、复制、放弃，还可以继续提「补充需求」多轮打磨；「对比原文」会在正文里就地显示红删绿增的 diff；可附加「当前小节 / 整篇文档」作为语境。写入后浮层自动关闭，可用 Ctrl+Z 或顶部工具栏撤销。润色、扩写、缩写、翻译、纠错、转列表等快捷意图按选区内容自动给出。与右侧 AI 助手 / 划词技能不同，这里的产出直接写回文档。工具条与格式条的切换移到浮栏最右端。
- **光标处 AI 创作** — 双击 Ctrl 或点顶部工具栏的星芒按钮，可在光标处让 AI 直接写一段：结果可插入到光标或复制。与划词改写共用同一浮层，提示词自动切换为写作模式。快捷键可在「设置 → 快捷键」里改为 Ctrl+Enter 或关闭。
- **技能直通文档** — 技能可设置 `delivery: "inline"`：划词浮栏里点击该技能会直接打开文档内 AI 并执行技能提示词，结果可替换选区 / 插入到下方；默认的 `chat` 仍送进右侧 AI 助手对话。
- **划词格式条** — 划词时点击浮栏最右端的 ⇄ 按钮，可在「工具条」与「格式条」之间切换，选择会记住。格式条提供加粗、斜体、删除线、高亮、行内代码（含代码块）、上标 / 下标、标题（H1–H3）、无序 / 有序 / 任务列表、引用与公式（行内 / 块）；带二级选项的图标 hover 展开。设置 → 划词助手 中可排序、显示或隐藏单个格式，链接默认隐藏。
- **表格键盘导航** — 实时模式表格支持 `Tab` / `Shift+Tab` 左右跳格（行末换到下一行，最后一格自动新增一行），`Enter` 跳到同列下一行（最后一行自动新增一行），`↑` / `↓` 切换上下单元格，`←` / `→` 在单元格文本首尾时切换左右单元格。
- **格式再点一次取消** — 正文与表格中的加粗、斜体、删除线、行内代码、高亮、上下标：已应用时再点一次即取消，不再叠加出 `****`；对加粗文字点斜体会得到 `***文字***`，不会误拆原有格式。
- **标题 / 列表 / 引用切换** — 标题同级再点取消、换级直接替换；无序列表、有序列表、任务列表与引用支持再次点击取消；列表类型之间可直接互转。

## 优化

- **表格单击换格** — 在一个单元格编辑后单击另一个单元格，一次点击即切换，不再需要点两次。
- **划词栏切换更稳** — 工具条与格式条高度一致，切换时不会纵向跳动；宽度变化带收放动画。
- **首次使用提示** — 第一次划词会提示「点击这里切换工具条 / 格式条」，设置页预览下方也常驻该提示。
- **品牌图标更清晰** — 去掉格式模式下的额外外框，图标保持 16×16 不变形。
- **表格整行 / 整列格式化** — 选中整行或整列后可直接使用工具栏的加粗、斜体等统一设置；格式化后选中态保留，方便连续操作。
- **单元格选区跟随主题** — 单元格内划词的高亮色与正文一致，深浅主题自动适配。
- **前缀格式更稳** — 标题、列表、引用按整行处理，光标在行中间也不会插进文字里；保留原有缩进，空行不加标记。
- **云端版本对比显示保存时间** — 打开已缓存的云端文档、遇到「云端文档已更新」提示时，「内容对比」除大小、行数与 SHA-256 外，新增本地 / 云端的保存时间：本地取缓存副本的最后写入时间，云端取服务器的 `Last-Modified`，一眼看出哪一份更新；服务器未提供时间时显示 `—`。
- **划词入口改为星芒图标** — 浮栏最左侧由应用图标换成单色星芒 SVG：划词出现时主星弹入、小星随后点亮，之后每 6 秒轻眨一次，悬停轻微放大旋转；系统开启「减少动态效果」时保持静止。该位置是文档内 AI 的统一入口，工具条 / 格式条的切换移到浮栏最右端。
- **文档内 AI 快捷键设置** — 「设置 → 快捷键」里可切换双击 Ctrl / Ctrl+Enter / 关闭；下拉按两栏各 50% 布局，不再挤压左侧名称。
- **浮栏切换按钮与星芒同款配色** — 右侧「工具条 ↔ 格式条」切换按钮改用强调色，并在左侧加分隔线，与 AI 入口区分。
- **文档内 AI 浮层可拖动** — 浮层顶部新增拖动柄，可把面板拖到不挡住正文的位置；拖动后不再跟随选区锚点，窗口缩放时自动夹回视口。

## 修复

- **Windows 划词工具条无法粘贴** — 用 `Ctrl+C` 复制后点「粘贴」会提示无法读取剪贴板。现在改为读取系统原生剪贴板，复制与粘贴不再依赖应用内缓存；表格右键粘贴同样受益。
- **单元格内格式落到表格外** — 在单元格里选中文字点加粗，语法会插到表格外面；现在只写入该单元格，再点一次即可取消。
- **输入法组字误触发表格换行** — 中文输入法组字时按 `Enter` / 方向键，不再触发增行或跳格。
- **任务列表输入法 NBSP** — 输入法在任务复选框后写入不换行空格时，Windows 预览会把整行当作普通列表；旧文档打开后也会自动修正。

## 后续可选计划

- **会话历史** — 按标签页记住最近几次文档内 AI 任务，支持回看、重新应用或继续追问。
- **内置技能的默认去向** — 为「润色改写」「Markdown 格式化」等适合直接改文档的技能补上 `delivery: "inline"`，开箱即用。
- **「文档内 AI」独立设置分区** — 集中放快捷键、默认上下文（不附加 / 当前小节 / 整篇文档）与写入行为（替换 / 插入 / 每次询问）。
