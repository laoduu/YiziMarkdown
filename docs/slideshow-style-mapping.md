# 演示模式：纯 Markdown → 自动版式

YiziMarkdown 的演示模式（幻灯片）**不需要任何额外格式**：你按平时写 Markdown 的习惯写，引擎根据内容自动排版，配色继承当前主题。本文是「Markdown 写什么 → 演示效果是什么」的对照参考。

相关代码：
- 分页与版式推断：`src/lib/slides.ts`
- 渲染与主题继承：`src/components/Slideshow.tsx`
- 幻灯片样式：`src/styles/slideshow.css`

---

## 唯一规则：分页

用**单独成行的 `---`**（标准 Markdown 水平分割线）翻页：

```markdown
# 第一页

---

# 第二页
```

- `---` 必须单独成行（前后是空行）
- 代码围栏（```` ``` ````）内部的 `---` 是代码内容，**不会**分页
- 文档顶部的 front matter（首个 `--- ... ---` 块）自动忽略，不会成为一页

除了这一条，其余全部是你已经会的 Markdown。

---

## 自动版式：Markdown 结构 → 幻灯片效果

引擎按每页**开头的内容结构**自动选择版式，无需任何标记：

| 一页开头的内容 | 自动版式 | 效果 |
|----------------|---------|------|
| `# 一级标题` 开头 | **标题页** | 大标题居中（封面强调）+ 主题色渐变下划线，副标题次要色 |
| `##` / `###` 开头 | **内容页** | 块居中，正文左对齐 |
| 段落 / 列表 / 表格 | **内容页** | 块居中，正文左对齐 |
| 图片开头（`![...]`） | **图片页** | 大图居中 |
| `> 引用` 开头 | **引用页** | 大引号 + 居中大字 |
| ` ``` 代码围栏` 开头 | **代码页** | 代码聚焦居中 |
| `` ```mermaid `` 开头 | **图表页** | 图表居中 |

> 版式判定只依赖**结构**，不依赖任何配置，用户无感知、零学习成本。

### 排版约定

- **块居中、正文左对齐**：每个内容块在页面中垂直/水平居中，块内长正文保持左对齐以便阅读。
- **标题一律居中**；h1/h2/h3 仅靠字号递减区分层级（h1 最大）。当一页以 `# 一级标题` 开头时，作为**封面标题强调**（放大 + 主题色下划线）。

---

## 配色：主题继承

- 幻灯片**自动继承应用当前主题与明暗**，无需配置。
- 取色来自主题的 CSS 变量（`--editor-bg/text/accent/surface/border/...`、`--font-sans/mono`），因此换主题，幻灯片同步换肤。
- **标题颜色**通过主题变量 `--editor-h1 / --editor-h2 / --editor-h3` 继承（各主题已定义这些变量，对应各自 h1/h2/h3 配色；深色模式另有取值）。行内代码用 `--editor-accent`。
- 主题 CSS 中的 `:root.theme-*` 会被自动改写为幻灯片作用域以提供变量；幻灯片的字号/对齐/居中由 `slideshow.css` 全权控制（不继承编辑器的元素排版规则，避免左对齐/小字号覆盖演示版式）。

---

## 可选：演讲者备注（仅演示者可见）

在幻灯片任意位置用 HTML 注释写备注，播放时按 `S` 显示/隐藏：

```html
<!-- notes: 这一页要强调的重点 -->
```

备注只出现在左下角面板，不会出现在正片画面。这是**唯一**非纯 Markdown 的可选语法，且不影响版式与美观。

## 播放快捷键

| 按键 | 功能 |
|------|------|
| → / 空格 / PageDown / Enter | 下一页 |
| ← / PageUp / Backspace | 上一页 |
| Home / End | 首页 / 末页 |
| F | 切换全屏 |
| S | 显示 / 隐藏演讲者备注 |
| ? | 显示 / 隐藏帮助 |
| Esc | 退出演示 |

---

## 支持的内容

幻灯片内支持编辑器全部预览能力：标题、列表、表格、引用、行内 / 块级公式（KaTeX）、Mermaid 图表、本地图片等，与预览一致（需在 设置 → 插件 中启用对应插件）。

---

## 扩展版式（进阶）

如需新增或调整某类版式的观感，编辑 `src/styles/slideshow.css` 中 `.ys-kind-<类型>` 规则即可（`title / content / image / quote / code / chart`）。版式识别逻辑在 `src/lib/slides.ts` 的 `detectSlideKind`；标题颜色在主题文件的 `--editor-h1/h2/h3` 变量中调整。
