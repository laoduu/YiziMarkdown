**Официальный сайт:** https://md.yizigpt.com

Лаконичный и изящный кроссплатформенный редактор `Markdown` с поддержкой портативной версии для Windows и версии для macOS. Не требует установки: распакуйте и пользуйтесь, сочетая эстетику и практичность. В Windows его можно установить или скачать архивом и просто распаковать; для macOS предлагается универсальный бинарный установщик, нативно работающий на Intel и Apple Silicon.

Почему мы решили создать редактор `Markdown`?

На рынке немало редакторов `Markdown`, но у одних некрасивый интерфейс, у других — перегруженный и громоздкий функционал; найти инструмент, который одновременно прост, красив и удобен, непросто.

Так появился YiziMarkdown.

Мы создали невероятно элегантный опыт для режима WYSIWYG; кроме того, поддерживается быстрая презентация в стиле PPT — готовые заметки и документы можно мгновенно переключать в режим презентации для удобных выступлений и отчётов. Лучше один раз попробовать.

## Возможности

### Многоязычный интерфейс

- **16 языков интерфейса**: 简体中文 (по умолчанию), 繁體中文, English, 日本語, 한국어, Deutsch, Français, Español, Português, Italiano, Polski, Nederlands, Türkçe, Svenska, Українська, Русский
- Переключение языка интерфейса в разделе «Настройки → Общие → Настройки интерфейса → Язык интерфейса» одним кликом, изменения применяются сразу; весь текст интерфейса, панель горячих клавиш и описания плагинов следуют за языком
- **Размер шрифта интерфейса**: 80%–120% (по умолчанию 100%), масштабируются только текст и значки интерфейса; размеры панелей и содержимое редактора / предпросмотра не затрагиваются

### AI-помощник (боковая панель чата)

- **17 поставщиков больших моделей + пользовательский сервис**: OpenAI, Anthropic, Gemini, xAI, Mistral, Groq, DeepSeek, 通义千问, 智谱 GLM, Moonshot Kimi, 火山方舟, 硅基流动, MiniMax, OpenRouter, OpenCode Go, Ollama (локально); «Пользовательский сервис» поддерживает протоколы, совместимые с OpenAI / Anthropic: укажите Base URL, ID модели и ключ самостоятельно — можно подключить любой сторонний сервис
- **AI-навыки (Skill)**: кнопка ⚡ в поле ввода открывает меню навыков; после выбора тег навыка вставляется в позицию курсора, а промпт автоматически добавляется в контекст; чтобы создать собственный навык, достаточно поместить `skills.json` + `.md`-файлы промптов в каталог `skills/`. Встроено 5 навыков: «Выжимка для презентации», «Сводка документа», «Вычитка и переписывание», «Полный перевод», «Форматирование Markdown»
- **Потоковый диалог**: кнопка с роботом на панели инструментов открывает AI-панель справа; ответ выводится потоком в реальном времени, в любой момент можно остановить
- **Отображение процесса размышления**: содержимое рассуждений (reasoning/thinking) reasoning-моделей показывается в сворачиваемом блоке, по умолчанию свёрнутом и не мешающем чтению основного текста
- **Безопасность ключей**: API-ключи хранятся в системном брелоке (OS keychain), поддерживаются сохранение, очистка и проверка одним кликом; для локальных эндпоинтов (llama.cpp / LM Studio / vLLM и т. п.) ключ можно оставить пустым
- **Цитирование текущего документа**: если включить этот пункт, текущий документ отправляется AI в качестве контекста; можно настроить лимит цитирования (64K~512K/без ограничений) и число раундов контекста (0~20, по умолчанию 3)
- **Сохранение результатов**: ответ можно скопировать, вставить в позицию курсора в документе или одним кликом создать как новый документ

### Редактирование и предпросмотр

- **Редактирование исходного кода**: ядро CodeMirror 6, подсветка синтаксиса, сопоставление скобок, автодополнение
- **Режим реального времени (WYSIWYG)**: редактирование «что видишь, то и получаешь», при вводе разметка Markdown автоматически скрывается — концентрация на создании контента
- **Анимация в режиме реального времени**: 4 варианта анимации появления разметки (фокус / вспышка / свечение / рябь), переключение с предпросмотром в настройках
- **Предпросмотр в реальном времени**: Markdown рендерится по мере ввода, поддерживается интерактивное взаимодействие с флажками списков задач
- **Пять режимов просмотра**: исходный код / бок о бок / реальное время (WYSIWYG) / предпросмотр / презентация (полноэкранные слайды), переключение одним кликом
- **Синхронизация прокрутки по структуре документа**: в режиме «бок о бок» левая и правая панели связаны в обе стороны; при переключении вида автоматически позиционируется текущее место
- **Поиск и замена**: навигация по совпадениям, заменить всё
- **Быстрое форматирование на панели инструментов**: жирный, курсив, зачёркивание, встроенный код — выделенный текст сразу оборачивается
- **Отображение локальных изображений**: режим предпросмотра автоматически отображает изображения по локальным путям (jpg/png/gif/webp/svg/bmp)
- **Номера строк / перенос строк**: включаются и отключаются в настройках
- **Улучшенные блоки кода**: подсветка синтаксиса (highlight.js), метки языка, кнопка копирования, переключение переноса строк
- **Сворачивание панели форматирования**: автоматически сворачивается при недостаточной ширине окна, можно вручную развернуть / свернуть
- **Фильтрация Frontmatter**: в режимах предпросмотра, «бок о бок» и реального времени YAML frontmatter автоматически фильтруется
- **Панель свойств метаданных**: в режиме реального времени YAML front matter отображается как редактируемая панель свойств в стиле Obsidian (7 типов: авто / текст / число / флажок / дата / дата и время / список; тип глобально запоминается по имени свойства); в режиме исходного кода — как есть, в режиме предпросмотра — скрыта

### Режим чтения

- **Полноэкранное чтение**: кнопка книги на панели инструментов или `Ctrl+Alt+R`; включается полный экран, панель редактирования скрывается, `Esc` выходит и восстанавливает прежний вид
- **Книжная вёрстка**: страницы обрамлены тонкой рамкой с равными полями со всех сторон, две страницы образуют разворот, а в месте сгиба проходит только одна разделительная линия; название книги — вверху слева, название главы / номер страницы — внизу слева, HUD — внизу справа, расположение совпадает с режимом презентации
- **Обложка / титульный лист / страница содержания**: название книги автоматически извлекается из `title` front matter или первого H1, создаются обложка и титульный лист; затем по заголовкам формируется страница содержания с номерами страниц (длинное содержание автоматически разбивается на страницы)
- **Настоящая пагинация**: это не полноэкранный предпросмотр с прокруткой — текст сначала раскладывается по фиксированным страницам, а затем читается; разворот из двух страниц (в узком окне автоматически одна страница), на страницах есть номера и прогресс чтения
- **3D-перелистывание**: страница закручивается от правого нижнего угла, лист сгибается через корешок (в одностраничном режиме — вокруг корешка книги); при перелистывании бумага приподнимается, появляются блики и падающие тени; при быстрых нажатиях страницы не пропускаются, переходы по содержанию / номерам страниц / сноскам выполняются без анимации
- **Правила постраничной вёрстки**: абзацы разбиваются по строкам, заголовки не остаются одни в конце страницы, при переносе таблицы на следующую страницу повторяется её шапка, блоки кода переносятся построчно, списки продолжаются по пунктам, цельные изображения масштабируются пропорционально; абзацы основного текста автоматически получают **абзацный отступ в два знака** (на страницах-продолжениях отступ не повторяется)
- **Выдвижная панель содержания**: открывается по `T`, перечисляет заголовки по уровням с номерами страниц, клик сразу переходит на страницу; поддерживается переход на указанную страницу по клавише `G` или через поле ввода номера
- **Переходы к сноскам и обратно**: клик по ссылке на сноску переходит на страницу определения и подсвечивает её, есть кнопка «Вернуться к ссылке»; внутренние якоря также переходят по страницам
- **HUD**: в правом нижнем углу переключаются светлый/тёмный режим, тема оформления, шрифт (следует теме / с засечками / без засечек / моноширинный), размер шрифта и межстрочный интервал; изменения действуют только на текущее чтение, цветовая схема темы следует за текущей темой
- **Запоминание позиции чтения**: для каждого документа запоминаются последняя страница / глава, при повторном входе позиция восстанавливается автоматически
- **Чтение EPUB**: при открытии `.epub` сразу включается режим чтения; используется тема чтения приложения (CSS издателя игнорируется), считываются встроенная обложка, навигационное содержание EPUB, изображения, формулы, Mermaid SVG, сноски и ссылки между главами; EPUB с DRM-шифрованием и фиксированной вёрсткой (комиксы/фотоальбомы) пока не поддерживаются
- **Управление**: стрелки / PageUp/PageDown / пробел / колесо мыши перелистывают страницы, также можно кликать по левому или правому краю страницы; `F` переключает полноэкранный режим

### Математические формулы и диаграммы

- **Формулы KaTeX**: встроенная базовая возможность, LaTeX-формулы внутри строки `$...$` и блочные `$$...$$` отображаются в реальном времени
- **Диаграммы Mermaid**: встроенная базовая возможность, блок-схемы, диаграммы последовательностей, диаграммы Ганта, диаграммы классов, круговые диаграммы и др. автоматически отображаются как визуальные диаграммы, цветовая схема следует текущей теме приложения
- **Выбор строк и столбцов таблицы**: кнопка таблицы на панели инструментов открывает сетку 8×8, щелчок мышью вставляет таблицу с соответствующим числом строк и столбцов

### Режим презентации (слайды)

- **Работает на чистом Markdown**: никакого дополнительного формата не нужно, `---` (горизонтальная разделительная линия) разделяет страницы, движок анализирует структуру страницы и автоматически выбирает макет
- **Колонки**: внутри страницы колонки разделяются отдельной строкой `***` (стандартная разделительная линия), до 4 колонок — `---` разделяет страницы, `***` — колонки
- **14 автоматических макетов**: обложка, страница главы, финальная страница, содержание, контент, список, таблица данных, дорожная карта, текст с изображением, изображение, цитата, код, диаграмма (mermaid), формула
- **Содержимое выравнивается по левому краю + акцентное подчёркивание**: заголовок выровнен по левому верхнему краю и подчёркнут цветом темы, основной текст выровнен по левому краю — читать комфортно
- **Большие кавычки по диагонали на странице цитаты**: открывающая кавычка — в левом верхнем углу, закрывающая — в правом нижнем, содержимое центрируется по вертикали
- **Типографика и область содержимого (настраивается в HUD)**: во время показа можно менять шрифт (следует теме / без засечек / с засечками / моноширинный), насыщенность шрифта, размер, ширину/высоту заполнения содержимого (доля области содержимого от всего экрана, 50%~95%), изменения применяются сразу и сохраняются
- **Автоматический перенос встроенного кода**: слишком длинный встроенный код (например, `"{:=^20}".format("python")`) автоматически переносится и больше не обрезается краем страницы
- **Явные директивы**: `<!-- layout: xxx -->` принудительно задаёт макет, `<!-- align: left|center|right -->` — выравнивание всей страницы (HTML-комментарии не видны при рендеринге)
- **Метаданные обложки**: в front matter указываются `author`/`date`, обложка отображает их автоматически
- **Нижний колонтитул и прогресс**: внизу слева название главы + номер страницы, внизу полоса прогресса цвета темы
- **Прокрутка колесом мыши**: если содержимое можно прокручивать, сначала прокручивается оно, а по достижении границы происходит смена страницы
- **Выдвижное содержание / переход по страницам**: во время презентации `T` открывает список глав и слайдов, клик сразу переходит на нужную страницу; поле ввода внизу позволяет перейти на страницу N (`G` также открывает панель)
- **Наследование темы**: цвет заголовков точно меняется вместе с темой (поддерживаются все 15 тем), во время презентации можно переключать тему / светлый и тёмный режим
- **Переключение полного экрана**: клавиша F включает / выключает полноэкранный режим, надёжно работает из любого состояния окна (обычное / развёрнутое)
- **Кнопка выхода**: при активности мыши в правом верхнем углу появляется полупрозрачная кнопка выхода, через 1,5 секунды без действий она автоматически скрывается
- **Восстановление состояния окна**: при выходе из презентации автоматически восстанавливается состояние окна, которое было до входа (полный экран / развёрнутое / обычное)

### Система плагинов

- **Базовые возможности**: семантические функции документов, такие как KaTeX / Mermaid / сноски / списки задач / TOC, встроены по умолчанию и не зависят от переключателей плагинов
- **Встроенные плагины**: экспорт EPUB (включён по умолчанию, можно отключить на странице плагинов; manifest + возможность экспорта); меню экспорта на панели инструментов появляется только после включения; перед экспортом доступна панель управления (разбиение на главы / обложка / видимое содержание / тема чтения / информация о документе)
- **Стандарт плагинов**: manifest (версия / версия API / момент активации / разрешения / возможности) → проверка соответствия → ленивая активация → регистрация возможностей → очистка при отключении; текущая версия загружает только встроенные плагины, скомпилированные в приложение

### Управление несколькими файлами

- **Режим одного экземпляра**: открытие нескольких файлов больше не запускает несколько окон, они автоматически объединяются в существующий экземпляр, повторно открытый файл автоматически позиционируется на соответствующей вкладке
- **Панель вкладок**: вверху управление несколькими открытыми файлами — переключение, закрытие, создание, **поддерживается перетаскивание для сортировки**
- **Главная страница**: список недавно открытых файлов с размером и временем изменения
- **Индикатор состояния сохранения**: пульсирующая точка у несохранённых файлов, анимация подтверждения ✅ после сохранения
- **Подтверждение закрытия**: при закрытии несохранённого файла появляется выбор «Сохранить / Не сохранять / Отмена»

### Работа с файлами

- **Открытие**: поддерживаются .md / .markdown / .txt / .epub; после открытия EPUB сразу включается полноэкранный режим чтения
- **Создание**: создаётся пустая вкладка с надписью «Новый файл без имени»
- **Создание из шаблона**: выпадающее меню «Создать из шаблона» на панели инструментов создаёт новый документ по структуре Markdown выбранного шаблона; также можно задать шаблон по умолчанию в разделе «Настройки → Общие», после чего `Ctrl+N` будет автоматически его применять
- **Сохранение / автосохранение**: ручное сохранение + автосохранение с настраиваемым интервалом (5~180 секунд, по умолчанию 60 секунд)
- **Сохранить как**: при сохранении нового файла автоматически открывается диалог «Сохранить как»
- **Экспорт**: шесть форматов — HTML / Markdown / обычный текст / Word (DOCX) / PDF / PPTX, а также EPUB, предоставляемый плагином (появляется после включения «Настройки → Плагины → Экспорт EPUB»; перед экспортом можно выбрать разбиение на главы / обложку / содержание / тему чтения); DOCX использует нативную семантику Word (списки / таблицы / блоки кода / цитаты / списки задач), стили таблиц соответствуют предпросмотру, изображения поддерживают локальные пути, сетевые изображения и HTML-тег `<img>` (ширину можно задать атрибутом `width`); PDF соответствует предпросмотру и автоматически разбивается на страницы; HTML снабжается **плавающей карточкой содержания слева**, клик по пункту сразу переходит к соответствующей главе (в PDF боковой панели нет); PPTX наследует тему, светлый/тёмный режим и макеты презентации, выводит редактируемые текст, таблицы, изображения, фигуры и нативные формулы
- **Связывание файлов .md**: в настройках одним кликом можно назначить приложение редактором Markdown по умолчанию, после чего .md открывается двойным щелчком (реестр Windows / LaunchServices macOS)
- **Умная вставка**: форматированный текст, скопированный из веб-страниц, Word/DOCX, Google Docs, Notion и т. п., при вставке преобразуется в памяти в нормализованный Markdown (заголовки / списки / таблицы / код / цитаты / ссылки); исходный Markdown и обычный текст вставляются как есть

### Облачное хранилище (WebDAV)

- **Обозреватель облачных файлов**: вкладка «Облако» на боковой панели показывает дерево каталогов сервера WebDAV, поддерживает открытие документов, создание папок, переименование, удаление; хлебные крошки глубоких каталогов сворачиваются в «…» с выпадающим списком для перехода, щелчок по значку папки раскрывает её уровень за уровнем с ленивой загрузкой
- **Загрузка предустановки**: «Настройки → Облачное хранилище», при фокусе на поле адреса появляется «Загрузить предустановку», одним кликом подставляется адрес 坚果云
- **Сохранение в облако**: локальный документ загружается одним кликом (изображения, на которые в документе есть относительные ссылки, также загружаются с сохранением структуры каталогов); если документ уже облачный, `Ctrl+S` напрямую записывает его обратно на сервер
- **Защита от конфликтов**: перед сохранением сравнивается ETag сервера; если удалённая версия изменена другим устройством, появляется диалог с выбором «Перезаписать серверную версию» или «Отказаться от локальных изменений и перезагрузить», перезапись без предупреждения исключена
- **Безопасность учётных данных**: имя пользователя и пароль хранятся в хранилище учётных данных ОС (Диспетчер учётных данных Windows / связка ключей macOS) и не записываются ни в какие файлы конфигурации
- **Совместимость**: поддерживаются стандартные сервисы WebDAV, такие как 坚果云, Nextcloud, 群晖 (рекомендуется использовать пароль приложения)

### Настройка внешнего вида

- **15 встроенных тем**: Liquid Glass Prism (по умолчанию), Академический синий, Яркий оранжевый, Техно, Минимализм, Журнальный, Природа, Красный личи, Фиолетовый, Киберпанк, Facebook, Матрица, Мятный, Расплавленный закат, Ретро-печатная машинка; каждая включает две цветовые схемы — светлую и тёмную
- **Тёмный / светлый режим**: каждая тема включает две цветовые схемы — светлую и тёмную
- **Настройка шрифтов**: для режимов исходного кода и предпросмотра отдельно задаются шрифт, размер и высота строки
- **Пользовательская тема**: напишите стили в разделе «Настройки → Внешний вид → Пользовательский CSS» и сохраните — создаётся «Пользовательская тема» (тема на момент сохранения как основа + ваш CSS, автоматически выбирается); можно вставить целую новую тему или лишь слегка изменить несколько цветов; изменения вступают в силу сразу, перезапуск не нужен
- **Расширение тем**: поместите `.css`-файл в каталог `themes/` и добавьте параметры темы в `themes/theme.json`, после перезапуска тема распознаётся автоматически; система токенов темы и правила дизайна описаны в `docs/THEME-DESIGN-SPEC.md`

### Прочее

- **Шаблоны документов**: шаблоны хранятся в пользовательском каталоге `~/Documents/yizimarkdown/templates/`, достаточно положить туда `.md`-файл (также можно создавать/редактировать в разделе «Настройки → Шаблоны», меню обновляется сразу после создания); встроенные шаблоны при первом запуске автоматически синхронизируются в этот каталог, обновление/переустановка не перезаписывают ваши шаблоны
- **Система горячих клавиш**: визуальная панель настройки горячих клавиш, пользовательские привязки для 30 действий, запись клавиш, обнаружение конфликтов и сброс к значениям по умолчанию
- **Панель настроек**: вкладки «Общие», «Внешний вид», «Редактор», «Режим реального времени», «AI-помощник», «Облако», «Плагины», «Горячие клавиши», «Шаблоны», «О программе» и др., настройки с мгновенным предпросмотром
- **Версия и обновления**: установленная версия для Windows может обновляться одним кликом внутри приложения; macOS и портативная версия при запуске проверяют `latest.json`, при обнаружении новой версии показывают уведомление в правом нижнем углу и открывают страницу загрузки соответствующей версии (замена вручную, без автоматической установки)

## Разработка

### Требования к окружению

- Node.js 18+
- Rust (stable)
- Tauri CLI (`npm install -g @tauri-apps/cli`)

### Запуск сервера разработки

```bash
cd code
npm install
npm run tauri:dev
```

### Сборка релизной версии

**Windows**

```bash
npm run tauri:build
```

Результаты сборки:
- Портативный exe: `src-tauri/target/release/yizimarkdown.exe`
- Установщик NSIS: `src-tauri/target/release/bundle/nsis/`

Мастер установки: при первой установке сначала выбирается язык установки (16 языков: все языки интерфейса приложения + бразильский португальский), текст мастера и язык первого запуска после установки следуют этому выбору; обновление / автообновление не сбрасывают выбранный пользователем язык. Значки и изображения боковой панели / заголовка находятся в `src-tauri/installer/`, после изменения фирменных цветов повторно запустите `powershell -ExecutionPolicy Bypass -File scripts/make-installer-art.ps1` для генерации.

После сборки вручную скопируйте exe и файлы ресурсов в каталог `public/YiziMarkdown-vX.X.X/` для распространения.

**macOS (универсальный бинарный файл, поддерживает Intel и Apple Silicon)**

```bash
rustup target add aarch64-apple-darwin
npm run tauri:build -- --target universal-apple-darwin
```

Результаты сборки:
- Пакет приложения: `src-tauri/target/universal-apple-darwin/release/bundle/macos/YiziMarkdown.app`
- Установщик: `src-tauri/target/universal-apple-darwin/release/bundle/dmg/YiziMarkdown_0.2.2_universal.dmg`
