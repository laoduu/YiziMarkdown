# YiziMarkdown


![image](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/index.png)

[简体中文](../../readme.md) | [繁體中文](./readme-zh-TW.md) | [English](./readme-en.md) | [日本語](./readme-ja.md) | [한국어](./readme-ko.md) | [Deutsch](./readme-de.md) | [Français](./readme-fr.md) | [Español](./readme-es.md) | [Português](./readme-pt.md) | [Italiano](./readme-it.md) | [Polski](./readme-pl.md) | [Nederlands](./readme-nl.md) | [Türkçe](./readme-tr.md) | [Svenska](./readme-sv.md) | [Українська](./readme-uk.md) | [Русский](./readme-ru.md)

**Официальный сайт:** https://md.yizigpt.com

YiziMarkdown — кроссплатформенный редактор Markdown, в центре которого стоит письмо. Один и тот же файл `.md` можно увидеть семью способами: `редактирование исходника`, `сверка бок о бок`, `живой режим`, `предпросмотр результата`, `презентация слайдов`, `чтение как книги`, а также `режим дзен`, где остаётся только текст.

- **Windows**: можно установить (установщик NSIS с обновлением в приложении одним нажатием) или скачать портативный архив и запустить сразу после распаковки
- **macOS**: универсальный бинарный пакет, нативно работает на Intel и Apple Silicon
- **Linux**: пакет `deb` для Debian и `AppImage` без установки (Ubuntu 22.04+ / Debian 12+, сейчас только amd64)

Зачем делать ещё один редактор Markdown? Готовые решения либо выглядят неприятно, либо перегружены функциями, и трудно найти инструмент, сочетающий простоту, красоту и удобство работы. Так появился YiziMarkdown, верный трём вещам: **красивый интерфейс**, **мощные функции**, **разные сценарии**.

Так и получился нынешний `YiziMarkdown`: `поддержка 3 систем`, `7 режимов работы`, `16 языков интерфейса`, `15 светлых и тёмных тем`, `5 AI Skill`, `7 форматов экспорта`, плюс встроенный AI-помощник, облачное хранилище и другие новаторские функции, а также открытая документация по темам, навыкам и презентациям — из всего этого можно собрать собственный, ни на что не похожий опыт работы.

Это уже не простой редактор markdown, а полноценное многофункциональное приложение, которое охватывает самые разные сценарии работы с документами — творчество, работу, повседневную жизнь.

## Семь режимов: один документ — семь способов показа

Ценность Markdown не только в том, чтобы «писать», но и в том, «кому и как это показывать». YiziMarkdown предлагает одному документу семь способов представления: первые четыре — это режимы редактирования, переключающиеся между исходником и готовым результатом; последние три — отдельные сценарии, превращающие документ в слайды, книжные страницы или вовсе оставляющие только текст.

| Режим | Одной фразой | Вход | Кому подходит |
|------|-----------|------|------|
| Исходник | Прямое редактирование исходного Markdown | `F3` / кнопки вида | Точная правка структуры, массовая замена, front matter |
| Бок о бок | Слева пишете, справа сразу сверяете | `F3` / кнопки вида | Вычитка вёрстки, письмо по шаблону |
| Живой | WYSIWYG, разметка скрывается автоматически | `F3` / кнопки вида | Долгие тексты, сосредоточенное письмо |
| Предпросмотр | Показывается только итоговая вёрстка | `F3` / кнопки вида | Проверка результата, чтение целиком |
| Презентация | Документ сразу показывается слайдами | `Ctrl+Alt+P` / панель инструментов | Поделиться, отчёт, лекция |
| Чтение | Документ вёрстан в перелистываемую книгу | `Ctrl+Alt+R` / панель инструментов | Долгое чтение, EPUB, погружение в текст |
| Дзен | Интерфейс убирается, остаётся только текст | `F9` / панель инструментов | Глубокое письмо |

`F3` переключает по кругу между исходником / бок о бок / живым / предпросмотром; у презентации, чтения и дзена свои входы, они не конфликтуют.

## Markdown: четыре в одном

![Сравнение четырёх режимов](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/4modes.webp)

Исходник, бок о бок, живой режим и предпросмотр используют одно ядро редактора и один набор возможностей Markdown; разница только в «плотности информации»: от полностью открытой разметки до полностью свёрстанного результата. Переключаться можно в любой момент, и вид по возможности сохраняет текущую позицию.

### Режим исходника: видно всё, что нужно

- Ядро CodeMirror 6: подсветка синтаксиса, сопоставление скобок, автодополнение
- Номера строк и перенос строк включаются независимо; подходит для построчной правки и массовых изменений
- YAML frontmatter показывается как есть — при правке метаданных не нужно угадывать формат
- Таблицы, блоки кода и формулы показываются в виде исходника — самый управляемый вариант для сложных структур

### Режим «бок о бок»: пишете и сверяете

- Слева исходник, справа предпросмотр, обновление сразу при вводе
- Синхронизацию прокрутки задаёт структура заголовков; при переключении вида текущая позиция определяется автоматически
- Подходит для вычитки вёрстки и перестройки структуры по готовому документу

### Живой режим: что видите, то и получаете

- При вводе разметка Markdown скрывается, а когда курсор уходит — возвращается, чтобы вы сосредоточились на содержании
- 4 собственные анимации появления разметки (фокус / вспышка / свечение / рябь), их можно просмотреть и переключить в настройках
- YAML front matter отображается как редактируемая панель свойств в стиле Obsidian: авто / текст / число / флажок / дата / дата и время / список — 7 типов, тип запоминается глобально по имени свойства

### Режим предпросмотра: только результат

- Markdown отрисовывается сразу при письме, флажки списка задач можно нажимать
- Изображения по локальным путям, из сети и SVG отрисовываются автоматически (jpg / png / gif / webp / svg / bmp)
- frontmatter скрывается автоматически — вы видите итоговую вёрстку

### Что общего у всех четырёх видов

- **Поиск и замена**: навигация по совпадениям, замена всех
- **Форматирование с панели**: жирный, курсив, зачёркивание, встроенный код — выделение сразу оборачивается
- **Улучшения блоков кода**: подсветка highlight.js, ярлыки языков, кнопка копирования, переключение переноса строк
- **Выбор таблицы**: вставка по сетке 8×8 в один клик, число строк и столбцов видно сразу, добавление и удаление строк и столбцов, а также меню по правому клику — всё под рукой
- **Формулы и диаграммы**: KaTeX: встроенные `$...$` / блочные `$$...$$`, Mermaid — блок-схемы, диаграммы последовательностей, диаграммы Ганта, диаграммы классов, круговые и т. д., цвета следуют теме
- **Сворачивание панели форматирования**: автоматически сворачивается при сужении окна, можно развернуть вручную
- **Номера строк и перенос строк**: включаются в настройках
- **Навигация по структуре**: уровни заголовков берутся из структуры документа и связаны с позицией прокрутки

## Режим презентации: заметки в один клик превращаются в слайды

![Режим презентации](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/slide.webp)

Готовые заметки больше не нужно экспортировать в PPT: со встроенным навыком AI-помощника они в один клик превращаются в краткую версию для презентации, вы переключаетесь в режим презентации — и документ сразу становится полноэкранными слайдами. Разбивка на страницы, колонки и макеты выводятся из структуры Markdown автоматически; когда нужен точный контроль, используйте директивы в HTML-комментариях.

### Содержание становится слайдами

- Никакого дополнительного формата: `---` (горизонтальная линия) разбивает на слайды
- `***` отдельной строкой внутри страницы делит её на колонки, максимум 4
- Движок анализирует структуру страницы и сам выбирает макет: для заголовков, списков, таблиц, кода, изображений и диаграмм есть свои

### 14 макетов

Обложка, страница раздела, финальная страница, оглавление, содержание, список, таблица данных, дорожная карта, текст с изображением, изображение, цитата, код, диаграмма (Mermaid), формула.

- Кроме «текст с изображением», который требует явного `<!-- layout: figure -->`, все остальные макеты выводятся из содержания
- Страницы содержания выровнены по левому краю, заголовок с подчёркиванием цвета темы
- На странице цитаты диагональные крупные кавычки: открывающая вверху слева, закрывающая внизу справа, содержимое по центру по вертикали
- Обложка автоматически читает `author` / `date` из front matter

### Управление вёрсткой во время презентации

- Настройки HUD: шрифт (по теме / без засечек / с засечками / моноширинный), насыщенность, размер, ширина и высота области содержимого (50%–95%)
- Изменения применяются сразу и сохраняются — следующий показ использует их
- Слишком длинный встроенный код переносится, а не обрезается краем страницы
- Явные директивы: `<!-- layout: xxx -->` задаёт макет, `<!-- align: left|center|right -->` выравнивает всю страницу

### Показ и навигация

- Слева внизу название раздела и номер слайда, вдоль нижнего края — полоса прогресса цвета темы
- `T` открывает выдвижное оглавление, `G` или поле внизу переходит к слайду
- Колесо мыши листает: если содержимое прокручивается, сначала прокручивается оно, на границе — переход
- `F` — полный экран / восстановление, работает из любого состояния окна, включая обычное и развёрнутое
- После выхода состояние окна восстанавливается; кнопка выхода справа вверху скрывается через 1,5 с бездействия
- Наследование темы: цвета заголовков следуют теме, во время показа можно менять тему и светлый/тёмный режим

## Режим чтения: документ вёрстан в перелистываемую книгу

![Режим чтения](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/reading.webp)

Режим чтения — это не «предпросмотр на весь экран», а настоящая вёрстка текста в фиксированные страницы: с обложкой, титульным листом, оглавлением, номерами страниц, а также бумагой и анимацией перелистывания.

- Вход: кнопка книги на панели инструментов или `Ctrl+Alt+R`; `Esc` выходит и восстанавливает прежний вид
- Раскладка: тонкая рамка с равными полями по четырём сторонам обрамляет страницы, две страницы соединены, между ними только одна разделительная линия; название книги вверху слева, название главы / номер страницы внизу слева, HUD внизу справа — так же, как в режиме презентации
- Обложка, титульный лист и оглавление создаются автоматически: название берётся из front matter `title` или первого H1, оглавление строится по заголовкам с номерами страниц и при избытке разбивается на страницы
- Настоящая пагинация: разворот из двух страниц (в узком окне — одна страница), с номерами страниц и прогрессом чтения

### Анимация перелистывания

4 варианта, переключаются в настройках, по умолчанию горизонтальное скольжение:

- **Горизонтальное скольжение** (по умолчанию): страница целиком сдвигается — чётко и быстро
- **3D-перелистывание**: лист загибается от нижнего правого угла, складываясь по средней линии, при перелистывании бумага приподнимается, с освещением и падающей тенью (в одностраничном режиме — вокруг корешка)
- **Плавное появление** / **Масштабирование**: более спокойные переходы

Быстрые повторные нажатия не пропускают страницы; переходы по оглавлению, номерам страниц и сноскам идут без анимации.

### Правила разбиения на страницы

Абзацы разбиваются по строкам, заголовок не остаётся один в конце страницы, заголовок таблицы повторяется на следующей странице, блоки кода продолжаются построчно, списки продолжаются по пунктам, изображение целиком масштабируется пропорционально; абзацы основного текста получают отступ первой строки в два знака, на продолжении страницы отступ не повторяется.

### Навигация и детали

- Выдвижное оглавление: `T`, список по уровням заголовков с номерами страниц, клик ведёт прямо туда
- `G` или поле номера страницы переходит к указанной странице
- Сноски туда и обратно: клик по ссылке ведёт к странице определения с подсветкой, есть кнопка «вернуться к ссылке»; внутренние якоря тоже переходят по страницам
- HUD чтения: внизу справа можно переключить светлый/тёмный режим, выбрать тему и шрифт (тема / с засечками / без засечек / моноширинный), размер и межстрочный интервал — всё действует только для текущего чтения
- Запоминание позиции: номер страницы / глава запоминается по документу, при повторном входе восстанавливается
- Управление: стрелки, PageUp / PageDown, пробел, колесо, а также клик по левому или правому краю страницы

### EPUB

Открытие `.epub` сразу включает режим чтения: используется тема чтения приложения (CSS издателя игнорируется), читаются встроенная обложка, оглавление, изображения, формулы, Mermaid SVG, сноски и межглавные ссылки. DRM-шифрование и фиксированная вёрстка (комиксы / фотоальбомы) пока не поддерживаются.

## Режим дзен: остаётся только текст

![Режим дзен](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/zen.webp)

Вход по `F9` или кнопкой режима дзен на панели инструментов. Панель инструментов, панель вкладок, боковая панель, AI-панель и строка состояния слоями складываются к краям экрана и растворяются, остаётся только текст; весь процесс **не меняет раскладку**, текст не сдвигается ни на пиксель.

- **Мир по-прежнему рядом**: прижмите указатель к любому краю экрана (верх / лево / право / низ), и соответствующая область плавно проявляется на прежнем месте; примерно через 1,2 с после ухода указателя она снова сворачивается
- **Постоянный переключатель**: кнопка режима дзен не исчезает и всегда остаётся на месте (вокруг неё едва заметная дышащая рябь) — это и якорь состояния «вы в дзене», и выход; `F9` / `Esc` тоже выводят
- **Только для письма**: доступен лишь в режимах «Исходник» / «Живой»; при переключении на «бок о бок», предпросмотр или входе в чтение / презентацию он выходит автоматически
- **Более чистая бумага**: скрыты номера строк и вертикальные линии боковой панели, очень лёгкая виньетка, указатель скрывается после 2 с неподвижности; вертикальная полоса прокрутки заменена минимальной тонкой полоской, появляющейся при прокрутке или рядом с правым краем

## Файлы и письмо

### Файлы и вкладки

- **Открытие**: `.md` / `.markdown` / `.txt` / `.epub`, EPUB сразу открывается в режиме чтения
- **Один экземпляр**: несколько открываемых файлов автоматически сливаются в существующее окно, повторно открытый файл переключает на соответствующую вкладку
- **Панель вкладок**: переключение, закрытие, создание, перетаскивание для сортировки
- **Главная страница**: список недавно открытых файлов с размером и временем изменения
- **Статус сохранения**: дышащая точка, пока файл не сохранён, после сохранения — анимация подтверждения ✅
- **Подтверждение закрытия**: сохранить / не сохранять / отмена

### Создание и шаблоны

- Новая пустая вкладка показывает «Безымянный новый файл»
- «Создать из шаблона» на панели инструментов создаёт документ по структуре Markdown выбранного шаблона; в разделе Настройки → Общие можно задать шаблон по умолчанию, и тогда `Ctrl+N` будет применять его
- Шаблоны хранятся в каталоге пользователя, достаточно положить `.md`, также можно создавать / редактировать их в разделе Настройки → Шаблоны

### Вставка как Markdown

Форматированный текст, скопированный с веб-страниц, Word / DOCX, Google Docs, Notion и т. п., при вставке в памяти преобразуется в чистый Markdown (заголовки / списки / таблицы / код / цитаты / ссылки); готовый исходник Markdown и обычный текст вставляются как есть.

### Сохранение и экспорт

- **Сохранение / автосохранение**: ручное сохранение + настраиваемый интервал (5–180 с, по умолчанию 60 с)
- **Сохранить как**: при сохранении нового файла автоматически открывается диалог «Сохранить как»
- **Экспорт**: HTML / Markdown / обычный текст / Word (DOCX) / PDF / PPTX / EPUB
  - DOCX использует нативную семантику Word (списки, таблицы, блоки кода, цитаты, списки задач), стили таблиц соответствуют предпросмотру, изображения поддерживают локальные пути, сетевые изображения и HTML `<img>` (ширину можно задать через `width`)
  - PDF совпадает с предпросмотром по точности и разбивается на страницы автоматически
  - HTML дополняется плавающей карточкой оглавления слева, клик по пункту ведёт к разделу (в PDF боковой панели нет)
  - PPTX наследует тему, светлый/тёмный режим и макеты режима презентации, выдаёт редактируемый текст, таблицы, изображения, фигуры и нативные формулы
  - EPUB предоставляется встроенным плагином; перед экспортом можно выбрать разбивку по главам / обложку / видимое оглавление / тему чтения / сведения о документе
- **Связывание файлов `.md`**: в настройках одним нажатием назначается редактор Markdown по умолчанию в системе (реестр Windows / macOS LaunchServices)

### Облачное хранилище (WebDAV)

- **Проводник файлов**: вкладка «Облако» на боковой панели показывает дерево каталогов сервера, позволяет открывать документы, создавать файлы / папки, переименовывать, перемещать, удалять; навигационная цепочка глубокого каталога сворачивается в «…» с выпадающим переходом, папки подгружаются послойно
- **Сохранение в облако**: локальный документ загружается в один клик, изображения, на которые он ссылается по относительным путям, загружаются вместе с ним с сохранением структуры каталогов; `Ctrl+S` для облачного документа сразу записывает изменения обратно
- **Защита от конфликтов**: перед сохранением сравнивается ETag, если файл изменён другим устройством, появляется диалог с выбором «перезаписать версию на сервере» или «отказаться от локальных изменений и перезагрузить» — молчаливой перезаписи не бывает
- **Безопасность учётных данных**: имя пользователя и пароль хранятся в системном хранилище учётных данных (Диспетчер учётных данных Windows / связка ключей macOS) и не пишутся в файлы конфигурации
- **Совместимость**: стандартные сервисы WebDAV, такие как Nutstore, Nextcloud, Synology (рекомендуется пароль приложения)

## Расширения и персонализация

### AI-помощник (боковая панель чата)

- **18 поставщиков больших моделей + собственный сервис**: OpenAI, Anthropic, Gemini, xAI, Mistral, Groq, DeepSeek, Qwen, Zhipu GLM, Moonshot Kimi, Volcano Engine, SiliconFlow, MiniMax, Xiaomi MiMo, Meituan LongCat, OpenRouter, OpenCode Go, Ollama (локально); «собственный сервис» поддерживает два протокола — совместимый с OpenAI и совместимый с Anthropic, с самостоятельным заполнением Base URL, ID модели и ключа
- **Потоковый чат**: кнопка робота на панели инструментов открывает правую панель, ответ выводится потоком в реальном времени, можно остановить в любой момент
- **Процесс размышления**: reasoning / thinking рассуждающих моделей показывается в сворачиваемом блоке, по умолчанию свёрнут
- **Безопасность ключей**: API-ключи хранятся в системной связке ключей, поддерживается сохранение, очистка и проверка в один клик; для локальных эндпоинтов (llama.cpp / LM Studio / vLLM и др.) можно оставить пусто
- **Ссылка на текущий документ**: при включении текущий документ становится контекстом, можно задать лимит ссылки (64K~512K / без ограничения) и число раундов контекста (0~20, по умолчанию 3)
- **Сохранение результата**: копировать, вставить в позицию курсора или создать новый документ в один клик

### Навыки AI (Skill)

Кнопка ⚡ в поле ввода открывает меню навыков; выбранный тег навыка вставляется в позицию курсора, а промпт автоматически добавляется в контекст. Чтобы определить свои навыки, достаточно положить в каталог `skills/` файл `skills.json` + промпты `.md`. Встроены 5 навыков: «Выжимка для презентации», «Сводка документа», «Редактирование и шлифовка», «Перевод полного текста», «Форматирование Markdown».

### Плагины

- **Базовые возможности встроены по умолчанию**: такие семантические функции документа, как KaTeX / Mermaid / сноски / списки задач / TOC, не зависят от переключателей плагинов
- **Встроенный плагин**: экспорт EPUB (включён по умолчанию, отключается на странице плагинов; меню экспорта на панели инструментов появляется только когда он включён)
- **Стандарт плагинов**: manifest (версия / версия API / момент активации / разрешения / возможности) → проверка соответствия → ленивая активация → регистрация возможностей → очистка при отключении; текущая версия загружает только встроенные плагины, скомпилированные в приложение

### Темы и внешний вид

- **15 встроенных тем**: Liquid Glass Prism (по умолчанию), Академический синий, Яркий оранжевый, Техно, Минимализм, Журнальный стиль, Природа, Красный личи, Фиолетовый, Киберпанк, Facebook, Матрица, Мятный смузи, Закатное золото, Ретро-печатная машинка — у каждой светлая и тёмная палитра
- **Тёмный / светлый режим**: переключение одним нажатием (`F2`)
- **Настройка шрифтов**: отдельные шрифт, размер и межстрочный интервал для исходника и предпросмотра
- **Своя тема**: CSS пишется и сохраняется в разделе Настройки → Внешний вид → Свой CSS, на основе текущей темы создаётся «своя тема» — можно вставить целую новую тему или подправить несколько цветов, сохранение действует сразу
- **Расширение тем**: положите `.css` в каталог `themes/` и зарегистрируйте параметры в `themes/theme.json`, после перезапуска тема распознаётся автоматически; система токенов и правила описаны в `docs/THEME-DESIGN-SPEC.md`

### Языки и интерфейс

- **16 языков интерфейса**: упрощённый китайский (по умолчанию), традиционный китайский, English, 日本語, 한국어, Deutsch, Français, Español, Português, Italiano, Polski, Nederlands, Türkçe, Svenska, Українська, Русский
- Язык интерфейса переключается в разделе Настройки → Общие одним нажатием и действует сразу; тексты интерфейса, панель сочетаний клавиш и описания плагинов следуют за языком
- **Адаптация при первом запуске**: если у установщика нет языка, выбирается по системному языку, при отсутствии в списке поддержки — English; у пунктов языка есть английская метка `Language`, так что их легко найти и в китайском интерфейсе
- **Размер интерфейса**: 80%–120% (по умолчанию 100%), масштабируются только текст и значки интерфейса, размеры панелей и содержимое документа не затрагиваются
- **Панель настроек**: Общие, Внешний вид, Редактор, Живой режим, AI-помощник, Облако, Плагины, Сочетания клавиш, Шаблоны, Документы, О программе, Продукты, с мгновенным предпросмотром настроек

## Разработка

### Требования

- Node.js 18+
- Rust (stable)
- Tauri CLI (`npm install -g @tauri-apps/cli`)

### Запуск сервера разработки

```bash
cd code
npm install
npm run tauri:dev
```

### Значок в доке при разработке под Linux (необязательно)

Такие рабочие среды, как elementary / GNOME, ищут одноимённый `Icon` в `.desktop` по `WM_CLASS` окна; в режиме разработки установщика нет, значит нет и `.desktop`, и док показывает только общий значок (сам `_NET_WM_ICON` окна уже добавлен со стороны Rust, на установочные пакеты это не влияет). Выполните один раз:

```bash
npm run dev:icon           # записывает ~/.local/share/applications/yizimarkdown-dev.desktop
npm run dev:icon:remove    # отменяет
```

Затем перезапустите окно разработки — док покажет значок приложения.

### Сборка релиза

**Windows**

```bash
npm run tauri:build
```

Артефакты:
- Портативный exe: `src-tauri/target/release/yizimarkdown.exe`
- Установщик NSIS: `src-tauri/target/release/bundle/nsis/`

Установщик: при первой установке сначала выбирается язык установки (16 вариантов — все языки интерфейса приложения + бразильский португальский); тексты мастера и язык первого запуска после установки следуют этому выбору; обновление / автообновление не сбрасывают выбранный язык. Значки и графика боковой панели / заголовка лежат в `src-tauri/installer/`; после смены фирменных цветов перезапустите `powershell -ExecutionPolicy Bypass -File scripts/make-installer-art.ps1` для генерации.

После сборки вручную скопируйте exe и файлы ресурсов в каталог `public/YiziMarkdown-vX.X.X/` для распространения.

**macOS (универсальный бинарник, одновременно Intel и Apple Silicon)**

```bash
rustup target add aarch64-apple-darwin
npm run tauri:build -- --target universal-apple-darwin
```

Артефакты:
- Пакет приложения: `src-tauri/target/universal-apple-darwin/release/bundle/macos/YiziMarkdown.app`
- Установщик: `src-tauri/target/universal-apple-darwin/release/bundle/dmg/YiziMarkdown_<ver>_universal.dmg`

**Linux (deb + AppImage)**

```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential libssl-dev libayatana-appindicator3-dev librsvg2-dev patchelf
npm run tauri:build -- --bundles deb,appimage
```

Артефакты (**сейчас только amd64 / x86_64**; `arm64` deb и `aarch64` AppImage для ARM пока не публикуются):
- Пакет для Debian: `src-tauri/target/release/bundle/deb/YiziMarkdown_<ver>_amd64.deb` (около 16 МБ, устанавливается в `/usr/bin`, регистрирует пункт меню, значок и связь файлов `.md` / `.epub`)
- Универсальная версия без установки: `src-tauri/target/release/bundle/appimage/YiziMarkdown_<ver>_amd64.AppImage` (около 150 МБ, включает GTK / WebKit и медиакомпоненты GStreamer, запускается двойным щелчком)

Внимание: **собирать нужно на Ubuntu 22.04**. Бинарники, собранные на 24.04, требуют glibc 2.39 и сразу не запускаются на Ubuntu 22.04 (2.35) / Debian 12 (2.36); зависимость `deb` от `libwebkit2gtk-4.1-0` тоже задаёт нижнюю границу Ubuntu 22.04 / Debian 12 (в Debian 11 есть только webkit 4.0). `rpm` пока не предоставляется: в Fedora / openSUSE другие имена зависимостей, их нужно поддерживать отдельно.
