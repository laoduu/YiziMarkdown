# YiziMarkdown


![画像](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/index.png)

[简体中文](../../readme.md) | [繁體中文](./readme-zh-TW.md) | [English](./readme-en.md) | [日本語](./readme-ja.md) | [한국어](./readme-ko.md) | [Deutsch](./readme-de.md) | [Français](./readme-fr.md) | [Español](./readme-es.md) | [Português](./readme-pt.md) | [Italiano](./readme-it.md) | [Polski](./readme-pl.md) | [Nederlands](./readme-nl.md) | [Türkçe](./readme-tr.md) | [Svenska](./readme-sv.md) | [Українська](./readme-uk.md) | [Русский](./readme-ru.md)

**公式ウェブサイト：** https://md.yizigpt.com

YiziMarkdown は「書くこと」を中心に据えたクロスプラットフォームの Markdown エディタです。同じ `.md` ファイルを七つの表示方法で扱えます：`ソース編集`、`並べて表示での校正`、`リアルタイム執筆`、`完成プレビュー`、`スライドプレゼンテーション`、`書籍風リーディング`、そして文字だけを残して執筆に集中する`禅モード`。

- **Windows**：インストール版（NSIS インストーラー、アプリ内ワンクリック更新対応）と、展開するだけで使えるポータブル版 ZIP を用意
- **macOS**：ユニバーサルバイナリのインストールパッケージを提供。Intel と Apple Silicon のどちらでもネイティブに動作
- **Linux**：Debian 系の `deb` とインストール不要の `AppImage` を提供（Ubuntu 22.04+ / Debian 12+、現在は amd64 のみ）

なぜ Markdown エディタを開発したのか。市販の選択肢は、見た目がいまひとつだったり、機能が多すぎて肥大化していたりして、シンプルで美しく、しかも心地よく使えるツールはなかなか見つかりません。そこで YiziMarkdown が生まれ、三つのことを貫いています：**見た目の美しさ**、**強力な機能**、**多彩なシーン**。

こうして現在の`YiziMarkdown`ができあがりました。`3つの OS`、`7つの使用モード`、`16の表示言語`、`15のライト／ダーク対応テーマ`、`5つの AI Skill`、`7つのエクスポート形式`を備え、さらに AI アシスタントやクラウドストレージなどの革新的な機能、テーマ・スキル・プレゼンテーションに関する公開ドキュメントによって、他にはない使い方を組み立てられます。

これはもはや単純な Markdown エディタではなく、創作・仕事・暮らしのさまざまなドキュメントシーンを本当にカバーする多機能アプリです。

## 七つのモード：ひとつの文書、七つの見せ方

Markdown の価値は「書く」ことだけではなく、「誰に、どう見せるか」にもあります。YiziMarkdown は同じ文書に七つの見せ方を用意しています。最初の四つは編集ビューで、ソースと完成形の間を行き来します。後の三つは独立したシーンで、文書をスライドや本のページに変えたり、いっそ本文だけにしたりします。

| モード | ひとことでの位置づけ | 入口 | 向いている用途 |
|------|-----------|------|------|
| ソース | 生の Markdown を直接編集 | `F3` / ビューボタン | 構造の作り込み、一括置換、frontmatter の編集 |
| 並べて表示 | 左で書き、右で即座に照合 | `F3` / ビューボタン | レイアウトの校正、テンプレートに沿った執筆 |
| リアルタイム | 見たまま編集、マークアップは自動で非表示 | `F3` / ビューボタン | 長文執筆、集中して書く |
| プレビュー | 最終レイアウトだけを表示 | `F3` / ビューボタン | 完成物の確認、全文の通読 |
| プレゼンテーション | 文書をそのままスライドとして投影 | `Ctrl+Alt+P` / ツールバー | 共有、報告、講義 |
| リーディング | 文書をめくれる本として組む | `Ctrl+Alt+R` / ツールバー | 長文読書、EPUB、没入読書 |
| 禅 | インターフェースをすべて外し、文字だけを残す | `F9` / ツールバー | 深い執筆 |

`F3` はソース / 並べて表示 / リアルタイム / プレビューを循環します。プレゼンテーション、リーディング、禅にはそれぞれ独立した入口があり、互いに衝突しません。

## Markdown 4つの編集ビュー

![4つのモードの比較](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/4modes.webp)

ソース、並べて表示、リアルタイム、プレビューは同じエディタコアと同一の Markdown 機能を共有し、違いは「情報密度」だけです。完全に露出したマークアップから、きっちり組まれた完成形まで。いつでも切り替えられ、切り替え時にはビューができるだけ現在位置を保ちます。

### ソースモード：見えるべきものはすべて見える

- CodeMirror 6 コア：シンタックスハイライト、括弧の対応、自動補完
- 行番号と折り返しは個別にオン／オフ可能。行単位の作り込みや一括書き換えに向く
- YAML frontmatter をそのまま表示。メタデータを編集するときも形式を推測する必要がない
- 表、コードブロック、数式はソースのまま表示。構造が複雑なときほど制御しやすい

### 並べて表示モード：書きながら照合する

- 左にソース、右にプレビュー。入力すると即座に更新
- スクロール同期はアウトラインが駆動し、ビューを切り替えると現在位置へ自動的に移動
- レイアウトの校正や、既存文書に合わせた構造変更に向く

### リアルタイムモード：見たまま編集

- 入力中は Markdown のマークアップを自動で隠し、カーソルが離れると元に戻る。内容そのものに集中できる
- 独自開発の4種類のマーク出現アニメーション（フォーカス / フラッシュ / グロー / リップル）。設定でプレビューと切り替えが可能
- YAML front matter は Obsidian 風の編集可能なプロパティパネルとして描画：自動 / テキスト / 数値 / チェックボックス / 日付 / 日付と時刻 / リストの7種類。型はプロパティ名ごとにグローバルに記憶

### プレビューモード：完成形だけを見る

- Markdown は書くと同時に描画され、タスクリストのチェックボックスは直接クリックできる
- ローカルパスの画像、ネットワーク画像、SVG を自動描画（jpg / png / gif / webp / svg / bmp）
- frontmatter は自動で非表示。見えるものが最終レイアウト

### 四つのビューが共有する機能

- **検索と置換**：一致箇所のナビゲーション、すべて置換
- **ツールバーの書式設定**：太字、斜体、取り消し線、インラインコード。選択範囲をその場で囲む
- **コードブロックの拡張**：highlight.js によるシンタックスハイライト、言語ラベル、コピーボタン、折り返しの切り替え
- **表の選択グリッド**：8×8 のグリッドをクリックして挿入。行数・列数が一目で分かり、行や列の追加・削除、右クリックの多機能メニューも揃う
- **数式とダイアグラム**：KaTeX のインライン `$...$` / ブロック `$$...$$`、Mermaid のフローチャート、シーケンス図、ガントチャート、クラス図、円グラフなど。配色はテーマに追従
- **書式ツールバーの折りたたみ**：ウィンドウが狭くなると自動で収納。手動での展開も可能
- **行番号と折り返し**：設定でオン／オフ
- **アウトラインのナビゲーション**：見出しの階層は文書構造から取得し、スクロール位置と連動

## プレゼンテーションモード：ノートをワンクリックでスライドに

![プレゼンテーションモード](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/slide.webp)

書き上げたノートを PPT に書き出す必要はもうありません。内蔵の AI アシスタント Skill でワンクリックで簡潔なプレゼン版にまとめ、プレゼンテーションモードに切り替えれば、文書はすぐに全画面スライドになります。ページ分割、段組み、レイアウトは Markdown 構造から自動推定され、細かく制御したいときは HTML コメントのディレクティブを使います。

### 内容がそのままスライド

- 追加の書式は不要：`---`（水平線）でページを分割
- ページ内で単独行の `***` が段組みになり、最大4段
- エンジンがページ全体の構造を解析してレイアウトを自動選択：見出し、リスト、表、コード、画像、ダイアグラムにそれぞれ対応するレイアウトがある

### 14 種類のレイアウト

表紙、セクション区切り、クロージング、目次、コンテンツ、リスト、データ表、ロードマップ、図とテキスト、画像、引用、コード、ダイアグラム（Mermaid）、数式。

- 「図とテキスト」は `<!-- layout: figure -->` で明示指定する必要があるが、それ以外のレイアウトは内容から自動推定される
- コンテンツページは左揃えで、タイトルにはテーマ色の下線
- 引用ページは対角の大きな引用符：開き引用符は左上、閉じ引用符は右下、内容は上下中央
- 表紙は front matter の `author` / `date` を自動で読み取る

### プレゼン中のタイポグラフィ制御

- HUD で調整可能：フォント（テーマに従う / サンセリフ / セリフ / 等幅）、ウェイト、サイズ、コンテンツ領域の幅と高さ（50%〜95%）
- 変更は即時反映され、永続化。次回のプレゼンでも引き継がれる
- 長いインラインコードは自動で折り返され、ページ端で切れなくなる
- 明示ディレクティブ：`<!-- layout: xxx -->` でレイアウトを強制、`<!-- align: left|center|right -->` でページ全体の揃えを指定

### プレゼン中の操作とナビゲーション

- 左下に章名とページ番号、下部にテーマ色のプログレスバー
- `T` で目次ドロワーを開く。`G` または下部の入力欄でページ移動
- マウスホイールでページ送り：内容がスクロール可能なときは先に内容をスクロールし、端に達したらページを送る
- `F` でフルスクリーン / 復元。通常・最大化など任意のウィンドウ状態から進入できる
- 終了時は進入前のウィンドウ状態に自動復元。右上の終了ボタンは1.5秒無操作で自動的に隠れる
- テーマの継承：タイトルの配色はテーマに追従し、プレゼン中もテーマと明暗を切り替えられる

## リーディングモード：文書をめくれる本に組む

![リーディングモード](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/reading.webp)

リーディングモードは「全画面プレビュー」ではなく、本文を本当に固定ページへ組み上げます。表紙、扉、目次、ページ番号があり、紙面とページめくりのモーションもあります。

- 入口：ツールバーの本のボタンまたは `Ctrl+Alt+R`。`Esc` で終了し、元のビューに戻る
- 版面：四辺が等しい余白の細い罫線がページを包み、見開きは連結して中央の綴じ目には区切り線が一本だけ。書名は左上、章名 / ページ番号は左下、HUD は右下で、位置はプレゼンテーションモードと揃う
- 表紙、扉、目次ページを自動生成：書名は front matter の `title` または最初の H1 から取得。目次は見出しから生成されてページ番号付き、長い場合は自動で分割
- 本物のページ分割：見開き（狭いウィンドウでは自動で単ページ）、ページ番号と読書進捗付き

### ページめくりアニメーション

4種類から選択でき、設定で切り替え。既定は水平スライド：

- **水平スライド**（既定）：ページ全体が平行移動。きびきびとして明快
- **3D めくり**：紙葉が右下からめくれ、中央の綴じ目を軸に折れ曲がる。めくる際は紙面が浮き上がり、受光と影を伴う（単ページモードでは背表紙を軸に回転）
- **フェード** / **ズーム**：より静かなトランジション

連打してもページを飛ばしません。目次、ページ番号、脚注などからのジャンプではアニメーションを再生しません。

### ページ単位の分割ルール

段落は行単位で分割、見出しがページ末尾に取り残されない、表は続きページでヘッダーを繰り返す、コードブロックは行単位で継続、リストは項目単位で継続、ブロック画像は等比縮小。本文段落は自動で2文字分の字下げを行い、続きページでは字下げを繰り返さない。

### ナビゲーションと細部

- 目次ドロワー：`T` で開き、見出し階層ごとにページ番号付きで一覧、クリックで直接移動
- `G` またはページ番号入力欄で指定ページへ移動
- 脚注の往復：引用をクリックすると定義ページへ移動してハイライトし、「引用に戻る」ボタンを提供。内部アンカーも同様にページ単位で移動
- リーディング HUD：右下で明暗、テーマ、フォント（テーマ / セリフ / サンセリフ / 等幅）、サイズと行間を切り替え。今回の読書にのみ適用
- 位置の記憶：文書ごとにページ番号 / 章を記憶し、再度入ると自動復元
- 操作：方向キー、PageUp / PageDown、スペース、ホイールでページ送り。ページの左右端をクリックしてもめくれる

### EPUB

`.epub` を開くと直接リーディングモードに入ります：アプリの読書テーマを使用し（出版社の CSS は無視）、埋め込みの表紙、ナビゲーション目次、画像、数式、Mermaid SVG、脚注、章をまたぐリンクを読み取ります。DRM 暗号化と固定レイアウト（漫画 / 画集）は現在未対応です。

## 禅モード：文字だけを残す

![禅モード](https://github.com/laoduu/YiziMarkdown/raw/main/assets/readme/zen.webp)

`F9` またはツールバーの禅モードボタンで入ります。ツールバー、タブバー、サイドバー、AI パネル、ステータスバーが層ごとに画面の端へ折り畳まれてフェードアウトし、本文だけが残ります。その過程で**レイアウトは変わりません**。本文は1ピクセルも動きません。

- **世界はまだそこにある**：ポインタを画面のいずれかの端（上 / 左 / 右 / 下）に寄せると、その領域がその場でフェードインして戻る。離れると約1.2秒で自動的に引っ込む
- **常設スイッチ**：禅モードボタンは消えず、常に元の位置に留まる（周囲にごく淡い呼吸のような波紋）。「禅モード中である」ことの状態アンカーであり、退出経路でもある。`F9` / `Esc` でも退出できる
- **執筆のためだけに**：ソース / リアルタイムモードでのみ使用可能。並べて表示、プレビューに切り替えるか、リーディング / プレゼンテーションに入ると自動的に退出
- **より澄んだ紙面**：行番号とサイドバーの縦線を隠し、ごく淡いビネット、ポインタは2秒静止で自動的に隠れる。縦スクロールバーは極細のバーに置き換わり、スクロール時または右端に近づいたときに現れる

## ファイルと執筆

### ファイルとマルチタブ

- **開く**：`.md` / `.markdown` / `.txt` / `.epub` に対応。EPUB は直接リーディングモードに入る
- **単一インスタンスモード**：複数ファイルを開くと既存のウィンドウに自動で統合され、既に開いているファイルは該当タブに移動
- **タブバー**：切り替え、閉じる、新規作成、ドラッグでの並べ替えに対応
- **ホームページ**：最近開いたファイルの一覧。サイズと更新日時付き
- **保存状態**：未保存ファイルは呼吸するドット、保存後は ✅ の確認アニメーション
- **閉じる確認**：未保存時は保存 / 保存しない / キャンセルを提示

### 新規作成とテンプレート

- 新規の空タブには「名称未設定の新規ファイル」と表示
- ツールバーの「テンプレートから新規作成」はテンプレートの Markdown 構造から文書を作成。設定 → 一般 で既定テンプレートを指定すると、以降 `Ctrl+N` で自動適用
- テンプレートはユーザーディレクトリに保存され、`.md` を置くだけで使える。設定 → テンプレート で新規作成 / 編集も可能

### 貼り付けるだけで Markdown

Web ページ、Word / DOCX、Google Docs、Notion などからコピーしたリッチテキストは、貼り付け時にメモリ上で正規の Markdown（見出し / リスト / 表 / コード / 引用 / リンク）に変換されます。既存の Markdown ソースとプレーンテキストはそのまま貼り付きます。

### 保存とエクスポート

- **保存 / 自動保存**：手動保存 + 設定可能な間隔（5〜180秒、既定60秒）
- **名前を付けて保存**：新規ファイルの保存時に保存ダイアログが自動で開く
- **エクスポート**：HTML / Markdown / プレーンテキスト / Word（DOCX）/ PDF / PPTX / EPUB
  - DOCX は Word ネイティブのセマンティクス（リスト、表、コードブロック、引用、タスクリスト）を使用し、表のスタイルはプレビューと揃う。画像はローカルパス、ネットワーク画像、HTML `<img>` に対応（`width` で幅を制御可能）
  - PDF はプレビューとの再現性が一致し、自動でページ分割
  - HTML は左側にフローティングのアウトラインカードを付け、項目をクリックすると章へ直接移動（PDF にはサイドバーなし）
  - PPTX はプレゼンテーションモードのテーマ、明暗、レイアウトを継承し、編集可能なテキスト、表、画像、図形、ネイティブ数式を出力
  - EPUB は内蔵プラグインが提供。エクスポート前に章分割 / 表紙 / 表示目次 / 読書テーマ / 文書情報を選択可能
- **.md ファイルの関連付け**：設定でワンクリックでシステム既定の Markdown エディタに設定（Windows レジストリ / macOS LaunchServices）

### クラウドストレージ（WebDAV）

- **ファイルブラウザ**：サイドバーの「クラウド」タブでサーバーのディレクトリツリーを閲覧。文書を開く、ファイル / フォルダの新規作成、名前変更、移動、削除が可能。深い階層のパンくずは「…」に折り畳まれ、ドロップダウンでジャンプ。フォルダは階層ごとに遅延読み込み
- **クラウドへ保存**：ローカル文書をワンクリックでアップロード。本文中で相対参照されている画像も一緒にアップロードされ、ディレクトリ構造を保持。クラウド文書は `Ctrl+S` で直接書き戻し
- **競合保護**：保存前に ETag を比較。リモートが他のデバイスで変更されていれば、「サーバー版を上書き」か「ローカルの変更を破棄して再読み込み」を選ぶダイアログを表示し、決して無言で上書きしない
- **認証情報の安全**：ユーザー名とパスワードはシステムの資格情報ストア（Windows 資格情報マネージャー / macOS キーチェーン）に保存し、設定ファイルには書き込まない
- **互換性**：Nutstore、Nextcloud、Synology などの標準 WebDAV サービス（アプリ専用パスワードの使用を推奨）

## 拡張とカスタマイズ

### AI アシスタント（サイドチャットパネル）

- **18 社の大規模モデルプロバイダー + カスタムサービス**：OpenAI、Anthropic、Gemini、xAI、Mistral、Groq、DeepSeek、Qwen、Zhipu GLM、Moonshot Kimi、Volcano Engine、SiliconFlow、MiniMax、Xiaomi MiMo、Meituan LongCat、OpenRouter、OpenCode Go、Ollama（ローカル）。「カスタムサービス」は OpenAI 互換 / Anthropic 互換の2プロトコルに対応し、Base URL、モデル ID、キーを自分で入力
- **ストリーミング対話**：ツールバーのロボットボタンで右側パネルを開き、返答をリアルタイムでストリーミング出力。いつでも停止可能
- **思考プロセス**：推論モデルの reasoning / thinking を折りたたみ可能なブロックで表示。既定では折りたたみ
- **キーの安全**：API キーはシステムのキーチェーンに保存し、ワンクリックでの保存、削除、検証に対応。ローカルエンドポイント（llama.cpp / LM Studio / vLLM など）は空欄のままでよい
- **現在の文書を参照**：チェックすると現在の文書をコンテキストとして使用。参照上限（64K〜512K / 無制限）とコンテキストのターン数（0〜20、既定3）を設定可能
- **結果の反映**：コピー、カーソル位置への挿入、またはワンクリックでの新規文書作成

### AI スキル（Skill）

入力欄の ⚡ ボタンでスキルメニューが開き、選択するとスキルタグがカーソル位置に挿入され、プロンプトが自動的にコンテキストへ注入されます。`skills/` ディレクトリに `skills.json` + `.md` プロンプトを置けば独自に定義できます。内蔵スキルは「プレゼン原稿の抽出」「文書要約」「推敲・書き換え」「全文翻訳」「Markdown フォーマット」の5つです。

### プラグイン

- **コア機能は既定で内蔵**：KaTeX / Mermaid / 脚注 / タスクリスト / TOC などの文書セマンティクス機能はプラグインのオン／オフの影響を受けない
- **内蔵プラグイン**：EPUB エクスポート（既定で有効、プラグインページで無効化可能。有効にするとツールバーのエクスポートメニューが現れる）
- **プラグイン標準**：manifest（バージョン / API バージョン / 有効化のタイミング / 権限 / 機能）→ 適格性チェック → 遅延有効化 → 機能登録 → 無効化時のクリーンアップ。現行バージョンはアプリにコンパイルされた内蔵プラグインのみを読み込む

### テーマと外観

- **15 種の内蔵テーマ**：Liquid Glass Prism（既定）、アカデミックブルー、ヴィヴラントオレンジ、テック、ミニマル、マガジン、ナチュラル、ライチレッド、ヴァイオレット、サイバーパンク、Facebook、マトリックス、ミント、サンセット、レトロタイプライター。各テーマにライトとダークの2配色
- **ダーク / ライトモード**：ワンクリック切り替え（`F2`）
- **フォントのカスタマイズ**：ソースとプレビューでそれぞれフォント、サイズ、行の高さを設定
- **カスタムテーマ**：設定 → 外観 → カスタム CSS に書いて保存すると、現在のテーマをベースに「カスタムテーマ」が生成される。テーマ全体を貼り付けても、数色だけ微調整してもよく、保存で即時反映
- **テーマ拡張**：`themes/` ディレクトリに `.css` を置き、`themes/theme.json` にパラメータを登録すると、再起動後に自動認識。トークン体系と仕様は `docs/THEME-DESIGN-SPEC.md` を参照

### 多言語とインターフェース

- **16 種の表示言語**：簡体字中国語（既定）、繁体字中国語、English、日本語、한국어、Deutsch、Français、Español、Português、Italiano、Polski、Nederlands、Türkçe、Svenska、Українська、Русский
- 設定 → 一般 → 表示言語でワンクリック切り替え、即時反映。UI 文言、ショートカットパネル、プラグインの説明も言語に連動
- **初回起動時の自動判定**：インストーラーの言語がない場合はシステム言語で選択し、サポート外なら English にフォールバック。言語項目には英語の `Language` 表記が付くため、中国語 UI でもすばやく見つけられる
- **UI の文字サイズ**：80%〜120%（既定 100%）。UI の文字とアイコンのみを拡大縮小し、パネルのサイズと文書内容は影響を受けない
- **設定パネル**：一般、外観、エディタ、リアルタイムモード、AI アシスタント、クラウド、プラグイン、ショートカット、テンプレート、ドキュメント、アプリについて、製品。設定は即時プレビュー

## 開発

### 必要環境

- Node.js 18+
- Rust (stable)
- Tauri CLI（`npm install -g @tauri-apps/cli`）

### 開発サーバーの起動

```bash
cd code
npm install
npm run tauri:dev
```

### Linux 開発時のタスクバーアイコン（任意）

elementary / GNOME などのデスクトップは、ウィンドウの `WM_CLASS` から同名の `.desktop` にある `Icon` を探します。開発状態にはインストーラーがなく `.desktop` も存在しないため、Dock には汎用アイコンしか表示されません（ウィンドウ自体の `_NET_WM_ICON` は Rust 側で補完済みで、インストーラー版には影響しません）。一度だけ実行してください：

```bash
npm run dev:icon           # ~/.local/share/applications/yizimarkdown-dev.desktop に書き込み
npm run dev:icon:remove    # 取り消し
```

その後 dev ウィンドウを再起動すると、Dock にアプリアイコンが表示されます。

### リリース版のビルド

**Windows**

```bash
npm run tauri:build
```

ビルド成果物：
- ポータブル版 exe：`src-tauri/target/release/yizimarkdown.exe`
- NSIS インストーラー：`src-tauri/target/release/bundle/nsis/`

インストールウィザード：初回インストール時にインストール言語を選択します（16 種類：アプリの全表示言語 + ブラジルポルトガル語）。ウィザードの文言とインストール後の初回起動時の言語はその選択に従い、アップグレード / 自動更新でユーザーが選んだ言語がリセットされることはありません。アイコンとサイドバー / ヘッダー画像は `src-tauri/installer/` にあり、ブランドカラーを変更したら `powershell -ExecutionPolicy Bypass -File scripts/make-installer-art.ps1` を再実行して生成します。

ビルド後、exe とリソースファイルを手動で `public/YiziMarkdown-vX.X.X/` ディレクトリにコピーして配布します。

**macOS（ユニバーサルバイナリ、Intel と Apple Silicon の両方に対応）**

```bash
rustup target add aarch64-apple-darwin
npm run tauri:build -- --target universal-apple-darwin
```

ビルド成果物：
- アプリバンドル：`src-tauri/target/universal-apple-darwin/release/bundle/macos/YiziMarkdown.app`
- インストーラー：`src-tauri/target/universal-apple-darwin/release/bundle/dmg/YiziMarkdown_<ver>_universal.dmg`

**Linux（deb + AppImage）**

```bash
sudo apt install libwebkit2gtk-4.1-dev build-essential libssl-dev libayatana-appindicator3-dev librsvg2-dev patchelf
npm run tauri:build -- --bundles deb,appimage
```

ビルド成果物（**現在は amd64 / x86_64 のみ提供**；ARM の `arm64` deb と `aarch64` AppImage は未公開）：
- Debian 系インストーラー：`src-tauri/target/release/bundle/deb/YiziMarkdown_<ver>_amd64.deb`（約 16 MB、`/usr/bin` にインストールし、メニュー項目、アイコン、`.md` / `.epub` のファイル関連付けを登録）
- 汎用インストール不要版：`src-tauri/target/release/bundle/appimage/YiziMarkdown_<ver>_amd64.AppImage`（約 150 MB、GTK / WebKit と GStreamer メディアコンポーネントを同梱、ダブルクリックですぐ使える）

注意：**Ubuntu 22.04 上でビルドする必要があります**。24.04 でビルドしたバイナリは glibc 2.39 を要求し、Ubuntu 22.04（2.35）/ Debian 12（2.36）では起動に失敗します。`deb` の `libwebkit2gtk-4.1-0` 依存も同じく下限を Ubuntu 22.04 / Debian 12 に固定しています（Debian 11 には webkit 4.0 しかありません）。`rpm` は未提供です：Fedora / openSUSE は依存名が Debian 系と異なり、個別に保守する必要があります。

## バージョンと更新

Windows インストール版はアプリ内でワンクリック更新が可能です。macOS、Linux、ポータブル版は起動時に `latest.json` を確認し、新バージョンがあれば右下に通知して該当バージョンのダウンロードページを開きます（手動での置き換えで、自動インストールは行いません。Linux の `deb` と `AppImage` もこの経路を使います）。
