# 演示模式：纯 Markdown → 自动版式

YiziMarkdown 的演示模式（幻灯片）**不需要任何额外格式**：你按平时写 Markdown 的习惯写，引擎根据整页内容的结构自动排版，配色继承当前主题。本文是「Markdown 写什么 → 演示效果是什么」的对照参考。

相关代码：
- 分页与版式推断：`src/lib/slides.ts`
- 解析与渲染（演示 / 导出共用）：`src/lib/slideDeck.ts`
- 渲染与主题继承：`src/components/Slideshow.tsx`
- 幻灯片样式：`src/styles/slideshow.css`
- PPTX 导出：`src/lib/pptxExport.ts`（编排）、`pptxFrame.ts`（1280×720 测量）、`pptxScene.ts`（DOM → 场景图）、`pptxBuild.ts`（PptxGenJS + XML 后处理）

---

## 唯一规则：分页

用**单独成行的 `---`**（标准 Markdown 水平分割线）翻页：

```markdown
# 第一页

---

# 第二页
```

- `---` 必须单独成行（前后是空行）
- 代码围栏（```` ``` ````）内部的 `---` 是代码内容，**不会**分页
- 文档顶部的 front matter（首个 `--- ... ---` 块）自动忽略，不会成为一页

除了这一条，其余全部是你已经会的 Markdown。

## 自动版式：整页结构 → 幻灯片效果

引擎分析每页的**完整块结构**（标题层级、内容类型、组合方式）自动选择版式，无需任何标记：

| 一页的内容结构 | 自动版式 | 效果 |
|----------------|---------|------|
| `# 一级标题` + 副标题段落 | **封面页** | 居中大标题 + 主题色渐变下划线，底部作者/日期 meta 行 |
| `## 标题` 单独成页 | **章节页** | 大号序号 + 章节标题居中，过渡感 |
| `# 谢谢 / Thanks / Q&A` | **结尾页** | 居中大字收尾 |
| 整页有序列表（3 项以上） | **目录页** | 大号数字编号，双列网格排布 |
| `## 标题` + 段落 | **内容页** | 标题左上 + 强调下划线，正文左对齐 |
| `## 标题` + 列表 | **列表页** | 标题左上，列表大号强调 |
| `## 标题` + 表格 | **数据表页** | 表头主题色、斑马纹行 |
| 任务列表（`- [ ]`） | **路线图页** | 大号勾选框，进度感 |
| 图片开头（后面可跟文字） | **图片页** | 图片居中，图与文按书写顺序纵向排列 |
| `> 引用` | **引用页** | 大引号 + 居中大字 |
| ` ``` 代码围栏` | **代码页** | 代码聚焦居中 |
| `` ```mermaid `` | **图表页** | 图表居中 |
| 块级公式（`$$`） | **公式页** | 公式居中放大 |

> 版式判定依赖**整页结构**（不只首块），无需配置，用户无感知、零学习成本。
>
> **`figure`（图文页 / 左图右文）已从自动推断中移除**（v0.3.4）：并排是「想要才要」的版式，不该由引擎猜 —— 想并排用 `***` 分栏，还能自由决定几栏与对齐。`figure` 仍作为 `<!-- layout: figure -->` 的合法取值保留，样式未删。

### 排版约定

- **内容页**：标题左上对齐 + 主题色短下划线；正文、列表左对齐，阅读舒适。
- **封面 / 章节 / 结尾 / 目录 / 引用**：整体居中，突出仪式感。
- **图片**：单独成块的图片（无论有无标题）**默认居中**——`.ys-slide > img` 收缩到原生尺寸后靠 `align-items:center` 落到中线，不再被 `.ys-slide > *` 的 `width:100%` 拉满整行。

### 分栏：`***`

一页内想并排放两块内容，用**单独成行的 `***`**（标准 Markdown 主题分割线）圈出栏区。
`***` 同时承担**栏区边界**与**栏分隔**两种身份 —— 类比表格的 `|`：既是左右外框，也是内线，靠位置决定：

```markdown
## 对比

引言（栏外）

***

- 左侧第一条
- 左侧第二条

***

- 右侧第一条
- 右侧第二条

***

落款（栏外）
```

- `---` = **分页**，`***` = **分栏**（同为标准分割线，语义分开）
- **N 栏写 N+1 条 `***`**：首尾两条是栏区**边界**，中间的是**分隔**；
  栏区**之外**的内容是页级文案（`splitColumns` 的 `before` / `after`），整页横跨、不参与分栏
- **退化规则**（不是兼容垫片）：条数 ≤2 时圈定读法退化成「空栏区」（1 条）或「单栏」（2 条），
  作者不可能是那个意思 ⇒ 这两档按**分隔**读（旧语义：条数 + 1 = 栏数），存量文档不受影响。
  唯一的代价：写满 4 栏（3 条）会被读成「2 栏 + 栏外文案」，语法上无法区分、也无法检测
- 必须单独成行；代码围栏内的 `***` 是代码内容，**不参与计数**，因此不会破坏圈定
- **页内第一个标题**（`#`~`######`）视为**页标题**，整页显示在分栏之上、不参与分栏
  （`splitColumns` 把它抽成 `intro`；否则标题会落进第 1 栏，出现「左栏带标题、右栏内容顶端高于标题」的错位）
- 最多 4 栏，超出时后续内容并入最后一栏（控制台提示，内容不丢）
- 注意：`***` 从此不再渲染为 `<hr>`（需要页内分隔线请用 `___` 或 `- - -`）
- 分栏数独立于版式：`.ys-cols` 容器由 `getSlideHtml` 生成，栏数经行内变量 `--ys-cols` 下发；
  页标题**不包 div**、直接作为 `.ys-slide` 的直接子元素 ⇒ 各版式的 `h2` 规则与
  `> :first-child` 装饰仍能命中它，标题样式与不分栏时一致；
  栏外文案（`before` / `after`）**包一层 `.ys-col-aside`**：它是页级内容，落在 `.ys-cols` 之外，
  因此「栏内对齐 / 卡片 / 分隔线」这些栏内规则天然碰不到它 —— 它跟随版式与页标题，不跟随栏内对齐；
  页面容器以 `.ys-slide.ys-has-cols` 退回单列 flex，避免与 `figure` 版的 `display:grid` 冲突（见 `src/styles/slideshow.css`）

#### 栏内对齐 / 分栏样式（HUD「演示排版」，v0.3.4）

分栏内容默认**左对齐**，可在播放中点击 HUD 的 `Aa` 图标调整（持久化在 `settingsStore`，纯函数在 `src/lib/slideColumns.ts`）：

| 旋钮 | 取值 | 说明 |
|------|------|------|
| 栏内对齐 | `left`（默认）/ `center` / `right` | 栏**内**的标题、正文、列表、引用、图片、代码块一并对齐；**页标题不参与** |
| 分栏样式 | `card`（默认）/ `line` / `none` | `card` = 每栏一张等高主题卡片；`line` = 栏间中缝细线；`none` = 无参照 |

**为什么需要它们** —— 分栏是等宽栅格，设栏宽为 `W`、栏间距为 `g`，则第 2 栏的左边线

```
左缘 + (W_total − g)/2 + g = 屏幕中心 + g/2      ← W_total 被完全消掉
```

即**与「内容填充宽度」无关**，拖滑杆时右栏左边线纹丝不动，只有左栏在飘。栏内容少时用户会觉得「右边没反应」。
对齐解决「栏内内容怎么排」，卡片给每栏一个随宽度**两侧同时伸缩**的可见外框 —— 两者配合才让栏的实际占位可感知。

实现要点（`src/styles/slideshow.css` 的「分栏对齐」「分栏样式」两段）：

- 值在 JS 里合成（`resolveColAlign`：**页级 `<!-- align -->` 覆盖 HUD 全局默认**），CSS 只认 `.ys-slide.ys-col-align-*` 一个来源，无需与 `.ys-align-*` 争夺优先级
- 每条规则都带 `.ys-has-cols` 且从 `.ys-cols` 往下走：只作用于**分栏页的栏内内容**，非分栏页 / 页脚 / HUD / 页标题都不受影响
- 栏内的标题、列表、引用在基础排版里被写死为 `text-align:left`（`.ys-slide h1` / `ul` / `blockquote`），必须用 `:is()` 一并抬高特异性才能翻过来
- 中/右对齐给栏的直接子块加 `width:fit-content` + `margin:auto` —— 只写 `text-align` 对图片 / 代码块 / 表格这些块盒无效（`.ys-cols > .ys-col > *` 已把 width 钉成 100%）；对文本则是无损的，折行位置不变
- 右对齐时列表的内边距与项目符号一起翻到右侧（比页级 `.ys-align-right` 更彻底：它只改 `ul` 的 padding，`li` 仍留着 1.5em 左内边距）
- **页标题（`intro`）刻意不参与栏对齐**：它是页面层级的元素（`.ys-slide` 的直接子元素、在 `.ys-cols` 之外），继续跟所属版式走（内容页左对齐、封面/章节页居中）。让页标题跟着栏内走会打散「一屏一个标题」的层级
- 卡片用主题既有令牌（`--editor-surface` / `--editor-border` / `--editor-accent` / `--radius-lg` / `--shadow-1`）+ `color-mix`，明暗与主题自动跟随；内边距用 `em` ⇒ 随「字号」旋钮一起缩放；卡片开启时 `.ys-cols` 由 `align-items:start` 转为 `stretch`（等高，对比才有参照）
- 分隔线画在栏间 gap 的正中线上（`left: -1.2vw`），不改变栏宽与间距；`position:relative` 只在该样式下加，避免改变栏内绝对定位后代的包含块
- **默认值的取舍**：对齐默认 `left` 无对应规则 ⇒ 逐像素零变化；样式默认 **`card`** ⇒ 会产出 `ys-col-style-card`。后者是**有意的默认观感升级**（卡片是这组旋钮的价值所在，默认藏起来等于没做），存量用户升级后分栏页会直接看到卡片；只有显式选 `none` 才退回无参照的旧观感

## 可选：显式指令（覆盖自动版式）

自动版式在绝大多数场景足够；个别页面需要精确控制时，可在该页任意位置用 HTML 注释指定（渲染时不可见，不影响预览）：

```html
<!-- layout: content-list -->
<!-- align: left -->
```

- `<!-- layout: <类型> -->`：显式指定版式，覆盖自动推断（类型见上表，如 `cover` / `section` / `agenda` …；`figure` 只能靠这条指令指定，不会自动命中）。**非法值会被忽略并回落自动推断**
- `<!-- align: left|center|right -->`：整页对齐方向；**分栏页上它同时覆盖 HUD 的「栏内对齐」**（页级 > 全局，见上文「栏内对齐 / 分栏样式」）
- `<!-- fragments: off|on -->`：关闭 / 恢复该页片段逐步显示（见下节）

显式指令优先于结构推断，适合需要精确控制的进阶场景。

## 片段逐步显示（默认关闭）

内容页 / 列表页 / 路线图页的**顶层列表项**可逐条出现：播放时按 `→` 先显示下一条，全部显示后再按才翻页；按 `←` 先回退一条，退完再翻页（翻回的页面列表全显）。

```markdown
## 产品优势

- 第一条（开启后逐条出现）
- 第二条
- 第三条
```

**默认关闭**（列表整页显示，避免目录等内容被迫逐条点击）。开启方式：

| 粒度 | 写法 / 操作 | 效果 |
|------|------|------|
| 播放中切换 | HUD 底部列表图标 | 即时生效，仅本次播放 |
| 整副开启 | front matter `slideshow-fragments: on` | 全部符合条件的页面逐条出现 |
| 单页开启 | 页内 `<!-- fragments: on -->` | 覆盖 deck 级关闭 |
| 单页关闭 | 页内 `<!-- fragments: off -->` | 该页整页显示 |

- 仅内容页 / 列表页 / 路线图页生效；封面、章节、目录、表格、图表、公式、引用等版式整页显示
- 嵌套子列表随父项一起出现，无需单独标记

## 切换动画（播放中可选）

播放中点击 HUD 底部 ✨ 图标切换翻页动画（仅本次播放生效）。

**柔和型**：

| 动画 | 效果 |
|------|------|
| 水平滑动 | 新页从右滑入 + 淡入（默认） |
| 淡入淡出 | 纯透明度溶解 |
| 轻微缩放 | 轻微缩放进出 |
| 无动画 | 直接切换 |

**强烈型**：

| 动画 | 效果 |
|------|------|
| 高斯溶解 | 水渍从多点渗开、互相吞并，有机边缘吞没整页（12 层软边径向渐变 mask + `@property --ys-blob` 驱动半径，新页同时 blur→0） |
| 百叶窗格 | 整页切成竖条，每条绕自身中轴翻面露出下一页（瓷砖转场 · strip） |
| 棋盘格子 | 整页拆成方格，随机次序 3D 翻面露出下一页，随后融合回落（瓷砖转场 · square） |
| 百变立方 | 每格绕自身竖轴转 180°，三面各沿法线平移半格宽 ⇒ 中途露出侧面（瓷砖转场 · 3 面） |
| 六角蜂巢 | 整页切成蜂巢状六边形（尖顶六边形铺砖：行距 3h/4 + 相邻行错位半宽，r/c 从 -1 起补出界格才是严格无缝），各自随机次序翻面；裁形挂在面上、影用卡片级 box-shadow（六边形无缝 ⇒ 矩形影多出的方角被邻格的面盖住，不露方角；实测逐格 drop-shadow 会让帧率从 60 掉到 34fps） |
| 爆裂卡片 | 旧页碎片带随机方向旋转飞散，新页碎片从反方向飞入归位（瓷砖转场 · 冲量） |
| 纵深穿梭 | 每格有不同纵深，翻面时前后穿梭产生视差（瓷砖转场 · 冲量 z） |
| 卡片推换 | 当前页缩小成卡片向左移出，新页卡片从右进入后放大落定；后退完全镜像 |

> 「瓷砖转场」= 整页连同背景被切成单元，每个单元是一个窗口 + 一份【整页克隆】负偏移对齐（正面旧页、背面新页），因此每格能独立做 2D/3D 变换与独立时序。切割形状 / 延迟节奏 / 单格时长由 `src/lib/slideTiles.ts` 的 `TILE_VARIANTS` 配置驱动（有单元测试 `tests/slideTiles.test.ts`），CSS 只负责"怎么动"。
>
> 强烈型中的 mask 动画依赖 CSS `@property` 与 mask 合成（Chromium 85+ / WebView2 均支持）；不支持的引擎自动降级为淡入淡出。

## 配色：主题继承

- 幻灯片**自动继承应用当前主题与明暗**，无需配置。
- 取色来自主题的 CSS 变量（`--editor-bg/text/accent/surface/border/...`、`--font-sans/mono`），因此换主题，幻灯片同步换肤。
- **标题颜色**通过主题变量 `--editor-h1 / --editor-h2 / --editor-h3` 继承（各主题已定义这些变量，对应各自 h1/h2/h3 配色；深色模式另有取值）。行内代码用 `--editor-accent`。
- 主题 CSS 中的 `:root.theme-*` 会被自动改写为幻灯片作用域以提供变量；幻灯片的字号/对齐/居中由 `slideshow.css` 全权控制（不继承编辑器的元素排版规则，避免左对齐/小字号覆盖演示版式）。

## 导出为 PPTX

演示模式可以一键导出 `.pptx`，**不需要在 Markdown 里加任何标记**。导出结果是 PowerPoint 里的**原生可编辑对象**（文字、表格、图片、形状、原生公式），不是整页截图。

### 入口

- 编辑器工具栏 →「导出」菜单 →「PPTX」
- 演示模式右下角 HUD →「导出 PPTX」

两处打开的是**同一个导出弹窗**：HUD 入口多一个「只导当前页」选项；工具栏入口没有当前页，但提供「先看演示效果」按钮。

导出时：

- 主题、明暗、版式、演示字号、填充比例、分栏样式全部沿用演示的同一套解析与 CSS（演示与导出共用 `src/lib/slideDeck.ts`），暗色主题所见即所得，不会强制白底。
- 基准固定为 **16:9 / 1280×720**，与当前窗口大小无关；演示窗口更宽或更窄都不会改变导出结果。
- 先选保存路径，再逐页测量生成；弹窗里有进度与「取消导出」。
- 弹窗打开期间，演示的翻页键与滚轮翻页会挂起，避免误翻页。

### 弹窗选项

| 选项 | 默认 | 说明 |
|------|------|------|
| 范围 | 全部页 | 可选当前页（仅 HUD 入口）或自定义页码区间 |
| 演讲者备注 | 开启 | 把 `<!-- notes: … -->` 写进 PPT 的演讲者备注 |
| 页脚 | 开启 | 每页底部写「章节名 + 页码」 |
| 超页处理 | 警告并列出页码 | 也可选「自动压缩字号」：逐档缩小到 94% → 60%，让浏览器真实重排，而不是拉伸图片 |

导出结束后弹窗会列出告警（超页、公式回退、图片/图表失败等）；点告警旁的页码可直接跳到演示中的对应页。选择「警告并列出页码」时，超出可视区的内容会保持原尺寸，**底部可能被裁到页外**；介意裁切就选「自动压缩字号」。

### 元素映射

| Markdown / 演示内容 | PPTX 里的对象 |
|---------------------|--------------|
| 标题、段落、行内样式 | 独立文本框；加粗、斜体、删除线、行内代码、链接、字距、行距保留 |
| 列表 | 文本 + **手绘圆点 / 序号形状**（几何、颜色、字号取演示的伪元素样式），不是字符项目符号 |
| 表格 | 原生 PPT 表格；表头底色、行条纹、边框、对齐逐格还原 |
| 代码块 | 等宽文本框 + 背景卡片；保留高亮颜色与缩进 |
| 引用、卡片、分栏 | 圆角矩形 + 文本块（背景、边框、阴影按 computed style） |
| 封面 / 章节页的渐变下划线 | 原生形状 + `gradFill`（主题色 → 透明） |
| 行内 / 块级公式（KaTeX） | **原生 OMML 公式**，可在 PowerPoint 里编辑；转换失败回退为 `$TeX$` 纯文本并告警 |
| Mermaid 图表 | 重新渲染为纯文本标签 SVG 后由 Rust `resvg` 栅格化嵌入（与 DOCX 导出同源） |
| 本地 / 远程图片 | 内嵌 PNG / JPEG，保留演示里的圆角与阴影 |
| `<!-- notes: … -->` | 演讲者备注（notesSlide） |
| 页脚（章节名 + 页码） | 独立文本框 |

### 已知取舍

- 表格单元格只保留**纯文本**（多段落用换行分隔），单元格内的图片、公式不单独建对象。
- 与文字混排的**行内图片**不导出；单独成块的图片正常导出。
- `[toc]` 目录导出为文字，**不生成 PPT 内部超链接**。
- 动画、页面切换、片段分步、HUD、进度条不进入 PPTX：每页只导出「全部内容已显示」的最终状态。
- CJK 字体按 `latin / ea / cs` 拆分写进 XML；本机没有演示所用字体时，PowerPoint 可能回退到相近字体，宽度会略有差异。
- 极密内容即使缩到 60% 仍可能超页，此时弹窗会继续告警。

## 扩展版式（进阶）

如需新增或调整某类版式的观感，编辑 `src/styles/slideshow.css` 中 `.ys-layout-<类型>` 规则即可（`cover / section / thanks / agenda / content / content-list / table / roadmap / figure / image / quote / code / chart / formula`）。版式识别逻辑在 `src/lib/slides.ts` 的 `detectLayout`；标题颜色在主题文件的 `--editor-h1/h2/h3` 变量中调整。
