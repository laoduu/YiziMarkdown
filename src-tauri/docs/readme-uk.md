**Офіційний сайт:** https://md.yizigpt.com

Простий та елегантний кросплатформний редактор `Markdown`, що підтримує портативну версію Windows та macOS. Не потребує встановлення, розпаковуйте та використовуйте, поєднуючи красу з практичністю. Windows можна встановити або завантажити у вигляді zip-архіву для розпакування; macOS пропонує універсальний бінарний інсталятор, який працює як на Intel, так і на Apple Silicon.

Чому ми вирішили розробити редактор `Markdown`?

На ринку існує багато редакторів `Markdown`, які або мають непривабливий інтерфейс, або надто складні та громіздкі, і складно знайти інструмент для редагування, який був би одночасно простим, красивим та зручним у використанні.

Так з'явився YiziMarkdown.

Ми створили надзвичайно елегантний досвід для режиму WYSIWYG; крім того, підтримується швидка презентація, схожа на PPT, що дозволяє швидко перемикатися в режим презентації для зручного спільного використання та звітування. Спробуйте, щоб повірити.

## Можливості

### Багатомовний інтерфейс

- **15 мов інтерфейсу**: Спрощена китайська (за замовчуванням), Традиційна китайська, Англійська, Японська, Корейська, Німецька, Французька, Іспанська, Португальська, Італійська, Польська, Нідерландська, Турецька, Шведська, Українська
- Налаштування → Загальні → Одноразове перемикання мови інтерфейсу, миттєвий ефект; весь текст інтерфейсу, панелі гарячих клавіш та описи плагінів синхронізуються з мовою

### AI-помічник (бічна панель чату)

- **17 великих постачальників моделей + користувацький сервіс**: OpenAI, Anthropic, Gemini, xAI, Mistral, Groq, DeepSeek, Qwen, Zhipu GLM, Moonshot Kimi, Volcano Engine, SiliconFlow, MiniMax, OpenRouter, OpenCode Go, Ollama (локально); «Користувацький сервіс» підтримує протоколи, сумісні з OpenAI/Anthropic, заповніть Base URL, ID моделі та ключ самостійно, можна підключити будь-який сторонній сервіс
- **AI-навички (Skill)**: Натисніть кнопку ⚡ у полі введення, щоб відкрити меню навичок; після вибору тег навички вставляється курсор, а підказка автоматично додається до контексту; розмістіть файли `skills.json` + `.md` підказок у директорії `skills/` для налаштування власних навичок. Вбудовані 3 навички: «Структура презентації», «Резюме документа», «Полірування тексту»
- **Потоковий діалог**: Натисніть кнопку робота на панелі інструментів, щоб відкрити праву панель AI, відповіді виводяться в реальному часі, можна зупинити в будь-який момент
- **Відображення процесу мислення**: Контент мислення моделі міркувань (reasoning/thinking) відображається у згортному блоці, за замовчуванням згорнутий, не впливає на читання основного тексту
- **Безпека ключів**: API-ключі зберігаються в системному сховищі ключів (ОС keychain), підтримується одноразове збереження, очищення та перевірка; ключі локальних ендпоінтів (llama.cpp / LM Studio / vLLM тощо) можна залишити порожніми
- **Посилання на поточний документ**: Після позначення поточний документ надсилається як контекст до AI, можна налаштувати ліміт посилань (64K~512K/без обмежень) та кількість контекстних раундів (0~20 раундів, за замовчуванням 3)
- **Збереження результатів**: Відповіді можна копіювати, вставляти в позицію курсора документа або створювати новий документ одним кліком

### Редагування та попередній перегляд

- **Редагування вихідного коду**: Ядро CodeMirror 6, підсвітка синтаксису, зіставлення дужок, автодоповнення
- **Режим реального часу (WYSIWYG)**: Редагування "що бачиш, те й отримуєш", автоматично приховує маркери Markdown під час введення, зосереджуючись на створенні контенту
- **Анімація режиму реального часу**: 4 схеми анімації появи маркерів (Фокус/Спалах/Свічення/Брижі), можна переглядати та перемикати в налаштуваннях
- **Попередній перегляд реального часу**: Markdown рендериться під час написання, підтримує інтерактивні чекбокси списків завдань
- **П'ять режимів перегляду**: Вихідний код / Поруч / Реальний час (WYSIWYG) / Попередній перегляд / Презентація (повноекранні слайди), перемикання одним кліком
- **Синхронізація прокрутки за структурою**: У режимі "поруч" ліва та права панелі зв'язані двосторонньо, автоматично позиціонується до поточного місця при перемиканні режимів
- **Пошук та заміна**: Підтримує навігацію по збігах, заміну всіх
- **Швидке форматування на панелі інструментів**: Жирний, курсив, закреслений, вбудований код, миттєво обертає виділений текст
- **Рендеринг локальних зображень**: Режим попереднього перегляду автоматично рендерить зображення з локальних шляхів (jpg/png/gif/webp/svg/bmp)
- **Номери рядків / Перенос слів**: Обидва параметри можна ввімкнути/вимкнути в налаштуваннях
- **Покращений блок коду**: Підсвітка синтаксису (highlight.js), мовні мітки, кнопка копіювання, перемикання переносу слів
- **Згортання панелі форматування**: Автоматично згортається при недостатній ширині вікна, підтримує ручне розгортання/згортання
- **Фільтрація Frontmatter**: Режими попереднього перегляду/поруч/реального часу автоматично фільтрують YAML frontmatter

### Математичні формули та діаграми

- **Формули KaTeX**: Вбудований плагін KaTeX, вбудовані `$...$` та блочні `$$...$$` LaTeX-формули рендеряться в реальному часі
- **Діаграми Mermaid**: Вбудований плагін Mermaid, блок-схеми, діаграми послідовності, діаграми Ґанта, класні діаграми, кругові діаграми тощо автоматично рендеряться у візуальні графіки, підтримується конфігурація різних тем
- **Селектор рядків та стовпців таблиці**: Натисніть кнопку таблиці на панелі інструментів, щоб відкрити сітку 8×8, натисніть, щоб вставити таблицю з відповідною кількістю рядків та стовпців

### Режим презентації (слайди)

- **Чистий Markdown без додаткових форматів**: `---` (горизонтальна лінія) для розбиття на сторінки, движок аналізує структуру всієї сторінки та автоматично вибирає макет
- **14 автоматичних макетів**: Обкладинка, сторінка розділу, фінальна сторінка, зміст, вміст, список, таблиця даних, дорожня карта, текст-зображення, зображення, цитата, код, діаграма (mermaid), формула
- **Сторінка вмісту з вирівнюванням вліво та підкресленням**: Заголовок вирівнюється вліво вгору з підкресленням кольору теми, текст вмісту вирівнюється вліво, зручне читання
- **Сторінка цитати з діагональними лапками**: Відкриваюча лапка розташована вгорі зліва, закриваюча лапка — внизу справа, контент центровано по вертикалі
- **Явні інструкції**: `<!-- layout: xxx -->` для примусового вибору макету, `<!-- align: left|center|right -->` для вирівнювання всієї сторінки (HTML-коментарі, невидимі при рендерингу)
- **Метадані обкладинки**: Front matter надає `author`/`date`, обкладинка відображається автоматично
- **Нижній колонтитул та прогрес**: Назва розділу та номер сторінки внизу зліва, прогрес-бар кольору теми внизу
- **Переворот сторінки колесом миші**: Коли вміст прокручується, спочатку прокручується вміст, потім на межі — сторінка
- **Наслідування теми**: Кольори заголовків точно змінюються з темою (підтримуються всі 15 тем), можна перемикати тему/світлий-темний режим під час презентації
- **Перемикання повного екрану**: Клавіша F для повного екрану/відновлення, підтримується надійний вхід з будь-якого стану вікна (звичайний/максимізований)
- **Кнопка виходу**: Напівпрозора кнопка виходу з'являється вгорі справа при активності миші, автоматично зникає через 1,5 секунди бездіяльності
- **Відновлення стану вікна**: Автоматично відновлюється стан вікна перед входом (повний екран/максимізований/звичайний) при виході з презентації

### Система плагінів

- Плагінна архітектура, вбудовані два основні плагіни: KaTeX та Mermaid
- Сторінка «Плагіни» панелі налаштувань підтримує керування увімкненням/вимкненням та конфігурацію плагінів
- Пагіни завантажуються динамічно за потребою, вимкнені плагіни не витрачають ресурси

### Управління декількома файлами

- **Однорежимний режим**: Відкриття декількох файлів більше не запускає декілька вікон, автоматично об'єднується в існуючий екземпляр, повторно відкриті файли автоматично позиціонуються у відповідну вкладку
- **Панель вкладок**: Верхня частина керує кількома відкритими файлами, перемикання, закриття, створення нових
- **Головна сторінка**: Список нещодавно відкритих файлів, включає розмір файлу та час зміни
- **Індикатор збереження**: Незбережені файли показують анімацію дихаючої точки, збережені файли показують анімацію підтвердження ✅
- **Підтвердження закриття**: Незбережені файли запитують підтвердження зберегти / не зберігати / скасувати при закритті

### Операції з файлами

- **Відкриття**: Підтримує .md / .markdown / .txt
- **Створення нового**: Створює порожню вкладку, показує «Неназваний новий файл»
- **Створення з шаблону**: Випадаюче меню «Створити з шаблону» на панелі інструментів, створює новий документ на основі Markdown-структури вибраного шаблону; також можна встановити шаблон за замовчуванням у Налаштування → Загальні, потім `Ctrl+N` автоматично застосовується
- **Збереження / Автозбереження**: Ручне збереження + автозбереження з налаштовуваним інтервалом (5~180 секунд, за замовчуванням 60 секунд)
- **Зберегти як**: Автоматично відкриває діалог «Зберегти як» при збереженні нових файлів
- **Експорт**: Три формати: HTML / Markdown / Текст
- **Асоціація .md файлів**: Одноразове встановлення як редактора Markdown за замовчуванням у налаштуваннях, подвійне клацання .md відкриває безпосередньо (реєстр Windows / LaunchServices macOS)

### Налаштування зовнішнього вигляду

- **П'ятнадцять вбудованих тем**: Академічна синя (за замовчуванням), Жива помаранчева, Технологічна, Мінімалістична, Журнальна, Природна, Рідке скло, Лічі червона, Фіолетова, Киберпанк, Facebook, Матриця, М'ятний мус, Захід сонця, Ретро-друкарська, кожна зі світлою та темною колірними схемами
- **Темний / Світлий режим**: Кожна тема має світлу та темну колірні схеми
- **Налаштування шрифту**: Режими вихідного коду та попереднього перегляду можуть окремо налаштовувати шрифт, розмір шрифту, висоту рядка
- **Користувацький CSS**: `user.css` перевизначає після всіх тем, найвищий пріоритет
- **Розширення тем**: Розмістіть файли `.css` у директорії `themes/`, додайте параметри теми в `themes/theme.json`, автоматично розпізнається після перезапуску

### Інше

- **Шаблони документів**: Розмістіть файли `.md` у директорії `templates/`, можна вибирати при створенні нового
- **Система гарячих клавіш**: Візуальна панель налаштування гарячих клавіш, підтримує налаштування прив'язки для 30 дій, запис клавіш, виявлення конфліктів та відновлення за замовчуванням
- **Панель налаштувань**: Загальні, Зовнішній вигляд, Редактор, Режим реального часу, AI, Плагіни, Гарячі клавіші, Шаблони, Про нас та інші вкладки, налаштування застосовуються миттєво

## Розробка

### Вимоги до середовища

- Node.js 18+
- Rust (stable)
- Tauri CLI (`npm install -g @tauri-apps/cli`)

### Запуск сервера розробки

```bash
cd code
npm install
npm run tauri:dev
```

### Збирання релізної версії

**Windows**

```bash
npm run tauri:build
```

Результати збирання:
- Портативний exe: `src-tauri/target/release/yizimarkdown.exe`
- MSI-інсталятор: `src-tauri/target/release/bundle/msi/`
- NSIS-інсталятор: `src-tauri/target/release/bundle/nsis/`

Після збирання вручну скопіюйте exe та файли ресурсів до директорії `public/YiziMarkdown-vX.X.X/` для розповсюдження.

**macOS (Універсальний бінарний файл, підтримує як Intel, так і Apple Silicon)**

```bash
rustup target add aarch64-apple-darwin
npm run tauri:build -- --target universal-apple-darwin
```

Результати збирання:
- Пакет додатку: `src-tauri/target/universal-apple-darwin/release/bundle/macos/YiziMarkdown.app`
- Інсталятор: `src-tauri/target/universal-apple-darwin/release/bundle/dmg/YiziMarkdown_0.2.2_universal.dmg`
