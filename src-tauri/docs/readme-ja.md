# YiziMarkdown


![image](https://github.com/laoduu/YiziMarkdown/raw/main/docs/index.png)

[简体中文](../readme.md) | [繁體中文](./readme-zh-TW.md) | [English](./readme-en.md) | [日本語](./readme-ja.md) | [한국어](./readme-ko.md) | [Deutsch](./readme-de.md) | [Français](./readme-fr.md) | [Español](./readme-es.md) | [Português](./readme-pt.md) | [Italiano](./readme-it.md) | [Polski](./readme-pl.md) | [Nederlands](./readme-nl.md) | [Türkçe](./readme-tr.md) | [Svenska](./readme-sv.md) | [Українська](./readme-uk.md)


**公式ウェブサイト：** https://md.yizigpt.com

シンプルで洗練されたクロスプラットフォーム `Markdown` エディタ。Windows ポータブル版と macOS 版をサポート。インストール不要、解凍してすぐに使える。見た目と実用性を兼ね備えています。Windows ではインストールも、圧縮ファイルを解凍して使うことも可能です。macOS ではユニバーサルバイナリインストールパッケージを提供しており、Intel と Apple Silicon の両方でネイティブに動作します。

なぜ `Markdown` エディタを開発するのか？

市場には多くの `Markdown` エディタがありますが、どれもインターフェースの見た目がいまひとつだったり、機能が複雑で肥大化していたりして、シンプルで美观上品な上に使いやすい編集ツールを見つけるのは困難でした。

そこで YiziMarkdown が生まれました。

WYSIWYG モードにおいて、極めてエレガントな体験を創造しました。さらに PPT 風のクイックプレゼンテーション機能もサポートしており、作成したノートやドキュメントをすぐにプレゼンテーションモードに切り替えて、共有やプレゼンテーションに活用できます。試してみてください。

## 機能特性

### 多言語インターフェース

- **15のインターフェース言語**：简体中文（デフォルト）、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Português、Italiano、Polski、Nederlands、Türkçe、Svenska、Українська
- 設定 → 一般 → インターフェース言語をワンクリックで切り替え、即座に反映。すべてのインターフェース文言、ショートカットキーパネル、プラグイン説明が言語に連動します

### AI アシスタント（サイドチャットパネル）

- **17の大規模言語モデルプロバイダー + カスタムサービス**：OpenAI、Anthropic、Gemini、xAI、Mistral、Groq、DeepSeek、通義千問、智譜 GLM、Moonshot Kimi、火山方舟、硅基流動、MiniMax、OpenRouter、OpenCode Go、Ollama（ローカル）；「カスタムサービス」は OpenAI 互換 / Anthropic 互換の2つのプロトコルをサポートし、Base URL、モデル ID、キーを入力することで任意のサードパーティサービスに接続可能
- **AI スキル（Skill）**：入力欄の ⚡ ボタンでスキルメニューを表示、選択後にスキルタグがカーソル位置に挿入され、プロンプトが自動的にコンテキストに注入。`skills/` ディレクトリに `skills.json` + `.md` プロンプトを配置するだけでスキルをカスタマイズ可能。内蔵「プレゼンテーション要約」「ドキュメント摘要」「文章推敲」の3つのスキル
- **ストリーミング会話**：ツールバーのロボットボタンで右側の AI パネルを開き、返答がリアルタイムでストリーミング出力。いつでも停止可能
- **思考過程の表示**：推論モデルの思考内容（reasoning/thinking）を折りたたみ可能なブロックで表示。デフォルトでは折りたたまれており、本文の閲覧を妨げません
- **キーの安全性**：API キーはシステムキーチェーン（OS keychain）に保存。ワンクリックで保存、クリア、検証が可能。ローカルエンドポイント（llama.cpp / LM Studio / vLLM など）のキーは空欄のままにできます
- **現在のドキュメントを参照**：チェックを入れると、現在のドキュメントをコンテキストとして AI に送信。参照上限（64K〜512K/無制限）とコンテキスト轮数（0〜20轮、デフォルト3轮）を設定可能
- **結果の保存**：返答はコピー、ドキュメントのカーソル位置への挿入、ワンクリックで新規ドキュメント作成が可能

### 編集とプレビュー

- **ソースコード編集**：CodeMirror 6 コア、シンタックスハイライト、括弧のマッチング、自動補完
- **リアルタイムモード（WYSIWYG）**：所見即所得編集、入力時に Markdown マークを自動的に非表示にし、コンテンツ作成に集中
- **リアルタイムモードアニメーション**：4種のマーク出現アニメーション（フォーカス/フラッシュ/グロー/リップル）、設定でプレビューと切り替えが可能
- **リアルタイムプレビュー**：Markdown を書くと即座にレンダリング。タスクリストのチェックボックス操作をサポート
- **5つのビューモード**：ソース / 並列 / リアルタイム（WYSIWYG） / プレビュー / プレゼン（フルスクリーンスライド）、ワンクリックで切り替え
- **アウトライン駆動スクロール同期**：並列モードで左右パネルが双方向に連動。ビュー切替時に自動的に現在位置にジャンプ
- **検索と置換**：マッチ項目のナビゲーション、すべて置換をサポート
- **ツールバークイックフォーマット**：太字、斜体、取り消し線、インラインコード。テキストを選択してそのまま適用
- **ローカル画像レンダリング**：プレビューモードでローカルパスの画像（jpg/png/gif/webp/svg/bmp）を自動レンダリング
- **行番号 / 自動折り返し**：設定でオン/オフを切り替え可能
- **コードブロック強化**：シンタックスハイライト（highlight.js）、言語タグ、コピーボタン、自動折り返し切替
- **フォーマットツールバー折りたたみ**：ウィンドウ幅が不足した場合に自動折りたたみ。手動で展開/折りたたみが可能
- **Frontmatter フィルタリング**：プレビュー/並列/リアルタイムモードで YAML frontmatter を自動フィルタリング

### 数学式とチャート

- **KaTeX 数式**：内蔵 KaTeX プラグイン。インライン `$...$` とブロック `$$...$$` の LaTeX 数式をリアルタイムでレンダリング
- **Mermaid チャート**：内蔵 Mermaid プラグイン。フローチャート、シーケンス図、ガントチャート、クラス図、円グラフなどを自動で可視化チャートにレンダリング。複数のテーマ設定をサポート
- **テーブル行列セレクター**：ツールバーのテーブルボタンで 8×8 グリッドを表示。マウスでクリックするだけで該当する行数・列数のテーブルを挿入

### プレゼンモード（スライド）

- **純 Markdown ドリブン**：追加のフォーマットは不要。`---`（水平線）でページ区切り。エンジンがページ全体の構造を分析し、自動的にレイアウトを選択
- **14種の自動レイアウト**：表紙、章ページ、結びページ、目次、コンテンツ、リスト、データテーブル、ロードマップ、テキスト＋画像、画像、引用、コード、チャート（mermaid）、数式
- **コンテンツページ左揃え + 強調アンダーライン**：タイトルは左上揃えでテーマカラーのアンダーライン付き。本文は左揃えで、読書が快適
- **引用ページ対角線大型引用符**：上の引用符は左上に、下の引用符は右下に配置。コンテンツは上下中央揃え
- **明示的ディレクティブ**：`<!-- layout: xxx -->` でレイアウトを強制。`<!-- align: left|center|right -->` でページ全体の揃えを制御（HTML コメント、レンダリング時に非表示）
- **表紙メタ情報**：front matter で `author`/`date` を提供すると、表紙に自動表示
- **フッターと進捗**：左下に章名 + ページ番号。底部にテーマカラーのプログレスバー
- **マウスホイールでページ送り**：コンテンツがスクロール可能な場合は先にコンテンツをスクロールし、境界に達したらページ送り
- **テーマ継承**：タイトルの色がテーマに合わせて正確に変化（15のテーマすべてサポート）。プレゼン中にテーマ/明暗を切り替え可能
- **フルスクリーン切替**：F キーでフルスクリーン/復元。任意のウィンドウ状態（通常/最大化）から確実に entering 可能
- **終了ボタン**：マウスが動いた時に右上に半透明の終了ボタンを表示。1.5 秒操作なしで自動的に非表示
- **ウィンドウ状態の復元**：プレゼン終了時に entering 前のウィンドウ状態（フルスクリーン/最大化/通常）に自動復元

### プラグインシステム

- プラグイン化アーキテクチャ。内蔵 KaTeX と Mermaid の2つのコアプラグイン
- 設定パネルの「プラグイン」ページでオン/オフ制御とプラグイン設定をサポート
- プラグインは必要に応じて動的にロード。未有効時はリソースを消費しません

### マルチファイル管理

- **シングルインスタンスモード**：複数ファイルを開いても複数のウィンドウを起動せず、既存のインスタンスに自動マージ。重複して開かれたファイルは対応するタブに自動定位
- **Tab タブバー**：上部で開いている複数のファイルを管理。切り替え、閉じる、新規作成
- **ホームページ**：最近開いたファイルリスト。ファイルサイズと変更時刻を表示
- **保存状態インジケーター**：未保存ファイルには呼吸するドットアニメーション。保存後に ✅ 確認アニメーション
- **閉じる確認**：未保存ファイルを閉じる際に保存/保存しない/キャンセルの確認ダイアログを表示

### ファイル操作

- **開く**：.md / .markdown / .txt をサポート
- **新規作成**：新規空白タブを開き「無名の新規ファイル」と表示
- **テンプレートから新規作成**：ツールバーの「テンプレートから新規作成」ドロップダウンメニュー。選択したテンプレートの Markdown 構造に基づいて新規ドキュメントを作成。設定 → 一般 でデフォルトテンプレートを設定すると、`Ctrl+N` で自動適用
- **保存 / 自動保存**：手動保存 + 設定可能な間隔の自動保存（5〜180秒、デフォルト60秒）
- **名前を付けて保存**：新規ファイルの保存時に自動的に名前を付けて保存ダイアログを表示
- **エクスポート**：HTML / Markdown / プレーンテキストの3つの形式
- **.md ファイル関連付け**：設定でワンクリックでシステムのデフォルト Markdown エディタに設定。.md をダブルクリックで直接開く（Windows レジストリ / macOS LaunchServices）

### 外観カスタマイズ

- **15の内蔵テーマ**：アカデミックブルー（デフォルト）、バイブラントオレンジ、テック、ミニマル、マガジン、ネイチャー、リキッドグラス、ライチレッド、バイオレット、サイバーパンク、Facebook、マトリックス、ミントスムージーサンセット、タイピスト。各テーマに明暗2つの配色
- **ダーク / ライトモード**：各テーマに明暗2つの配色
- **フォントカスタマイズ**：ソースモードとプレビューモードでそれぞれフォント、フォントサイズ、行間を設定
- **カスタム CSS**：`user.css` がすべてのテーマの後に適用され、最優先
- **テーマ拡張**：`themes/` ディレクトリに `.css` ファイルを配置し、`themes/theme.json` にテーマパラメータを追加。再起動後に自動認識

### その他

- **ドキュメントテンプレート**：`templates/` ディレクトリに `.md` ファイルを配置。新規作成時に選択可能
- **ショートカットキーシステム**：ビジュアルショートカットキー設定パネル。30のアクションのカスタムバインド、キー録音、衝突検出、デフォルト復元をサポート
- **設定パネル**：一般、外観、エディタ、リアルタイムモード、AI、プラグイン、ショートカットキー、テンプレート、など複数のタブを搭載。設定は即座にプレビュー

## 開発

### 環境要件

- Node.js 18+
- Rust (stable)
- Tauri CLI (`npm install -g @tauri-apps/cli`)

### 開発サーバーの起動

```bash
cd code
npm install
npm run tauri:dev
```

### リリースビルド

**Windows**

```bash
npm run tauri:build
```

ビルド成果物：
- ポータブル版 exe：`src-tauri/target/release/yizimarkdown.exe`
- MSI インストーラー：`src-tauri/target/release/bundle/msi/`
- NSIS インストーラー：`src-tauri/target/release/bundle/nsis/`

ビルド後、exe とリソースファイルを手動で `public/YiziMarkdown-vX.X.X/` ディレクトリにコピーして配布。

**macOS（ユニバーサルバイナリ、Intel と Apple Silicon の両方をサポート）**

```bash
rustup target add aarch64-apple-darwin
npm run tauri:build -- --target universal-apple-darwin
```

ビルド成果物：
- アプリケーションパッケージ：`src-tauri/target/universal-apple-darwin/release/bundle/macos/YiziMarkdown.app`
- インストーラー：`src-tauri/target/universal-apple-darwin/release/bundle/dmg/YiziMarkdown_0.2.2_universal.dmg`
