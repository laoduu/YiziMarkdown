# 欢迎使用 YiziMarkdown

一款以「写作」为中心的跨平台 `Markdown` 编辑器。同一份 `.md` 文件，提供七种呈现方式：源码编辑、并排校对、实时书写、成品预览、幻灯片演示、成书阅读，以及只留下文字的禅模式。

支持 Windows（安装版 / 便携版）、macOS（Intel 与 Apple Silicon 通用二进制）与 Linux（`deb` / `AppImage`）。免安装，解压即用，兼顾颜值与实用。

为什么要开发一款 `Markdown` 编辑器？市面上的选择，要么界面观感欠佳，要么功能繁杂臃肿，很难找到一款兼顾简洁美观、上手顺手的工具。于是便有了 YiziMarkdown，并坚持三件事：**界面好看**，**功能彪悍**，**场景多元**。

本篇文档也是借助 YiziMarkdown 编辑完成。现在涵盖 `3 种系统`、`7 种使用模式`、`16 种界面语言`、`15 种明暗双色主题`、`5 种 AI Skill`、`7 种导出格式`，并内置 AI 助手、云端存储等能力。

### Markdown 四项全能

源码、并排、实时、预览共享同一个编辑器内核与同一套 Markdown 能力，区别只在信息密度：

- **源码** — CodeMirror 6 内核，语法高亮、括号匹配、自动补全；行号与自动换行可开关
- **并排** — 左写右看，滚动同步由大纲驱动，切换视图时自动定位
- **实时** — 输入时隐藏标记、光标离开后恢复；4 种标记显现动画（聚焦 / 闪光 / 辉光 / 涟漪）
- **预览** — 即写即渲染，任务列表 checkbox 可直接点选，本地图片与 SVG 自动显示

YAML front matter 在实时模式下渲染成 Obsidian 式可编辑属性面板（自动 / 文本 / 数字 / 复选框 / 日期 / 日期和时间 / 列表 7 种类型，类型按属性名全局记忆）；源码模式原样显示，预览模式隐藏。

四种视图共享：搜索替换、工具栏格式化、代码块增强（语言标签 / 复制 / 折行）、8×8 表格选择器、KaTeX 公式、Mermaid 图表、大纲导航、格式工具栏自动折叠。

### 演示模式（幻灯片）

写好的笔记不必再导出 PPT：工具栏「放映」、标签栏「演示」或 `Ctrl+Alt+P` 即可进入，文档立刻变成全屏幻灯片。

- **纯 Markdown 驱动** — `---`（水平分割线）分页，引擎根据内容结构自动选择版式
- **分栏** — 页内单独成行的 `***` 分栏，最多 4 栏（`---` 分页、`***` 分栏）
- **14 种版式** — 封面、章节、结尾、目录、内容、列表、数据表、路线图、图文、图片、金句、代码、图表、公式；除「图文」需 `<!-- layout: figure -->` 显式指定外，其余自动推断
- **排版与内容区** — 播放中可实时调整字体、字重、字号与内容区宽高（50%~95%），并持久化
- **分栏卡片与对齐** — 分栏页每栏自带等高卡片，栏内对齐（左 / 中 / 右）与样式（无 / 分隔线 / 卡片）在 HUD 中调整
- **滚轮翻页** — 内容超出时先滚内容，到边界再翻页
- **主题继承** — 标题配色随主题变化，播放中可切换主题 / 明暗
- **播放快捷键** — `→/←` 翻页、`F` 全屏、`S` 演讲者备注、`T` 目录、`?` 帮助、`Esc` 退出
- **退出按钮** — 鼠标活动时右上角显示，1.5 秒无操作自动隐藏；退出后还原进入前的窗口状态

### 阅读模式

阅读模式不是全屏预览，而是把正文排成固定页面：有封面、扉页、目录、页码与翻页动效。

- 入口：工具栏书本按钮或 `Ctrl+Alt+R`；`Esc` 退出并恢复原视图
- 双页对开（窄窗口自动单页），页码与阅读进度齐备
- **4 种翻页动画** — 水平滑动（默认）/ 3D 翻页 / 淡入淡出 / 缩放，可在阅读 HUD 中切换
- **目录抽屉** — `T` 打开，按标题层级标注页码，点击直达；`G` 或页码框跳页
- **脚注往返** — 点击脚注引用跳到定义页并高亮，可「返回引用」
- **阅读 HUD** — 右下角切换明暗、主题、字体、字号与行距，只作用于本次阅读
- **位置记忆** — 按文档记住页码 / 章节，再次进入自动恢复
- **EPUB** — 打开 `.epub` 直接进入阅读模式，使用应用阅读主题，支持内嵌封面、目录、图片、公式、Mermaid SVG、脚注与跨章节链接（DRM 与固定版式暂不支持）

### 禅模式

`F9` 或工具栏禅模式按钮进入。工具栏、标签栏、侧栏、AI 面板、状态栏按层次朝屏幕边缘收折淡出，只留正文，**布局不变**，正文一个像素都不移动。

- 鼠标贴住屏幕任一边（上 / 左 / 右 / 下），对应区域原地淡回；离开约 1.2 秒自动收回
- 禅模式按钮常驻原位（周围一圈极浅呼吸涟漪），既是状态锚，也是退出通道；`F9` / `Esc` 都可退出
- 仅在源码 / 实时模式可用；切到并排、预览，或进入阅读 / 演示会自动退出
- 隐藏行号与侧栏竖线、极淡暗角、指针静止 2 秒自动隐藏，滚动条换成极简细条

## AI 助手

工具栏的 🤖 机器人按钮打开右侧 AI 聊天面板：

- **18 家大模型供应商 + 自定义服务** — OpenAI、Anthropic、Gemini、xAI、Mistral、Groq、DeepSeek、通义千问、智谱 GLM、Moonshot Kimi、火山方舟、硅基流动、MiniMax、小米 MiMo、美团 LongCat、OpenRouter、OpenCode Go、Ollama（本地）；「自定义服务」支持 OpenAI / Anthropic 兼容协议，自填 Base URL、模型 ID 与密钥
- 回答流式输出，可随时停止；回复可复制、插入文档，或一键创建为新文档
- 推理模型的思考过程（reasoning / thinking）以可折叠区块展示，默认收起
- 勾选「引用当前文档」可把文档作为上下文，并配置引用上限与上下文轮数
- API 密钥存系统钥匙串，支持一键保存、清除、验证；本地端点可留空

### AI 技能（Skill）

输入框上方的 ⚡ 按钮弹出技能菜单，选中后以胶囊标签插入输入框（可像文字一样删除），提示词自动注入上下文。内置 5 个技能：

- **演示稿提炼** — 把当前文档提炼为可直接播放的精简演示文稿
- **文档摘要** — 一句话主旨 + 核心要点 + 关键结论
- **润色改写** — 保持原意优化表达
- **全文翻译** — 按目标语言整篇翻译
- **Markdown 格式化** — 规范标题、列表、表格与代码块

在用户目录 `~/Documents/yizimarkdown/skills/` 放入 `.md` 提示词并在 `skills.json` 登记即可扩展，无需修改程序。

## 多语言界面

支持 16 种界面语言，在 设置 → 通用 → 界面语言 切换（简体中文 / 繁體中文 / English / 日本語 / 한국어 / Deutsch / Français / Español / Português / Italiano / Polski / Nederlands / Türkçe / Svenska / Українська / Русский），即时生效。首次启动会按系统语言自动选择，不在支持列表内则回退 English。界面字号支持 80%–120%。

## 大纲

左侧侧栏默认展示文档大纲，自动提取全部标题层级。

- 滚动编辑区或预览区，大纲高亮跟随当前位置
- 点击大纲节点，编辑区与预览区同步跳转到对应标题
- 并排模式下，滚动任一侧，另一侧自动联动

## 数学公式与图表

- **公式** — 用 `$...$` 包裹行内公式（如 `$E=mc^2$`），`$$...$$` 独占一行渲染块级公式；工具栏 Σ 按钮可一键包裹选中文字
- **Mermaid** — 用 Mermaid 语法描述图表，自动渲染为流程图、时序图、甘特图、类图、饼图等，配色跟随当前主题；工具栏图表按钮可插入模板
- **表格** — 工具栏表格按钮打开 8×8 行列网格，点选即插入对应大小的表格，无需手写语法

## 文件与标签

- **单实例模式** — 双击 .md 不会打开多个窗口，自动合并到已有实例；已打开的文件自动定位到对应标签页
- **首页** — Tab 栏最左侧，展示最近打开的文件列表
- **文件标签** — 每个文件一个 Tab，未保存时显示呼吸小圆点；保存后出现确认动画
- **新建 / 从模板新建** — Tab 栏 `+` 新建空白文件；工具栏「从模板新建」按模板结构创建，设置默认模板后 `Ctrl+N` 自动套用
- **拖动排序** — 按住 Tab 拖动即可调整顺序
- **关闭确认** — 未保存时弹出保存 / 不保存 / 取消

## 导出

工具栏导出菜单支持 **7 种格式**：Word（DOCX）、PDF、HTML、PPTX、Markdown、纯文本，以及插件提供的 EPUB。

- DOCX 使用 Word 原生语义（列表 / 表格 / 代码块 / 引用 / 任务列表），表格样式与预览一致，图片支持本地路径、网络图片与 HTML `<img>`
- PDF 与预览还原度一致并自动分页
- HTML 附带**左侧悬浮大纲卡片**，点击条目直达章节（PDF 不含侧栏）
- PPTX 把演示模式导出为原生可编辑的 PowerPoint，继承主题、明暗与版式，基准 16:9（1280×720）
- EPUB 导出前可选择章节拆分 / 封面 / 可见目录 / 阅读主题 / 文档信息

## 云端存储（WebDAV）

设置 → 云端存储，可以把文档直接读写到 WebDAV 服务器（坚果云、Nextcloud、群晖等），多台设备共用同一份笔记。

1. 填**服务器地址**（坚果云是 `https://dav.jianguoyun.com/dav/`）、**用户名**与**应用专用密码**，点「保存凭据」
2. 点「测试连接」确认可用

之后侧边栏切到「云端」标签页即可浏览目录、打开文档、新建 / 移动 / 重命名 / 删除；工具栏「保存到云端」把本地文档传上去，云端文档 `Ctrl+S` 直接写回服务器。

- 账号密码存系统凭据库（Windows 凭据管理器 / macOS 钥匙串），不写入配置文件
- 保存前比对 ETag，远程被其他设备改过会提示覆盖或重新加载，绝不静默覆盖
- 云端图片统一放在 `<WebDAV 根>/assets/`，正文以相对路径引用；目录里自带 `README.md` 说明，请勿手动清理

## 自定义与插件

| 文件 | 用途 |
|------|------|
| `user.css` | 自定义样式，覆盖在所有主题之后，优先级最高 |
| `keybindings.json` | 快捷键配置（也可在 设置 → 快捷键 中可视化编辑） |
| `themes/*.css` | 放入新主题文件并在 `themes/theme.json` 登记，重启后在设置面板中可见 |
| `~/Documents/yizimarkdown/skills/*.md` + `skills.json` | AI 技能：提示词正文 + 技能清单 |
| `~/Documents/yizimarkdown/templates/*.md` | 文档模板，可在 设置 → 模板 中直接新建 / 编辑 |

KaTeX / Mermaid / 脚注 / 任务列表 / TOC 等文档语义能力默认内置，不受插件开关影响；内置插件为 **EPUB 导出**（可在 设置 → 插件 中管理）。

如果想定制自己的主题，也很简单：

1. 打开任意 AI 平台
2. 从 `themes` 目录挑一个 CSS 文件上传
3. 告诉 AI 你想改成什么风格、什么配色
4. 把生成的 CSS 保存回 `themes` 目录（并在 `themes/theme.json` 登记）
5. 重启程序即可

## 其他设置

- **自动保存** — 建议开启，间隔可设 5~180 秒（默认 60 秒）
- **预览字体** — 推荐小米字体 `MiSans`，排版观感更好
- **文件关联** — 设置 → 通用 → 文件关联，勾选后双击 `.md` 直接用 YiziMarkdown 打开（Windows 注册表 / macOS LaunchServices）
- **模板与技能目录** — Linux 下位于 XDG 文档目录的 `yizimarkdown/`，无文档目录时兜底 `~/.local/share/yizimarkdown/`
