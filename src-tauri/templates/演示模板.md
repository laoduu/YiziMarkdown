# 演示模式

## 把 Markdown 变成全屏幻灯片

按 `Ctrl+Alt+P` 或点「演示」按钮进入全屏播放

<!-- notes: 开场：大家好，今天演示 YiziMarkdown 的演示模式 -->

---

# 分页规则

- `---` 单独成行 → 横向幻灯片分页
- `--` 单独成行 → 纵向子页（按 ↑↓ 切换）
- 代码围栏里的 `---` 是内容，不会分页

```markdown
---
# 第一页

---

# 第二页
```
